# 설계 36 C3: planner 점수가 자기 후보의 실제 성적 순서를 맞히는가

각 분기점(branch point)은 적응된 planner가 실제로 걸으며 지나간 상태 하나다. 그 제어 단계에서 planner가 점수를 매긴 후보 64개(첫/마지막 반복의 Gaussian 표본을 점수 순위로 고르게 뽑은 것, 정책 혼합 표본, 마지막 반복의 최고 점수 후보, 실제로 실행한 평균 계획 mean, 정책 헤드 chunk head)를 시뮬레이션에서 25 step open loop로 실행한 뒤 정책 헤드로 125 step까지 이어 걸었다. '모델 점수' = 25 step 예측 보상의 할인 합 + 끝 value (planner가 후보를 고를 때 쓰는 값). '실제 return' = 시뮬레이션에서 받은 125 step 보상 합. 괄호는 분기점에 대한 bootstrap 95 % 신뢰구간(5000회, seed 36).

| 조건 | 분기점 수 | 빠진 분기점 |
|---|---|---|
| nominal | 96 | 0 |
| tow20 | 96 | 0 |
| mot50 | 96 | 0 |
| legR50 | 96 | 0 |

\begin{abstract}
Latent world models pretrained in simulation can be adapted to a real robot from a few minutes of data by finetuning only their latent dynamics, while the encoder, reward and value heads stay frozen; unfreezing the value head has been reported to cause catastrophic forgetting. We show that this negative result rests on a single update rule rather than on a property of value functions: under a dynamics shift the simulation value is mostly wrong in \emph{scale and offset} while its \emph{ranking} of states is largely preserved, so a small correction suffices and a full re-estimation is unnecessary and harmful. We propose selective value adaptation, which keeps the simulation value frozen and learns a zero-initialized residual on top of it from truncated $n$-step returns of the real rollouts, bootstrapped with a frozen anchor copy of the simulation value and regularized by replay of simulation windows. The planner consumes the corrected value without any change. On a sim-to-sim benchmark with perturbed physics (friction, payload, motor strength) and real data budgets of 5--30 minutes, selective value adaptation improves the return in the target condition over dynamics-only adaptation by \prelim{$3\times$} while keeping nominal-condition performance and the value error on the pretraining distribution \prelim{six times} lower than full value finetuning. On a Unitree Go1 quadruped, \todo{real-robot headline}. We also introduce a value-forgetting metric that separates value drift from behavioral forgetting. \todo{trim to 200 words}
\end{abstract}

\section{Selective Value Adaptation}
\label{sec:method}
\subsection{Residual value head}
We keep the pretrained value head frozen and add a residual $\res_\phi(z, c)$ with the same sequence architecture as the value head and a zero-initialized output layer, so that at the start of adaptation
\begin{equation}
V_\phi(z, c) = \vsim(z, c) + \res_\phi(z, c), \qquad \res_\phi \equiv 0 .
\end{equation}
The planner reads $V_\phi$ in place of $\vsim$; nothing else in the pipeline changes.

\subsection{Truncated-return targets with a frozen anchor}
For a window of real data $(z_t, a_t, c_t, r_t)_{t=0}^{T}$ with latents $z$ obtained by encoding the \emph{true} observations (so the value update does not depend on the accuracy of the adapted dynamics), the target of the state at step $k$ is the truncated return
\begin{equation}
G_k = \sum_{j=k}^{T-1} \gamma^{\,j-k} r_j + \gamma^{\,T-k}\, \bar V(z_T, c_T),
\label{eq:target}
\end{equation}
where $\bar V$ is a frozen copy of $\vsim$ (the \emph{anchor}). Bootstrapping only through the anchor keeps the target in the scale of the simulation value and prevents the residual from chasing its own estimates. \todo{On a real robot $r_j$ is replaced by the frozen reward head evaluated on the true latents; state and justify.}
\begin{equation}
\mathcal{L}_{\mathrm{value}} = \frac{1}{T}\sum_{k=1}^{T} \big( V_\phi(z_k, c_k) - G_k \big)^2 .
\end{equation}

\subsection{Simulation replay as a data anchor}
Following the evidence that data-level anchors beat parameter-level anchors against forgetting~\citep{wolczyk2024forgetting}, every update also draws a batch of windows from the simulation pretraining set and regresses $V_\phi$ on the true simulation latents to the simulation critic's labels $v^{\mathrm{sim}}$:
\begin{equation}
\mathcal{L}_{\mathrm{replay}} = \frac{1}{T}\sum_{k} \big( V_\phi(z^{\mathrm{sim}}_k, c^{\mathrm{sim}}_k) - v^{\mathrm{sim}}_k \big)^2 .
\end{equation}

\subsection{Full objective}
\begin{equation}
\mathcal{L} = \mathcal{L}_{\mathrm{dyn}} + \lambda_v \mathcal{L}_{\mathrm{value}} + \lambda_r \mathcal{L}_{\mathrm{replay}},
\end{equation}
with $\mathcal{L}_{\mathrm{dyn}}$ the latent-dynamics loss of SimDist. Trainable: $f$ and $\res_\phi$ (residual learning rate \todo{$10^{-3}$}); frozen: $E$, $C$, $R$, $\vsim$, $\pi$. \todo{Algorithm box: iterative rounds (collect with current model, aggregate, update $f$ and $\res$).}

\section{Experimental Setup}
\label{sec:setup}
\paragraph{Platform.} Unitree Go1 EDU (12\,kg, \todo{torque}) in simulation (Isaac Lab) and hardware; pretraining at the scale of SimDist (\todo{1024 envs, 102M transitions, 369k gradient steps}); MPPI at 50\,Hz with \todo{200 samples $\times$ 3 iterations on an RTX 3060 (paper setting 450 $\times$ 8 reproduced in Sec.~\ref{sec:sensitivity})}.

\paragraph{Sim-to-sim benchmark.} Target conditions: friction 0.3, payload $+3$\,kg, motor torque limit $\times 0.6$ (\texttt{combo}), motor $\times 0.4$ (stress), \todo{low friction, payload alone}. ``Real'' data is collected by the pretrained planner in the target condition at three commanded speeds and logged in the real-data format; budgets of 5, 15 and 30 minutes (15k/45k/90k steps at 50\,Hz). Oracle: the same recipe with 60 minutes and $3\times$ the gradient steps. Expert reference: the privileged RL expert acting directly (observes friction and mass, blind to motor strength).

\paragraph{Recipes compared.} dynamics-only (SimDist); full value finetuning (SimDist's forgetting ablation); full + replay (FOWM-style); residual + anchor; residual + replay; residual + anchor + replay (ours); ablations: random-init residual, no anchor (ReLA-style self-bootstrap), MLP residual. All start from the same checkpoint and train for the same number of steps on the same windows.

\paragraph{Metrics.} Target-condition return over 1000 steps and fraction of episodes without a fall (\todo{10 seeds}); nominal-condition return (behavioral forgetting, 5 seeds); value-forgetting metric (Sec.~\ref{sec:method}); value error vs.\ Monte-Carlo return (Sec.~\ref{sec:diagnosis}).

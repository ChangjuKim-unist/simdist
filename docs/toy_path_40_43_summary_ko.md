# 장난감 고장 적응 경로 요약 (설계 40–43)

2026-11-24. 설계 43 §9 "실패" 갈래에 따라 새 GPU 실험 없이 정리한다.

## 1. 묻던 것

사용자 가설: world model이 expert(PPO) 상태에 묶여 있으면, 새 조건에서 적응할 때 얻는 이득이 작다. 이를 장난감 환경(MuJoCo Playground Go1, MJX)에서 확인하려 했다. 비교 대상은 다음 둘이다.

- E: expert 상태에서 배운 world model
- M: MPC 자신의 상태에서 배운 world model

planner는 reference 없는 MPPI(관절 상자)다.

## 3. 무엇이 막혔나

- **데이터가 아니라 모델 + planner 조합의 정확도가 막혔다.**
  - 데이터 양은 5만 → 7만5천에서만 효과가 있었다.
  - 어느 상태를 덮는지(걷는 planner 상태인지 자기 상태인지)는 상관없었다.
  - 진짜 모델로 바꾸면 같은 MPPI가 0/16으로 걷는다.
- **증상은 방향 틀어짐과 과신이다.**
  - world model planner의 방향 틀어짐은 50–108°로, 상한 planner(5–6°)보다 훨씬 크다.
  - 고장 데이터만 배운 모델은 상한보다 빨리 걸으려다(0.40 대 0.34 m/s) 넘어진다.
  - planner는 모델이 틀린 곳, 곧 실제보다 쉬워 보이는 곳을 골라 간다.
- **가설과의 관계.** 적응 전부터 world model planner가 고장 조건에서 걷지 못한다. 그래서 E 대 M 차이를 잴 바닥이 없었다. 이 장난감 설정으로는 가설을 확인하지도 반박하지도 못했다.

## 4. 다음 제안 (하나)

**불확실성을 보는 planner: world model 앙상블의 예측 불일치를 MPPI 비용에 벌점으로 넣기.**

- **왜:**
  - 막힌 이유가 "모델이 틀린 곳을 planner가 골라 감"이다.
  - 데이터를 더 넣어도 그 틈이 닫히지 않았다.
  - 그러면 planner가 모델이 모르는 곳을 피하게 하는 것이 다음 손잡이다.
  - 고정 문제(30분 데이터로 이득 + 안전 + 보존) 중 안전 축과 바로 맞닿는다.
  - 설계 29의 대피 방식(확신이 생길 때까지 사전학습 모델로 계획)과 다르다. 그 방식은 모델을 바꾸지만, 이 제안은 같은 모델 안에서 행동을 고른다.
- **첫 관문 (싸게, 약 1.5 GPU-시간):**
  - 설정: 설계 43 CT r4 데이터(무릎 고장 두 개)로 world model 5개를 학습한다. 비용에 β × (앙상블 45스텝 예측 분산)을 더한다. β는 3개 값을 시험한다.
  - 통과 기준: 설계 43과 같다. 시드 평균 J ≥ 상한의 절반, 넘어짐 ≤ 8/16.
  - 앙상블 평균만 쓴 팔(β = 0)과 비교해 벌점 자체의 효과를 가른다.
- **통과하면:** 이 planner로 설계 41의 E 대 M 질문을 다시 잴 수 있는 바닥이 생긴다.
- **실패하면:** 남은 원인은 모델 표현력이다(MLP 상태 모델). 장난감 대신 go1_paper 쪽으로 돌아가는 것을 검토한다.

실행 전에 설계 문서로 등록하고 사용자 승인을 받는다.

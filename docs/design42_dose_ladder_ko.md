# 설계 42: 고장 적응이 되는 용량을 먼저 찾고, 그 용량에서 expert 상태 대 MPC 상태를 다시 비교 (장난감)

등록 2026-11-23, 결과 전. 설계 41이 "측정 불가"로 끝난 뒤 사용자 승인("그러면 그렇게해줘")으로 등록한다.

## 1. 질문

**사용자 가설:** world model이 expert에 묶여 있으면, 학습 범위 밖 조건에 적응할 때 이득이 작다. 설계 41과 같이 데이터 경로, 그중 "어떤 상태에서 배웠나"만 본다.

설계 41에서 막힌 곳은 두 가지다.

| 설계 41의 막힘 | 수치 | 설계 42의 처리 |
|---|---|---|
| 특권 데이터로도 적응이 안 됨 | 무릎 고장 G⁺ ≤ +0.042, 미세조정 후 47/48 넘어짐 (상한 0/16) | **용량 사다리 (단계 A):** 특권 데이터 양, 미세조정 길이, 처음부터 다시 학습을 늘려 가며 world model MPPI가 걷는 가장 작은 절차를 찾는다 |
| 자기 수집 데이터가 너무 적음 | 무릎 고장에서 16개 에피소드가 첫 넘어짐까지 1072–1992 transition | **넘어지면 다시 세워 모으기 (단계 B):** 정해진 양이 찰 때까지, 실기 예산 30분(90000 스텝) 안에서 모은다 |

## 2. 고정 (설계 41과 같음)

- 환경, planner(256 × 6, 관절 상자), 평가(명령 0.6 m/s, 16개 × 500스텝, 평가 시드 0–15), 지표 J, 넘어짐, 동작 품질.
- 팔 E(PPO가 행동하고 MPPI 후보를 기록), M(MPPI가 행동). 설계 41의 pretrained world model `wm_E{0,1,2}`, `wm_M{0,1,2}`와 pretraining 데이터를 그대로 쓴다. 적응 전 J(조건, nominal)와 상한 U(c)도 설계 41 값을 다시 쓴다(같은 모델, 같은 평가 시드).
- EN은 걷기 관문에서 실패했으므로 뺀다. tow40은 상한이 거의 서 있어(전진 0.04 m/s, 여지 < 0.10) 뺀다.
- 조건: kneeRR0, kneeFR0.

## 3. 단계 A: 특권 데이터 용량 사다리

특권 데이터 = 진짜 조건 모델 MPPI가 그 조건에서 걸으며 만든 후보 궤적. pretraining 데이터와 같은 형식(DR 없는 조건, 에피소드 25개 × 500스텝 × 후보 4, 시드 1, 2)으로 조건마다 새로 만든다.

| 칸 | 시작 | 특권 데이터 | 학습 | replay |
|---|---|---|---|---|
| A1 | pretrained | 8000 | 30000스텝 | 자기 pretraining 50 % |
| A2 | pretrained | 50000 | 30000스텝 | 자기 pretraining 50 % |
| A3 | 처음부터 | 50000 | 30000스텝 | 자기 pretraining 50000 (같은 양 섞음) |
| A4 (진단) | 처음부터 | 50000 | 30000스텝 | 없음 (고장 데이터만), 시드 0 하나 |

- A1–A3: 팔 E, M × world model 시드 0, 1, 2 × 조건 2개. 조건과 nominal에서 평가한다.
- **칸 통과(조건 c, 팔 a):** 시드 평균 J ≥ U(c)의 절반(kneeRR0 0.300, kneeFR0 0.227), 그리고 시드 평균 넘어짐 ≤ 8/16.
- **절차 P(c):** A1 → A2 → A3 순서로, E와 M이 모두 통과하는 첫 칸.
- P(c)가 없는 조건은 단계 B에서 뺀다. 두 조건 모두 없으면 **"장난감 경로 닫음"** 으로 멈춘다. A4는 이때 원인을 가리는 데만 쓴다(A4도 실패하면 world model 자체가 고장 dynamics를 planner가 쓸 만큼 배우지 못함, A4만 통과하면 섞어 배우기가 문제).

## 4. 단계 B: 자기 데이터로 같은 절차

조건 c에서 P(c)가 정해지면 팔 E, M × 시드 0, 1, 2마다:

1. **수집:** 자기 pretrained world model MPPI가 c에서 걷는다. 한 묶음 = 에피소드 128개 × 최대 150스텝(3 s), 넘어지면 그 에피소드는 거기서 끝(= 다시 세움). 묶음 시드는 10000 + 128b로 팔·시드에 관계없이 같다. (등록 전 시험: M0, kneeRR0에서 64개 × 250스텝 묶음은 64개 모두 넘어졌고 첫 넘어짐 중앙 약 66스텝, usable 3992, 4분 → 3 s 에피소드로 줄여도 잘리는 데이터가 거의 없어 묶음을 키웠다.)
2. **멈춤:** 첫 넘어짐 전까지의 usable transition(8스텝 창 단위)이 N(c) = P(c)의 데이터 양(A1 8000, A2·A3 50000) 이상이 되거나, 로봇이 실제로 돈 스텝이 90000(30분)을 넘거나, 16묶음이 되면 멈춘다.
3. **적응:** P(c)와 같은 절차(시작, 30000스텝, replay)에 특권 데이터 대신 자기 데이터 N(c)개(넘어진 뒤 버림).
4. **평가:** c와 nominal에서 16개씩.

- 이득 G(a, c) = J(적응 후, c) − J(적응 전, c), 적응 전은 설계 41 값.
- 보존 손실 L(a) = J(적응 전, nominal) − J(적응 후, nominal), 포함 조건 평균.
- 안전(보고): 수집 중 넘어진 에피소드 수, 쓴 로봇 스텝, 적응 후 넘어짐.

## 5. 판정 (실행 전 고정)

- **조건 자격:** P(c)가 있고, 여지 U(c) − max(J_before(E, c), J_before(M, c)) ≥ 0.10. (사다리 통과가 설계 41의 양성 대조 조건을 대신한다.)
- **걷기 관문:** 설계 41 결과(E 0.479, M 0.562 통과)를 그대로 쓴다.
- **주 판정:** D(c) = G(M, c) − G(E, c), 시드끼리 짝지어 세 값. 설계 41 §5와 같은 표.

| 판정 | 조건 |
|---|---|
| 가설 지지 | 자격 조건 중 둘 이상(하나뿐이면 그 하나)에서 평균 D ≥ 0.10이고 세 시드 모두 D > 0, 그리고 L(M) − L(E) ≤ 0.05 |
| 가설 반대 | 같은 기준을 −D에 적용, 그리고 L(E) − L(M) ≤ 0.05 |
| 차이 없음 | 모든 자격 조건에서 \|평균 D\| < 0.05 |
| 중간 | 그 밖 |
| 장난감 경로 닫음 | 두 조건 모두 P(c) 없음 |
| 측정 불가 | P(c)는 있으나 자격 조건 없음 |

- 95 % 구간은 (시드, 에피소드) 짝 bootstrap으로 보고만 한다.
- 단계 A에서 E와 M을 특권 데이터로 비교한 값은 보고만 한다(판정 아님).

## 6. 예측

- 통과하는 첫 칸: A1 10 %, A2 20 %, A3 20 %, 없음 50 %. A4 통과 45 %.
  - 근거: 설계 41 특권 미세조정은 학습 손실 0.007까지 내려갔는데도 넘어졌다. 특권 데이터는 걷는 planner의 상태에서 나왔고, world model MPPI는 처음 몇 초에 그 상태를 벗어난다(설계 40 v2의 덮기 문제와 같은 꼴).
- 판정: 장난감 경로 닫음 50 %, 지지 12 %, 차이 없음 15 %, 반대 5 %, 중간·측정 불가 18 %.
- 단계 B 수집: N = 50000이면 무릎 고장에서 묶음 약 6–7개, 로봇 스텝 약 55000.

| 설계 42 결과 | 다음 (설계 43) |
|---|---|
| 장난감 경로 닫음, A4도 실패 | **자기 상태 덮기 확인:** world model MPPI가 실제로 지나가는 상태에서 진짜 모델 후보를 굴려 배우는 반복(DAgger식, 특권)으로 고장에서 걷게 되는지. 이것도 실패하면 장난감 고장 적응 경로를 끝내고 사용자에게 보고한다 |
| 장난감 경로 닫음, A4는 통과 | **새 모델 절차로 단계 B:** 자기 수집 데이터만으로 고장 world model을 새로 학습하는 절차(A4식)로 E 대 M 판정을 다시 한다. pretrained 모델은 따로 두므로 보존은 전환 규칙의 문제로 따로 보고한다 |
| 가설 지지 | **반복 확인:** 새 world model 시드 3–5로 같은 단계 B를 다시 돌린다 |
| 차이 없음, 반대, 중간 | **다른 expert 경로 시험:** planner에 PPO policy prior(표본 일부를 PPO 행동 주변에서 뽑음)를 넣었을 때 적응 이득이 줄어드는지 |
| 측정 불가 | 단계 B를 자격 조건이 생기는 다른 고장(여지 ≥ 0.10)으로 옮긴다 |

- 지키는 것: 삭제 없음, 고정 설정(중간 난이도 + 다리 고장, 조심스러운 시작) 유지, 분석 논문으로 돌리는 제안 없음, gpu1 GPU당 11 GB 이하.

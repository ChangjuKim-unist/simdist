# 설계 문서 14: 계획은 언제 돕는가 — 자기 예측 오차로 상상의 신뢰를 정하는 월드모델 (2026-11-06)

사용자 결정(2026-11-06): 맥락 슬롯(설계 13)·식별 후 재학습(설계 5~12) 계열을 접고 새 주제로. 문헌 조사 `reports/월드모델 계획 연구방향 재설정.md`(공통 미해결 문제: 계획기의 모델 오차 착취, 예측은 되는데 계획엔 못 씀, prior/샘플 배치가 병목, 실데이터 적응의 망각). 주제 한 문장:

> 시뮬 사전학습 월드모델 위의 샘플링 계획기는 prior가 넓어질수록 평균적으로 해가 되며, 계획기가 자기 상상을 얼마나 믿을지를 **모델 자신의 과거 예측 오차**(상상 − 실현)에서 학습한 신호로 정하면(결과·수익 보정 + 계획/prior 게이트) 실데이터 없이 해 없이 이득만 남는다.

구조(목표): SimDist 코어(인코더·이력 토큰·청크 동역학·보상·가치·prior) 그대로 + ① 자기 오차 토큰(지난 H스텝의 예측 잠재·보상 − 실현을 이력 인코더에 추가) ② 실현 수익·결과 헤드(오차 토큰 조건, 분위수) + 신뢰 가중치 w ③ prior 지속 결과 헤드(2~4초 리드타임) ④ 요구 시 계획 게이트(w 높으면 prior 실행, 낮으면 MPPI + ②를 터미널로). 코어는 얼리고 ①②③만 2단계 "자기 굴림" 데이터로 학습.

## 0. 실험 전 점검 (2026-11-06, 돌리기 전에 적음)

이미 있는 증거:
- 전제 "넓은 prior 위에서 계획기가 해롭다"는 **모델에 따라 다르다**. 짝지은 비교(18런, 부트스트랩 CI): go1_ctx 모터 0.4에서 prior만 − 계획기 = 넘어짐 −0.17 [−0.32, −0.03], 전진 +19 m [+10, +29] → 계획기가 해롭다. targethead 모터 0.4: +0.08 [−0.03, +0.19], 전진 −10 [−23, +0.4] → 차이 없음/계획기 약간 유리. **go1_broadwm은 prior만 숫자가 없다.**
- 설계 7 X2: 한 스텝 잠재 예측 오차가 이동 중앙값의 3배를 넘으면 prior로 폴백하는 게이트 → 효과 없음(넘어짐 비 0.92 [0.69, 1.25]). **원시 예측 오차는 신뢰 신호로 부족**. 살아남으려면 오차 창에서 학습한 신호가 원시 오차·상태 이력보다 확실히 나아야 한다.
- 설계 13: 참 물리(oracle ψ)를 줘도 계획기는 대조군 수준 → ①의 "동역학 테스트 시 보정" 역할은 기대가 낮다(25 %). "좁은 모델 + ① ≥ 넓은 모델" 주장은 내린다. ①의 역할은 ②④의 입력.
- 설계 3 명제 6: 넘어짐 4초 전 수익 하락 29 %, 후보 간 수익 차 0.4 → 리드타임 ≫ 지평(0.5 s). ③의 근거.
- 문헌(저희 측정 아님): 결과 라벨 헤드 AUC 0.97 대 동역학 불확실성 0.60(Wang 2026, 2D); 불확실성 패널티는 충돌을 늘림(26→34 %).

구성요소별 성공 확률(제 추정): ① 오차 토큰이 변화·위험을 읽음 55 %; ② 실현 수익 헤드 + 하위 분위수로 계획기 해악 제거 50 %; ③ 추가 이득 35 %; ④ "prior만보다 나쁘지 않음" 70 %, "어딘가에서 둘 다 이김" 40 %. 방법 논문 성립 35~45 %, 레짐 지도 + 신뢰 신호 분석 포함 성립 ~70 %. → 전체 체인 대신 **0단계로 전제를 먼저 판정**.

모든 실행에서 매 스텝 기록(`output.trace_npz`): z_t, 실행 계획에 대한 예측 잠재(25×64)·보상·가치, 실현 보상, 넘어짐, 리셋. 고친 평가기(6시드 × 3속도, 5000스텝, 100 s).

|---|---|---|

**예측 (전부 실험 전)**
- **S0-1 전제(계획기 해악)**: go1_broadwm에서 변화 조건(모터 0.4·마찰 0.15·질량 +3) 중 **하나 이상**에서 계획기 넘어짐 ≥ prior만 (짝지은 차이 CI가 0 제외) 또는 전진 거리 CI가 0 제외로 prior만 우세. 정상에서는 둘이 같음(넘어짐 0, 보상 차 ≤ 0.002).
  - 성립 → 게이트에 동기 있음. 불성립(전 조건에서 계획기가 같거나 좋음) → "계획기 해악"은 go1_ctx 특이 현상; 논문 질문을 "언제 계획이 돕는가"의 레짐 지도 + 신뢰 신호를 **적응 트리거**로 쓰는 쪽으로 옮긴다(게이트는 보조).
- **S0-2 신호(학습된 신뢰)**: 트레이스에서 창 길이 25의 세 가지 입력 — (a) 상태·행동 이력, (b) 원시 오차(예측 − 실현 잠재·보상), (c) (a)+(b) — 로 작은 MLP 프로브를 학습(조건 섞어 학습, 시드 분할 보류). 목표: 100스텝 안 넘어짐(AUC), 다음 25스텝 실현 수익 − 예측 수익(R²), 조건(모터/마찰/질량 분류). 예측: 변화 조건에서 (b) 또는 (c)의 넘어짐 AUC ≥ 0.8이고 (a)보다 ≥ 0.1 높음; 수익 격차 R² ≥ 0.3. 보류 축(질량 +3은 학습에서 빼고 시험)에서 AUC ≥ 0.7.
  - 성립 → ①②를 만든다. 불성립(오차가 이력보다 못하거나 AUC < 0.7) → 오차 토큰 구조 기각, 결과 헤드(라벨 학습)만 남기고 설계 재작성.
- **S0-3 레짐**: go1_paper(좁은)에서는 모터 0.4·마찰 0.15 모두 계획기 넘어짐 ≤ prior만 (SimDist 영역: 계획이 돕는다). 성립하면 "계획의 이득은 prior 폭에 따라 뒤집힌다"가 레짐 지도의 두 끝점.

**중단 기준**: S0-1과 S0-2가 **둘 다** 불성립이면 이 주제(게이트·오차 토큰)는 접고, 보고서의 A(축별 망각 없는 적응)로 간다. 하나만 성립하면 성립한 쪽으로 설계를 다시 등록한다.

**비용**: 14런 × 20~50분, 4 GPU ≈ 2~3 h. 트레이스 1런 ≈ 300 MB (/data1).

## 2. 실험 전 수학적 검토 (2026-11-06 14:00; 숫자는 1차 로컬 트레이스 go1_ctx·마찰 0.15·prior만, 18대 × 5000스텝)

기호. 참 물리 ξ 아래 행동열 a의 참 수익 J_ξ(a), 모델이 약속한 수익 Ĵ(a) = Σγ^i R̂(ẑ_{t+i}, a_{t+i}) + γ^T V̂(ẑ_{t+T}), 모델 오차 Δ(a) = J_ξ(a) − Ĵ(a) (음수 = 과대 약속). prior의 행동열 a_π, 계획기가 고른 a* = argmax Ĵ (엘리트 가중 평균).

**명제 1 (계획이 해가 되는 조건 = 선택 편향 > 약속 이득).**
J(a*) − J(a_π) = [Ĵ(a*) − Ĵ(a_π)] + [Δ(a*) − Δ(a_π)] = G − B. G ≥ 0은 계획기가 약속한 이득, B = Δ(a_π) − Δ(a*)는 "틀린 쪽으로 고른" 선택 편향(optimizer's curse: 후보 K개 중 Ĵ 최대를 고르면 E[Δ(a*)] < E[Δ], 독립 가우시안 근사에서 편향 ≈ σ_Δ·√(2 ln K)). 계획이 해가 된다 ⇔ B > G. 설계 3 측정: 넘어짐 4초 전 후보 간 수익 차 ≈ 0.4 → G ≤ 0.4. 1차 트레이스: 25스텝 수익 격차 Δ의 표준편차가 속도 0.3/0.6에서 0.02/0.025, **속도 0.9에서 0.163** (평균 −0.335, 약속 1.06의 31 % 과대). σ_Δ·√(2 ln 3600) ≈ 0.163 × 4.0 ≈ 0.66 > 0.4 → **속도 0.9에서는 선택 편향이 약속 이득을 넘을 수 있고, 0.3/0.6에서는 (0.08~0.1 ≪ 0.4) 그렇지 않다.** S0-1′ 예측을 구체화: go1_ctx 마찰 0.15의 계획기 해악은 속도 0.9에 집중되고 0.3/0.6에서는 없다. (후보 간 Δ는 시간 축 Δ보다 상관이 커서 유효 K가 작다 → 0.66은 상한.)

**명제 2 (게이트의 가치 = 두 커버리지의 분리).** 게이트 w∈{0,1}: w=1이면 a*, 아니면 a_π. prior 대비 이득 E[w·(G − B)]. 최적 게이트는 w = 1[G > B]. G는 계획기가 스스로 아는 양이고 B만 예측하면 된다. 그러나 G > B인 상태가 **존재해야** 이득이 있다. G가 큰 상태 = prior가 못 하는 상태; B가 큰 상태 = 모델이 틀리는 상태. 둘 다 같은 시뮬 데이터의 커버리지에서 오므로 **제로샷 넓은 모델에서는 G와 B가 함께 커서 게이트 ≈ prior만**으로 수렴할 가능성이 높다. 반면 **실데이터로 동역학을 적응한 뒤**에는 모델은 맞고(B↓) prior는 시뮬 그대로(G↑)라 G > B 영역이 생긴다 — SimDist 하드웨어 결과(적응 후 계획기 > BC prior)와 설계 3 관문 1(oracle prior −60 %)이 그 증거. 그리고 L3의 망각(마찰 적응 후 모터 0.4: 0.27 → 0.77)은 정확히 "적응으로 모델이 틀려진 축에서 B가 커진" 경우라, 게이트가 그 손해를 prior로 막을 수 있다. → **게이트의 주 무대는 제로샷이 아니라 적응 후**이고, 이것이 A(망각)와 B(신뢰)를 한 논문에 묶는 고리다. 0단계에 **적응 모델 한 쌍**(go1_ctx_friction0.15_dyn_b45000_term, 로컬 보유)의 prior만 대 계획기를 추가한다(§1 보조 표에 추가 등록, 아래).

**명제 3 (자기 오차로 B를 예측할 수 있는 조건).** Δ ≈ Σ_i γ^i ∇V·(ẑ_{t+i} − z_{t+i}) (1차 근사). 과거 1스텝 오차 e_s = ẑ_{s+1|s} − z_{s+1}가 미래 오차와 상관이 있어야 한다(물리가 수 초 동안 일정하고 오차가 상태에 대해 매끄러울 때). 1차 트레이스: 1스텝 오차 노름의 자기상관 lag 1/5/25/100 = **0.88/0.60/0.58/0.42** (지속적), **과거 25스텝 평균 오차 노름과 미래 25스텝 수익 격차의 상관 −0.64**(n = 88k; 오차가 크면 더 과대 약속), 넘어짐 전 100스텝의 오차 노름 1.67 대 평소 1.02, 격차 −0.59 대 −0.15. → **S0-2의 핵심 전제(과거 오차가 미래 격차·위험을 예측)는 이 데이터에서 이미 성립 방향.** 설계 7의 노름 임계 게이트가 실패한 이유로 남는 가설: (i) 노름은 부호(∇V 방향)를 버린다, (ii) 임계가 "평소의 3배"라 발동이 드물었다(발동률 미기록). 학습된 프로브는 (i)를 고친다. 주의: 1스텝 오차 노름 1.03은 "변화 없음" 예측의 오차 1.07과 거의 같다(모델의 1스텝 예측력이 약함) — 신호는 작고 지속성에서 온다.

**명제 4 (③의 근거 = 터미널 가치의 체계적 편향).** 지평 0.5 s ≪ 넘어짐 리드타임 2~4 s이므로 Ĵ는 V̂(ẑ_{t+T})가 좌우한다. V̂는 전문가 가치 V^e(전문가가 이어 간다는 가정)이고 실제 지속은 prior/계획기이므로 편향 V^e − V^π는 잡음이 아니라 체계적이다. 1차 트레이스: V̂(ẑ_{t+25})와 실현 200스텝 수익의 Spearman **0.36** → 터미널 가치가 미래를 약하게만 순서 매긴다. ③(prior 지속 결과 헤드)은 이 편향을 제거하는 것이고, 라벨은 트레이스에서 공짜로 나온다.

**명제 5 (④의 지연).** 계획 비율 ρ일 때 평균 지연 ≈ ρ·48 ms + (1−ρ)·3 ms. ρ = 0.2면 12 ms → 3060에서도 50 Hz.

**실패 양식과 대응**
- 과거 오차와 미래 격차의 상관이 조건·모델에 따라 사라짐(명제 3 불성립) → ①② 기각. 0단계 S0-2가 판정.
- 제로샷에서 G와 B가 완전히 결합(명제 2) → 게이트 = prior만. 적응 모델 쌍에서 판정; 거기서도 없으면 ④ 기각.
- 후보 간 Δ 상관이 커서 유효 K ≈ 1이면 선택 편향이 작고 계획기 해악은 다른 원인(지평·prior 배치) → 레짐 지도는 유지, 메커니즘 설명만 바뀜.

**0단계 추가 등록 (명제 2에 따라)**: 로컬 보조에 적응 모델 `go1_ctx_friction0.15_dyn_b45000_term`의 prior만 대 계획기를 마찰 0.15·모터 0.4에 추가(4런, 트레이스). 예측: 마찰 0.15에서 계획기 ≤ prior만(적응으로 B↓, 계획이 돕는다), 모터 0.4에서 계획기 > prior만(망각으로 B↑, 계획이 해친다). 둘 다 성립하면 게이트의 존재 이유가 한 모델 안에서 증명된다.

# 설계 문서 14: 계획은 언제 돕는가 — 자기 예측 오차로 상상의 신뢰를 정하는 월드모델 (2026-11-06)

사용자 결정(2026-11-06): 맥락 슬롯(설계 13)·식별 후 재학습(설계 5~12) 계열을 접고 새 주제로. 문헌 조사 `reports/월드모델 계획 연구방향 재설정.md`(공통 미해결 문제: 계획기의 모델 오차 착취, 예측은 되는데 계획엔 못 씀, prior/샘플 배치가 병목, 실데이터 적응의 망각). 주제 한 문장:

> 시뮬 사전학습 월드모델 위의 샘플링 계획기는 prior가 넓어질수록 평균적으로 해가 되며, 계획기가 자기 상상을 얼마나 믿을지를 **모델 자신의 과거 예측 오차**(상상 − 실현)에서 학습한 신호로 정하면(결과·수익 보정 + 계획/prior 게이트) 실데이터 없이 해 없이 이득만 남는다.

구조(목표): SimDist 코어(인코더·이력 토큰·청크 동역학·보상·가치·prior) 그대로 + ① 자기 오차 토큰(지난 H스텝의 예측 잠재·보상 − 실현을 이력 인코더에 추가) ② 실현 수익·결과 헤드(오차 토큰 조건, 분위수) + 신뢰 가중치 w ③ prior 지속 결과 헤드(2~4초 리드타임) ④ 요구 시 계획 게이트(w 높으면 prior 실행, 낮으면 MPPI + ②를 터미널로). 코어는 얼리고 ①②③만 2단계 "자기 굴림" 데이터로 학습.

## 0. 실험 전 점검 (2026-11-06, 돌리기 전에 적음)

이미 있는 증거:
- 전제 "넓은 prior 위에서 계획기가 해롭다"는 **모델에 따라 다르다**. 짝지은 비교(18런, 부트스트랩 CI): go1_ctx 모터 0.4에서 prior만 − 계획기 = 넘어짐 −0.17 [−0.32, −0.03], 전진 +19 m [+10, +29] → 계획기가 해롭다. targethead 모터 0.4: +0.08 [−0.03, +0.19], 전진 −10 [−23, +0.4] → 차이 없음/계획기 약간 유리. **go1_broadwm은 prior만 숫자가 없다.**
- 설계 7 X2: 한 스텝 잠재 예측 오차가 이동 중앙값의 3배를 넘으면 prior로 폴백하는 게이트 → 효과 없음(넘어짐 비 0.92 [0.69, 1.25]). **원시 예측 오차는 신뢰 신호로 부족**. 살아남으려면 오차 창에서 학습한 신호가 원시 오차·상태 이력보다 확실히 나아야 한다.
- 설계 13: 참 물리(oracle ψ)를 줘도 계획기는 대조군 수준 → ①의 "동역학 테스트 시 보정" 역할은 기대가 낮다(25 %). "좁은 모델 + ① ≥ 넓은 모델" 주장은 내린다. ①의 역할은 ②④의 입력.
- 설계 3 명제 6: 넘어짐 4초 전 수익 하락 29 %, 후보 간 수익 차 0.4 → 리드타임 ≫ 지평(0.5 s). ③의 근거.
- 문헌(저희 측정 아님): 결과 라벨 헤드 AUC 0.97 대 동역학 불확실성 0.60(Wang 2026, 2D); 불확실성 패널티는 충돌을 늘림(26→34 %).

구성요소별 성공 확률(제 추정): ① 오차 토큰이 변화·위험을 읽음 55 %; ② 실현 수익 헤드 + 하위 분위수로 계획기 해악 제거 50 %; ③ 추가 이득 35 %; ④ "prior만보다 나쁘지 않음" 70 %, "어딘가에서 둘 다 이김" 40 %. 방법 논문 성립 35~45 %, 레짐 지도 + 신뢰 신호 분석 포함 성립 ~70 %. → 전체 체인 대신 **0단계로 전제를 먼저 판정**.

## 1. 0단계 (사전 등록; 드라이버 `scripts/sim2sim/stage13_trust0.sh`, gpu4 4 GPU; 결과 `results/stage13/eval_trust0.csv`, 트레이스 `/data1/cjkim/stage13/*.npz`)

모든 실행에서 매 스텝 기록(`output.trace_npz`): z_t, 실행 계획에 대한 예측 잠재(25×64)·보상·가치, 실현 보상, 넘어짐, 리셋. 고친 평가기(6시드 × 3속도, 5000스텝, 100 s).

| 실행 | 모델 | 조건 |
|---|---|---|
| T_broadwm_prior (prior만) | go1_broadwm | 정상, 모터 0.4, 모터 0.5, 마찰 0.15, 질량 +3 |
| T_broadwm_planner (MPPI 450×8) | go1_broadwm | 정상, 모터 0.4, 마찰 0.15, 질량 +3 |
| T_paper_prior / T_paper_planner | go1_paper (좁은 DR) | 정상·모터 0.4·마찰 0.15 / 모터 0.4·마찰 0.15 |

**예측 (전부 실험 전)**
- **S0-1 전제(계획기 해악)**: go1_broadwm에서 변화 조건(모터 0.4·마찰 0.15·질량 +3) 중 **하나 이상**에서 계획기 넘어짐 ≥ prior만 (짝지은 차이 CI가 0 제외) 또는 전진 거리 CI가 0 제외로 prior만 우세. 정상에서는 둘이 같음(넘어짐 0, 보상 차 ≤ 0.002).
  - 성립 → 게이트에 동기 있음. 불성립(전 조건에서 계획기가 같거나 좋음) → "계획기 해악"은 go1_ctx 특이 현상; 논문 질문을 "언제 계획이 돕는가"의 레짐 지도 + 신뢰 신호를 **적응 트리거**로 쓰는 쪽으로 옮긴다(게이트는 보조).
- **S0-2 신호(학습된 신뢰)**: 트레이스에서 창 길이 25의 세 가지 입력 — (a) 상태·행동 이력, (b) 원시 오차(예측 − 실현 잠재·보상), (c) (a)+(b) — 로 작은 MLP 프로브를 학습(조건 섞어 학습, 시드 분할 보류). 목표: 100스텝 안 넘어짐(AUC), 다음 25스텝 실현 수익 − 예측 수익(R²), 조건(모터/마찰/질량 분류). 예측: 변화 조건에서 (b) 또는 (c)의 넘어짐 AUC ≥ 0.8이고 (a)보다 ≥ 0.1 높음; 수익 격차 R² ≥ 0.3. 보류 축(질량 +3은 학습에서 빼고 시험)에서 AUC ≥ 0.7.
  - 성립 → ①②를 만든다. 불성립(오차가 이력보다 못하거나 AUC < 0.7) → 오차 토큰 구조 기각, 결과 헤드(라벨 학습)만 남기고 설계 재작성.
- **S0-3 레짐**: go1_paper(좁은)에서는 모터 0.4·마찰 0.15 모두 계획기 넘어짐 ≤ prior만 (SimDist 영역: 계획이 돕는다). 성립하면 "계획의 이득은 prior 폭에 따라 뒤집힌다"가 레짐 지도의 두 끝점.

**중단 기준**: S0-1과 S0-2가 **둘 다** 불성립이면 이 주제(게이트·오차 토큰)는 접고, 보고서의 A(축별 망각 없는 적응)로 간다. 하나만 성립하면 성립한 쪽으로 설계를 다시 등록한다.

**비용**: 14런 × 20~50분, 4 GPU ≈ 2~3 h. 트레이스 1런 ≈ 300 MB (/data1).

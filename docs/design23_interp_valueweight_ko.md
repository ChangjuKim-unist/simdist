# 설계 23: 적응 가중치 보간과 종단 가치 가중 (2026-11-15 등록)

사용자 결정(11/15): 학습이 필요 없는 두 아이디어(보간, 종단 가치 가중)를 먼저 돌리고, 끝나면 설계 24(사전학습된 곱셈형 맥락 + 그 잠재 위 머리, 조사 보고서 설계 A)의 이어 학습을 시작한다. 이 설계의 결과는 설계 24의 기준선·계획기 설정을 정한다.

## 0. 질문
1. **보간**: SimDist 적응(동역학 전체 fine-tuning)의 결과를 θ_α = (1 − α)·θ_사전학습 + α·θ_적응으로 일부만 적용하면, 적응 축 이득 대부분을 지키면서 다른 축 망각을 줄이는 α가 있는가? (설계 20·21: 마찰 적응 시 모터 0.4 망각, 모터 적응 시 마찰 0.15 망각)
2. **종단 가치 가중**: 계획 점수 J = Σγ^k r̂ + w·γ^{T+1} V̂에서 w를 낮추면(얼린 가치 머리에 덜 기대면) 적응된 모델의 넘어짐이 주는가? (설계 22: 얼린 가치는 약한 모터에서 표준편차 4배 낙관, 재학습한 머리는 착취됨)

## 1. 코드 사실 (2026-11-15 확인)
- 적응 체크포인트 `go1_paper_very_weak_motor_dyn_b45000_s42`, `go1_paper_friction0.15_dyn_b45000_s42`(설계 20 V1)는 `go1_paper`와 파라미터 구조가 같고(236 텐서), 바뀐 것은 `dynamics`의 52텐서뿐, scaler는 완전히 같다(최대 차 0). 보간은 전이만 섞는다.
- 구현: `scripts/simulate_batch.py`의 `model.interp_from`·`model.interp_alpha`(모든 Param을 선형 보간, 계획기 생성 전), `config/control/mppi.yaml`의 `value_weight`(배치·단일 계획기 모두 종단 할인에 곱함, 기본 1.0 = 기존과 동일).

## 2. 이론적 기대
- 보간: 3000스텝 fine-tuning은 작은 이동이라 예측 잠재가 α에 거의 선형으로 움직인다(1차 근사). 넘어짐은 예측 오차의 문턱 함수라, 적응 축에서 이득이 생기는 α*와 다른 축에서 망각이 시작되는 α'가 다르면 그 사이에 파레토 개선이 있다. 같으면 이득과 망각이 함께 움직여 개선이 없다. 사전 근거 없음, 확률 0.4.
- 가치 가중: 상수 낙관은 후보 간에 소거되므로(설계 1 명제 1) w는 후보 간 V̂ 차이의 비중만 바꾼다. 25스텝(0.5초) 밖 넘어짐은 V̂로만 보이므로 w = 0은 넘어짐을 늘릴 것으로 본다(0.6). w = 0.5가 w = 1보다 나을 확률 0.3.

## 3. 실험
- 모델: SimDist 재현 모델 `go1_paper`(사전학습), 모터 적응(M), 마찰 적응(F). 적응 시드 42.
- 보간 팔: 방향 M·F 각각 α ∈ {0, 0.25, 0.5, 0.75, 1}(α = 0은 사전학습 모델, 두 방향 공유; α = 1은 SimDist 적응). w = 1.
- 가치 가중 팔: 세 모델(사전학습, M, F) × w ∈ {0, 0.5}. w = 1은 보간 팔의 α = 0·1과 공유.
- 조건: 모터 0.4, 마찰 0.15, 정상. 평가 6시드 × 3속도 × 5000스텝(본 규모), 짝지은 부트스트랩 CI(`paired_stats.py`).
- 런: 보간 27 + 가치 가중 18 = 45런, gpu1 4장, 약 10.5시간. 구동 `scripts/sim2sim/stage23.sh`, 결과 `results/stage23/`.

## 4. 예측과 판정 (사전 등록)
기호: F(·) = 넘어짐/1000스텝(낮을수록 좋음). 적응 축 = 그 방향이 적응한 조건, 다른 축 = 나머지 비정상 조건.

**보간 통과** (방향별): α ∈ {0.25, 0.5, 0.75} 중 하나가 셋을 모두 만족
- (a) 적응 축: F_α ≤ F_0 − 0.7·(F_0 − F_1)(이득의 70 % 이상 유지)이고 F_α < F_0의 짝지은 CI가 0 제외
- (b) 다른 축: F_α ≤ F_0 + 0.5·(F_1 − F_0)(망각의 절반 이하)이고 F_α < F_1의 짝지은 CI가 0 제외
- (c) 정상 F_α ≤ 0.1
**가치 가중 통과** (모델별, M·F): w ∈ {0, 0.5} 중 하나가 적응 축에서 w = 1보다 짝지은 CI상 낮고, 다른 두 조건에서 CI상 나쁘지 않음.

| 결과 | 설계 24에 주는 것 |
|---|---|
| 보간 통과(한 방향 이상) | 설계 24의 기준선에 "SimDist 적응 + 보간(통과한 α)"을 추가. 실기용 α는 시뮬에서 정한 값으로 고정 |
| 가치 가중 통과 | 통과한 w 중 적응 축 넘어짐이 가장 낮은 값을 설계 24의 모든 계획기 평가에 기본 설정으로 사용 (w = 1 결과도 함께 보고) |
| 둘 다 기각 | 설계 24는 SimDist 적응 그대로와 w = 1로 비교 |
결과와 무관하게 설계 24는 진행한다(사용자 결정).

## 5. 한계

# 설계 문서 17: 처음부터 다시 학습한 SimDist 베이스라인 위에서 생성 후보 + q50 비교 (2026-11-10 등록, 실행 전)

## 0. 출발점 (설계 16 §7까지)
- 지금까지 "SimDist 계획기(Ĵ, 450×8) 대 생성 후보 + q50"의 비교는 전부 `go1_broadwm`(논문 레시피로 학습한 `go1_paper`에서 넓은 DR 데이터로 60k 스텝 이어 학습) 또는 `go1_ctx` 위에서 했다. 두 모델 다 이어 학습 혈통이라 "베이스라인 계획기가 약하게 나온 것이 혈통 탓(이어 학습이 가치·동역학을 반쯤 망가뜨림)인가"라는 반론이 가능하다.
- 논문 레시피 그대로 처음부터 학습한 모델은 `go1_paper`(논문 데이터셋 102M 스텝, 배치 512, 2 epoch = 369k 스텝) 하나뿐이고, 그 위에서는 생성기(논문 데이터로 학습)가 걷지 못해(설계 16 S1a 진단) 비교가 성립하지 않았다.
- 질문: **같은 넓은 DR 데이터로 SimDist 레시피를 처음부터 다시 돌린 모델(씨드 2개) 위에서도, SimDist 계획기 대 생성 후보 + q50의 우열이 그대로인가.** 베이스라인은 우리가 손대지 않은 SimDist 학습 코드(`scripts/train_model.py`)와 계획기(`control` 기본값)로 만든다.

## 1. 가설
H1 (혈통 무관): 처음부터 학습한 모델에서도 범위 밖(마찰 0.15, 모터 0.4)에서 Ĵ 계획기는 prior만보다 해롭거나 같고, 생성 후보 + q50은 넘어짐·전진에서 Ĵ 계획기를 이긴다.
H2 (베이스라인 건전성): 처음부터 학습한 모델의 prior만(정책 헤드)은 정상 조건에서 `go1_broadwm`과 같은 수준(넘어짐/1k ≤ 0.1, 보상 ≥ 0.0352)으로 걷는다. 이것이 깨지면 학습 부족이지 비교가 아니다.
H3 (생성기 씨드): 생성기 학습 씨드를 바꿔도(1, 2) `go1_broadwm` 마찰 0.15·모터 0.4 결과가 유지된다(설계 16의 생성기 씨드 1개 한계 해소).

## 2. 방법
**학습 (논문 레시피, 처음부터)**: `scripts/train_model.py data.dataset_name=2026-11-05_11-39-08 system=go1dr`, 배치 512, lr 2e-4 → 1e-4(warmup 10k, cosine), `training.max_steps=150000`, `decay_steps=150000`, `training_data_ratio 0.998`, 씨드 1·2 → `go1_scratch_s1`, `go1_scratch_s2`. 데이터셋은 `go1_broadwm`·생성기가 쓴 그 넓은 DR 데이터(384 env × 50000 스텝, 17.4M 창, 전문가 비율 0.61, 논문과 같은 혼합: 전문가 0.5 + 비전문가 11개 + 행동 잡음).
- 스텝 수 근거: 논문은 102M 창에 2 epoch = 369k 스텝. 이 데이터(17.4M 창)에 2 epoch이면 68k 스텝이라 학습 부족 위험이 있어 150k(약 4.4 epoch)로 둔다. `go1_broadwm`의 총 스텝은 369k + 60k = 429k.
- 비상 규칙(실행 전 등록): 2080 Ti 11 GB에 배치 512가 안 들어가면 배치 256·300k 스텝(같은 샘플 수)으로 바꾸고 기록한다.
**베이스라인 (SimDist)**: 그 모델의 정책 헤드 = prior, `control` 기본값(450 샘플, 8 반복, Ĵ 점수) = 논문 계획기. 설정 수정 없음.
**우리 방법**: 생성 후보(`results/stage15/gen_broad.npz`, 설계 16과 같은 생성기 — 데이터만으로 학습되어 월드모델과 독립) + 보정 헤드 q50. 헤드는 설계 15 레시피 그대로 새 모델의 Ĵ 계획기 자기 롤아웃 트레이스(15 조건)로 보류 축별(noF/noM/noA) 학습.
**평가**: 설계 14~16과 같은 18로봇(속도 0.3/0.6/0.9 × 씨드 11–16) × 5000스텝, 넘어짐/1k·보상/스텝·전진 m, 짝지은 95 % CI(`paired_stats.py`).

## 3. 사전 등록 기준
R0 **베이스라인 건전성 (H2)**: 각 씨드의 prior만 정상 조건 넘어짐/1k ≤ 0.1, 보상 ≥ 0.0352. 실패한 씨드는 베이스라인으로 쓰지 않고 "학습 부족"으로 보고(스텝을 늘린 재학습은 별도 등록).
R1 **헤드 건전성 (설계 15 C1(a)(b))**: 보류 축 창에서 Spearman(q50) ≥ Spearman(Ĵ), MSE 비 ≤ 0.7. 축이 실패하면 그 축의 gen + q50 결과는 기록하되 "판정 불가"로 두고, gen + Ĵ(헤드 없음)와 Ĵ 계획기의 비교만 본다.
R2 **핵심 (H1)**, 씨드별·조건별(마찰 0.15, 모터 0.4): gen + q50 대 Ĵ 계획기 — 넘어짐/1k 차이의 CI가 0을 제외하고 낮거나 둘 다 ≤ 0.1, **그리고** 전진 m가 Ĵ 이상(CI). 두 씨드 × 두 조건 4칸 중 4칸 성립이어야 "확실".
R3 **범위 안 무해**: 정상·질량 3에서 gen + q50 넘어짐 ≤ prior만 + 0.1, 전진 ≥ prior만 − 2 m.
R4 **prior만 대비 (부차)**: gen + q50 보상 ≥ prior만(CI), 넘어짐 ≤ prior만 + CI.
R5 **혈통 진단**: 처음부터 학습한 모델의 Ĵ 계획기 마찰 0.15 넘어짐이 ≤ 0.1이면 "이어 학습 혈통이 베이스라인을 약하게 했다"로 기록하고 설계 16의 Ĵ 수치(0.47)를 주장에서 뺀다. 0.2–1.0이면 계획기 해악은 구조적.
R6 **생성기 씨드 (H3)**: `go1_broadwm`에서 씨드 1·2 생성기 + q50이 마찰 0.15·모터 0.4 모두 넘어짐 ≤ 0.1, 전진 ≥ 50 m.
G0(d) **생성기 온라인 검사** (설계 16 S1a 진단에서 추가): `gen_broad` 평균 계획만 실행(반복 0)이 `go1_broadwm` 마찰 0.15·모터 0.4에서 prior만 + 0.1 이내(0.03 / 0.46 기준). 이 검사를 실제로 돌린 적이 없어 여기서 처음 돌린다.

**판정 규칙**: R0 ∧ R1 ∧ R2(4/4) ∧ R3 → "혈통과 무관하게 성립"이라 적고 초록에 처음부터 학습한 모델 수치를 쓴다. R2 3/4 이하 → 어느 칸이 깨졌는지와 씨드 간 차이를 그대로 적고 "씨드 민감" 또는 "조건 민감"으로 분류한다. R0 실패 → 비교 자체 무효, 스텝 늘린 재학습 등록. R5 ≤ 0.1 → 설계 16 베이스라인 수치 폐기.

**예측** (실행 전): R0 85 %. R1 세 축 모두 70 %. R2 4/4 60 %(깨진다면 모터 0.4 넘어짐 칸: 처음부터 학습한 모델은 prior 자체가 모터 0.4에서 더 잘 걸어 차이가 CI 안에 들 가능성). R5 Ĵ 마찰 0.15 넘어짐 0.2–1.0 60 %, ≤ 0.1 15 %. R6 90 %. G0(d) 90 %.

## 5. 미리 적는 한계
- 처음부터 학습이어도 데이터는 같은 넓은 DR 데이터다. "논문 데이터(좁은 DR)로 처음부터"는 `go1_paper`가 이미 그 경우이고 그 위에서는 생성기가 걷지 않아(설계 16 S1a) 비교 불가. 이 문서는 혈통(이어 학습) 반론만 닫는다.
- 150k 스텝은 논문의 369k보다 적다. R0이 성립하면 "걷는 모델"로서 충분하다고 보지만 절대 보상은 `go1_broadwm`보다 낮을 수 있다. 그래서 비교는 같은 모델 위 쌍대 비교만 한다.
- 헤드는 모델마다 새로 학습하므로 설계 15 헤드와 수치가 다르다. 생성기는 모델과 독립이라 그대로 쓴다(G0(d)로 그 생성기의 온라인 건전성을 처음 확인).
- 씨드 2개는 "학습 씨드 민감도"의 최소 표본이다. 둘이 갈리면 결론을 내리지 않고 셋째 씨드를 등록한다.

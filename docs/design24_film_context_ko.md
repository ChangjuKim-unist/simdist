# 설계 24: 사전학습된 곱셈형 맥락 — 에피소드별 ξ를 함께 학습하고, 적응 때 ξ만 맞춘다 (2026-11-15 등록)

사용자 결정(11/15): 설계 23(보간·종단 가치 가중)이 끝나면 이 설계의 이어 학습을 시작한다. 조사 보고서(`reports/적응형 세계모델 구조 아이디어 조사.md`) §4.1 설계 A의 구현이다.

## 0. 가설 (H1)
저용량 적응이 실패한 것(설계 13·20·21)은 갱신한 자리가 사전학습 때 동역학 변화를 흡수하도록 훈련된 적이 없기 때문이다. 사전학습(이어 학습)에서 **에피소드마다 8차원 ξ_e가 전이를 곱셈 변조(FiLM)하도록 ξ_e와 망을 함께 학습**하면, 적응 때 실데이터 15분으로 ξ만 맞추는 것이 전이 전체 fine-tuning(SimDist)의 이득을 상당 부분 내면서 다른 축 망각은 적다.

## 1. 앞선 실패와 무엇이 다른가
| | 설계 13 (맥락 슬롯) | 설계 21 (슬롯 최적화) | 설계 24 |
|---|---|---|---|
| ξ를 정하는 방법 | 25스텝 이력에서 추론 | 설계 13 슬롯을 사후 최적화 | **에피소드 전체로 자유 최적화(auto-decoder)**, 학습 때와 적응 때 같은 방식 |
| 결합 | z_t 토큰에 덧셈 | 같음 | 전이 6개 LayerNorm 뒤 곱셈·덧셈(FiLM) |
| 슬롯이 가진 새 정보 | 없음: 전이가 이미 같은 이력을 봄(설계 21: 참값을 넣어도 예측 오차가 안 줄어듦) | 없음 | 있음: 이력으로 식별 안 되는 물리(설계 5: 25스텝 이력의 모터 probe R² 0.004)를 에피소드 전체에서 가져옴 |
| 머리 | 슬롯과 함께 학습 | 그대로 | 이어 학습 동안 ξ_e가 만든 예측 잠재 위에서 학습 → ξ를 맞춘 뒤의 잠재가 머리의 학습 분포 안(설계 22 교훈) |
| 데이터 | 넓은 DR(계획기가 정책보다 나쁨) | 같음 | 논문 DR 부분집합(SimDist 재현 영역: 적응한 계획기가 정책보다 나음) |

## 2. 구현 (2026-11-15, 코드 확인·테스트 전)
- `simdist/modeling/modules.py`: `TransformerDecoderLayer`에 film (B, 3, 2, D) 인자, 세 LayerNorm 출력에 y·(1+γ)+β. 없으면 기존과 동일.
- `simdist/modeling/models.py`: `film_proj` = Linear(8 → 2층 × 3 × 2 × 64 = 768), **영 초기화**(시작 시 원래 모델과 같음); `xi_table` (8192 × 8) N(0, 1) 초기화; 입력 키 `xi`(없으면 0).
- `simdist/modeling/losses.py` `WorldModelLoss`: 창의 `episode_id`로 ξ_e를 찾아 넣고, 사전 항 `xi_prior` = 평균 ‖ξ_e‖² (가중 0.01).
- `simdist/modeling/trainer.py`: `adapt.film`(dim 8, n_episodes, xi_lr 0.01 고정 Adam, 나머지는 기존 스케줄).
- 데이터: `scripts/sim2sim/stage24_subset.py` — 논문 사전학습 데이터(131,616 에피소드)에서 창 200개 이상인 에피소드 8192개를 무작위(시드 0)로 뽑아 `paper_sub8192`(약 720만 스텝, 680만 창)와 스텝별 `episode_id.hdf5`를 만든다. 논문 데이터에는 환경 번호·물리 라벨이 없어 환경별 ξ는 불가.
- 적응: `scripts/sim2sim/stage24_xi_fit.py` — 모든 가중치 얼리고 ξ(8)만 잠재 예측 오차 + 0.01‖ξ‖²로 Adam lr 0.05, 1000스텝, ξ = 0에서 시작. 계획기는 `sim.xi_json`.
- 축 범위: 논문 DR은 발 마찰 0.2~1.2·추가 질량(환경 시작 시), 관절 게인·관절 마찰(에피소드마다)을 무작위화하고 **모터 세기는 무작위화하지 않는다**. 따라서 ξ에는 마찰 방향은 학습되고 모터 방향은 없을 것으로 본다. 모터 방향은 H1의 반증 검사로 쓴다.

## 3. 학습 (gpu1, 설계 23 종료 후)

## 4. 관문 0 (오프라인, 약 30분)
- 사용 여부: 부분집합 창 4096개에서 자기 ξ_e 대 ξ = 0의 잠재 예측 MSE 상대 개선. **2 % 미만이면 슬롯이 쓰이지 않은 것이므로 폐루프를 돌리지 않고** 병목형(이력 정보가 ξ로만 전이에 들어가는 구조)으로 넘어간다.
- 적응 데이터(마찰 0.15·모터 0.4, 각 15분 = `sim2sim_*_go1_paper_b45000`)에서 ξ 맞춤, held-out(뒤 10 %) 잠재 MSE를 ξ = 0, 맞춘 ξ, 대조군의 SimDist 적응과 비교(기록, 판정은 폐루프).

## 5. 폐루프 (6시드 × 3속도 × 5000스텝, 짝지은 CI)
SimDist 적응 = 동역학 전체 fine-tuning 3000스텝(설계 20 V1 레시피), 같은 15분 데이터.
| 팔 | 모델 | 적응 |
|---|---|---|
| A | 대조군 | 없음 |
| B | 대조군 | SimDist 적응 (마찰 / 모터) |
| C | FiLM | ξ = 0 |
| D | FiLM | **맞춘 ξ** (마찰 / 모터), 세 조건 모두 같은 ξ(조건 전환 없음 = SimDist와 같은 조건) |
| E | FiLM | SimDist 적응, ξ = 0 |
조건: 마찰 0.15, 모터 0.4, 정상. 학습 시드 42로 전 팔(24런), 시드 43으로 B·D의 적응 축(4런). 정책 헤드만 실행한 참고값(A·C, 3조건)도 기록. 약 7시간.
설계 23 결과 반영(사전 등록): 종단 가치 가중이 통과하면 모든 팔을 그 w로 평가(w = 1은 B·D의 마찰 0.15·모터 0.4에서 함께 보고). 구동 `scripts/sim2sim/stage24.sh`: 평가 단계는 `results/stage24/planner_w.txt`(설계 23 분석 후 기록)를 기다리고, `interp_alpha.txt`가 있으면 보간 팔을 더한다. 보간이 통과하면 "B + 보간" 팔을 추가.

## 6. 예측과 판정 (넘어짐/1000스텝, 낮을수록 좋음)
| # | 예측 | 확률 |
|---|---|---|
| P0 | 사용 여부 상대 개선 ≥ 5 % | 0.6 |
| P1 | 마찰 데이터: 맞춘 ξ의 held-out MSE 감소가 SimDist 적응 감소의 50 % 이상; 모터는 50 % 미만 | 0.5 |
| P2 (주) | 마찰 방향: D의 마찰 0.15가 B보다 0.1 이상 나쁘지 않고(비열등), D의 모터 0.4가 B의 모터 0.4보다 CI상 낮음(망각 감소) | 0.35 |
| P3 | 모터 방향: D가 A 대비 모터 0.4 개선을 B 개선의 50 % 미만만 냄(학습되지 않은 방향은 ξ로 안 됨) | 0.6 |
| P4 | 정상: D ≤ 0.1, C가 A보다 CI상 나쁘지 않음 | 0.7 |

# 설계 35: 행동 쪽 적응을 만들기 전의 확인 다섯 개 (등록 2026-11-21)

## 1. 질문

설계 34 조건(정책은 걷지만 성능이 떨어지는 수준)에서 "행동은 시뮬레이션에서 미리 만든 head 묶음 중 실제로 잰 점수로 고르고, dynamics는 replay fine-tuning으로 고친다"는 방법(reports/중간 난이도 조건 적응 아이디어.md §4)을 만들 근거가 있는가.

그 방법은 두 전제에 달려 있다. 둘 다 아직 확인되지 않았다.

1. 적응한 planner에도 행동으로 메울 여지가 남아 있다 (평가기의 추종 편향과 적분 고리로 없어지는 부분을 빼고도).
2. 그 조건을 모르고 평소 물리에서 만든 다른 행동이 그 조건에서 실제로 낫다.

배경: 2026-11-20 조사와 반박 검토(research_notes/중간 난이도 조건 적응 아이디어/R1, R2). 특히 평가기의 바깥 고리가 주는 속도 명령은 `kx × 위치 오차`라서, 느려진 로봇은 목표 속도로 걸으면서도 명령과 속도의 일정한 차이만큼 추종 보상을 잃는다(simdist/rl/go2_mdp.py:725-730, scripts/simulate_batch.py `_update_command`). 설계 34 선별 단계 기준, 끄는 짐·한 다리 약화의 보상 손실 중 48–80 %가 이 편향이었다(정적 계산, 등록 안 함).

## 2. 조건과 모델

- 조건: 설계 34가 고른 수준 중 명령 지연을 뺀 네 개. 뒷다리 하나 50 % (legR50), 마찰 0.3 + 오르막 5° (slope5), 끄는 짐 20 N (tow20), 모터 전체 50 % (mot50). 지연은 설계 34 선별에서 여지가 작았고(planner 손실 2.2 %), 조사 결과 고칠 곳이 입력 특징(행동 이력 재정렬)이라 이 질문 밖이다.
- 모델: 논문 모델(go1_paper), 설계 34에서 조건마다 적응한 모델(`go1_paper_<조건>_dyn_b45000_s42`, 학습 시드 42), 논문 모델의 RL 전문가(2026-10-01_10-38-36, 4999회).
- 평가: 설계 34와 같다. 평지, 로봇 18대(속도 0.3 / 0.6 / 0.9 × 시드 11–16) × 5000스텝.

## 3. 확인 다섯 개

| | 확인 | 돌리는 것 |
|---|---|---|
| P0 | 남은 여지 (GPU 없음) | 설계 34 실행 로그로 과제 점수 S를 다시 계산. 적응한 planner의 조건 S와 평소 조건 적응 전 planner의 S 차이 |
| P1 | 적분 고리 | 모델에 주는 명령에 적분 항을 더한다(sim.cmd_ki = 0.5 /s, 축마다 크기 0.5 이하, 합은 학습 범위 [-0.5, 1.5] × [-0.5, 0.5] × [-1, 1]로 자름, 리셋 때 0). 평소 조건 적응 전 planner, 조건마다 적응한 planner, 평소·조건마다 정책만 |
| P2 | 이미 있는 head | 예전에 만든 policy head 10개(넓은 모터 DR, 식별 모터 DR 두 개, 짐 DR, 마찰 DR, 보상 가중 네 개, 넓은 DR world model의 head)를 하나씩 정책만으로, 평소와 네 조건에서. 조건마다 가장 나은 head를 적응한 dynamics의 planner에 넣어 한 번 더 |
| P3 | 전문 expert 상한 | 논문 RL 전문가를 각 조건 안에서 1500회 더 학습(1024 환경, 시드 1). 같은 길이로 평소 조건에서만 더 학습한 것(평소 연장)도 만든다. 셋 다 같은 조건에서 평가 |
| P4 | 한 가지 자세 expert | 논문 RL 전문가를 평소 조건에서 1500회 더 학습하되, 평평함 벌점의 목표만 바꾼다(투영 중력의 수평 성분 목표 (+0.15, 0), (−0.15, 0), (0, +0.15), (0, −0.15): 앞뒤 기울기 두 개, 좌우 기울기 두 개, 약 8.6°). 조건을 본 적 없이 네 조건과 평소에서 평가 |

로컬 동작 확인(결과로 쓰지 않음): 끄는 짐 20 N 한 조건, head 두 개, 150스텝 평가, RL 2회 학습으로 전체 흐름을 두 번 돌렸다. 적분 항은 150스텝 뒤 전진 축 +0.26 m/s까지 쌓였고, 조건과 자세 목표가 RL 학습 로그와 설정 파일에 들어간 것을 확인했다. 첫 시도에서 RL 체크포인트 경로가 상대 경로라 이어 학습이 실패해서 절대 경로로 고쳤다.

RL 학습은 원래 학습 장면 그대로다(거친 지형 curriculum, 무작위 명령과 방향, 원래 DR). 조건만 더한다: 다리 토크 상한, 끄는 힘, 모터 50 %, 마찰 0.3 고정 + 중력 기울임. 무작위 방향 때문에 학습 중 경사는 모든 방향의 경사이고, 평가는 +x 오르막이다.

실행: scripts/sim2sim/stage35.sh (gpu1, 네 GPU; gpu0은 설계 34가 끝난 뒤 합류), 점수 scripts/sim2sim/stage35_score.py. 코드: sim.cmd_ki (scripts/simulate_batch.py), RL 학습의 조건 연결 (simdist/rl/conditions.py `ConditionEnvWrapper`, `SIMDIST_COND`), 자세 목표 (simdist/rl/go2_mdp.py `flat_orientation_target_l2`, `GO1_STYLE_GRAV`), RL 체크포인트 위치 (`SIMDIST_RL_DIR`, gpu1 루트 디스크가 차 있음), expert 실행의 단계별 진단 기록.

실행 메모 (결과를 보기 전, 2026-11-21 05시): gpu1의 첫 실행은 결과 없이 멈췄다. 루트 디스크가 Isaac 캐시로 0바이트가 됐고, gpu1의 RTX 2080 Ti에서는 RL 학습이 지면 높이 센서 준비 단계에서 Warp 메모리 부족으로 실패했다(1024·768·512 환경 모두, Warp 메모리 풀을 꺼도 같음). 지금까지의 RL 학습은 모두 로컬 RTX 3060에서 했다. 그래서 RL 학습 9개만 로컬에서 같은 설정(1024 환경, 시드 1, 1500회)으로 돌리고(scripts/sim2sim/stage35_rl_local.sh), 끝난 것부터 gpu1로 옮겨 평가한다(stage35.sh `RL_REMOTE=1`). 확인 내용, 점수, 기준은 바꾸지 않았다.

## 4. 점수와 기준 (실행 전 고정)

**과제 점수 S** (스텝마다, 걷는 중 = 리셋 뒤 300스텝 이후, 리셋 중 제외):

S = dt × [1.5 · exp(−((vx − v*)² + vy²) / 0.25) + 0.75 · exp(−ωz² / 0.25)] + 다섯 벌점 항(수직 속도, 롤·피치 각속도, 토크, 관절 가속도, 행동 변화율; 등록된 보상의 가중치 그대로)

- v* = 그 로봇의 목표 속도(바깥 고리의 명령이 아님), 몸통 좌표 속도. 그래서 S에는 추종 편향이 없다.
- 걸음 패턴, 발 높이, 평평함, 고관절 편차 항은 S에서 뺀다(자세를 바꾸는 행동이 그 항 때문에 불리해지지 않도록). 등록된 보상과 이 항들은 따로 보고한다.
- 넘어짐은 S에 넣지 않고 1000스텝당 수로 따로 본다.
- 비교는 로봇 짝(같은 속도·시드), 95 % 구간은 로봇 18대 bootstrap 5000번.

**"도움이 된다"**: S 변화 ≥ 기준 %이고 구간 하한 > 0, 또는 전체 넘어짐이 0.7배 이하로, 1000스텝당 0.3 이상 줄고 S가 −2 % 위.

| 확인 | 판정 (변화량은 그 줄의 평소 기준 S 대비 %) |
|---|---|
| P0 | 적응한 planner의 손실 = (평소 적응 전 planner S − 조건 적응한 planner S)가 8 % 이상인 조건만 "여지 있음" |
| P1 | 적분 고리를 켠 채 같은 손실이 8 % 미만인 조건이 넷 중 셋 이상이면 **방법 개발 보류**. 적분 고리는 적응한 planner에서 네 조건 중 셋 이상 S를 1 % 넘게 깎지 않고 평소에서도 1 % 넘게 깎지 않으면 이후 모든 비교의 기본에 넣는다 |
| P2 | head 하나라도 정책만 비교(같은 조건의 논문 head 대비)에서 기준 5 %로 도움이 되면 "시뮬에서 만든 다른 행동이 통한 조건"으로 기록. 어느 조건에서도 없으면 전제 2에 불리한 증거(혼자서는 중단 사유 아님) |
| P3 | 여지 = 전문 expert S − (논문 전문가, 평소 연장 중 나은 쪽) S, 기준 10 %. 여지가 없는 조건이 넷 중 셋 이상이면 **이 조건들에서 행동 쪽 방법 중단** |
| P4 | 자세 expert 넷 중 하나라도 평소 연장 대비 기준 5 %로 도움이 되는 조건이 둘 이상이고, 도움이 되는 자세 중 평소 조건 S 손실이 3 % 이하인 것이 있으면 통과. 아니면 **head 묶음 방법 중단** |

## 5. 예측

- Q1 (P0). 손실 8 % 이상은 끄는 짐, 오르막, 모터 50 %에서 나오고, 뒷다리 50 %는 8 % 미만이다.
- Q2 (P1). 적분 고리는 S를 어느 조건에서도 3 % 넘게 바꾸지 않는다(편향은 S가 아니라 등록된 보상에 있으므로). 등록된 보상은 끄는 짐에서 10 % 넘게 오른다.
- Q3 (P2). 모터 50 %에서만 도움이 되는 head가 나온다(모터 DR로 만든 head들). 다른 세 조건에서는 없다.
- Q4 (P3). 여지 10 % 이상은 끄는 짐, 오르막, 모터 50 %에서 나오고 뒷다리 50 %에서는 안 나온다.
- Q5 (P4). 앞으로 기울인 자세가 끄는 짐과 오르막에서 도움이 되고 평소 손실은 3 % 이하라서 통과한다.

## 7. 한계

- 적응한 모델은 학습 시드 하나(42). P3·P4의 전문가는 학습 시드 하나(1). 이번 확인은 방향을 가르는 용도이고, 방법 비교는 시드를 늘려 다시 한다.
- P2의 head들은 예전 heads-filter 버그(출력층 고정) 상태로 학습됐고, prior만 바뀌고 value는 논문 모델 것이 그대로다(짝이 맞지 않음).
- P3·P4는 특권 정보를 받는 RL 전문가끼리의 비교라서, world model planner가 실제로 얻을 수 있는 몫보다 크다(상한).
- 학습 장면(거친 지형, 무작위 방향)과 평가 장면(평지, 직진)이 다르다. 경사는 학습에서 모든 방향이다.
- 1500회 추가 학습은 걸음새를 크게 재구성하기에는 짧을 수 있다(작은 행동 분산에서 이어 학습). 여지를 작게 볼 위험이 있다.
- 자세 목표는 몸통 기울기만이다. 걸음 주기·디딤 비율은 위상 시계가 다섯 곳에 묶여 있어 이번에는 하지 않는다.
- 명령 보정 격자(정적 offset 18점)는 하지 않는다. 명령 보정 자체를 방법으로 쓰지 않기로 해서 판정에 필요 없다.

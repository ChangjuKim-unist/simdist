# 설계 문서 15 — 자기 기록으로 보정한 계획기 점수 (calibrated planner score)

작성 2026-11-07 21:00 (실험 전). 전제는 설계 14 §3–4의 결과다: 계획 해악은 탐색 강도(반복 수)에 비례하고(0.31/0.47/7.62), 적응은 축을 옮길 뿐이며, 자기 오차 토큰은 이력보다 나을 게 없다. 사용자 결정(11/7): 손잡이 조절(반복 수 게이트)이 아니라 **점수 자체를 바꿔** 계획기가 모델 오차에 스스로 적응하게 한다. 계획기(MPPI)와 세계 모델은 그대로 둔다.

## 0. 한 줄
후보 행동열을 모델의 약속값 Ĵ가 아니라, **이 모델·이 계획기가 같은 상황에서 실제로 얻은 수익의 하위 분위수**로 매긴다. 분위수는 계획기 자신의 기록(설계 14 트레이스)에서 배운 작은 헤드가 낸다.

## 1. 지금 점수와 바꿀 점수
- 지금: Ĵ(c) = Σ_{k<25} γ^k r̂_k(c) + γ^26 V̂_25(c), γ = 0.99. 후보 c마다 상상 굴림 한 번. 상위 k개를 온도 0.25로 가중 평균.
- 바꿀 점수: q_τ(h_t, c) = 헤드가 낸 실현 25스텝 할인 수익의 τ 분위수. τ ∈ {0.5, 0.1}. 선택적으로 넘어짐 확률 p_fall(h_t, c) > p_max 인 후보는 제외.
- 헤드 입력(둘 다 계획 시점에 있는 것): 이력 h_t = [z_{t-24..t} (25×64, E로 관측 이력을 인코딩), a_{t-25..t-1} (25×12)]; 후보 c의 상상 = [r̂_{0..24} (25), V̂_24 (1), Ĵ (1), 상상 잠재의 평균·마지막 (2×64)].
- 헤드 출력: q_{0.1}, q_{0.5}, q_{0.9}, p_fall. MLP 2×256. 비용: 반복마다 472 후보 × MLP 한 번 → 지연 증가 < 1 ms.

## 2. 학습 데이터와 라벨 (전부 설계 14 트레이스, 추가 굴림 없음)
- go1_broadwm: T_(prior/계획기 × 정상·모터0.4·0.5·마찰0.15·질량3), G_(10조건 × 2), S_(전환 2) = 31런 × 5000 × 18. go1_paper 계열: T_paper 5런 + A_paper(마찰 적응·모터 적응 × 2조건 × 2) 8런. 반복 3/16 트레이스는 없다(예산 보충은 트레이스 없이 돌렸다) → 한계 §6.
- 샘플 = (런, 스텝 t, 로봇 n), 리셋 구간 제외, 보폭 1. 입력은 §1. 라벨: 실현 수익 G_t = Σ_{k<25} γ^k r_{t+k} + γ^26 V̂(z_{t+25}), 단 t+k에서 리셋(넘어짐)이 나면 그 뒤 보상과 끝단 가치는 0. 끝단 가치는 **실제로 도달한 상태**에서 모델이 낸 1스텝 가치(트레이스의 pred_values[t+25, 0])다. (수정 11/7 21:40, 실험 전: 처음 안은 끝단 가치 없이 25스텝 보상만이었는데, 그러면 Ĵ의 장기 항이 빠져 보정 계획기가 근시안이 된다. 로컬 go1_ctx 시험에서 Ĵ−G 평균 격차가 2.5 → 0.16으로 바뀐 것이 그 항의 크기다.) 넘어짐 라벨 = 100스텝 안 첫 리셋이 넘어짐(시간 초과 창은 버림).
- 손실: 핀볼(τ = 0.1/0.5/0.9) + 넘어짐 BCE. 입력 정규화는 학습 집합 기준. 시드 11–14 학습, 15–16 검증(설계 14 프로브와 같음).
- **보류 축**: 평가할 조건의 축을 통째로 뺀 헤드를 쓴다. broadwm_noF(마찰* 제외) → 마찰 0.15 평가, broadwm_noM(모터* 제외) → 모터 0.4, broadwm_noA(질량* 제외) → 질량 3, 정상은 noF. go1_paper: paper_noF, paper_noM(데이터가 얇다: T_paper + A_paper 중 해당 축 제외).
- 헤드는 모델마다 따로다(이 모델의 약속이 얼마나 지켜지는지를 배우는 것이므로). 적응 모델(A_paper*)은 기반 모델 go1_paper의 헤드를 쓴다 — 적응이 동역학만 바꿨으므로 "약속의 신뢰도"가 적응 전과 같다는 가정이고, 이 가정이 틀리면 C5가 깨진다(§6).

## 3. 사전 등록 기준과 예측
C1 **오프라인 보정 (싸다, 먼저)**: 보류 축 창에서 (a) Spearman(실현 G, q_{0.5}) ≥ Spearman(실현 G, Ĵ), (b) 약속 오차 감소 MSE(G − q_{0.5}) / MSE(G − Ĵ) ≤ 0.7, (c) 넘어짐 AUC(p_fall) ≥ 0.75.
  (수정 11/7 21:40, 실험 전: 처음 안 "Spearman +0.1, ≥ 0.5"는 끝단 가치가 빠진 라벨 기준이었다. 끝단 가치를 넣으면 Ĵ 자체의 스텝 간 순위 상관이 0.86으로 높아져(상태 차이가 순위를 지배) +0.1은 뜻이 없고, 계획기에 중요한 "같은 상태 안 후보 순위"는 트레이스로는 잴 수 없다. 그래서 오프라인 기준을 "약속 오차를 얼마나 줄이나"로 바꾼다. 로컬 go1_ctx 시험(마찰 보류, 8런): Spearman 0.893 대 0.857, MSE 비 0.66, AUC 0.73 — (a)(b) 성립, (c) 근소 미달. 이 값으로 문턱을 정했으므로 go1_broadwm 31런에서는 독립 시험이다.)
  예측: broadwm 세 보류 축 모두 (a)(b) 성립 70 %, (c) 성립 50 %.
C2 **반복 곡선 평탄화 (핵심)**: go1_broadwm 마찰 0.15, 반복 16: q_{0.1} 계획기 넘어짐/1k ≤ 0.47(= 지금 450×8 Ĵ), 즉 7.62가 무너진다. 짝지은 CI가 7.62 대비 0 제외.
  예측: 성립 55 %. 실패 양상 예상: 새 점수로 고른 후보가 헤드가 본 적 없는 행동이라(분포 이동) 헤드가 외삽 → 해악이 줄되 0.47까지는 안 감.
C3 **범위 안 이득 보존**: 모터 0.4, 450×8: q_{0.5}·q_{0.1} 계획기의 보상/스텝이 Ĵ 계획기(0.0282)의 짝지은 CI 안, 넘어짐 ≤ 0.20 + 0.1.
  예측: q_{0.5} 성립 75 %, q_{0.1} 성립 55 %(보수성 비용이 여기서 나온다).
C4 **범위 밖 해악 제거**: 마찰 0.15, 450×8: q_{0.1} 넘어짐이 prior만(0.03)의 CI 안이거나 ≤ 0.1, 전진 ≥ 45 m(Ĵ 33, prior 55).
  예측: 성립 50 %.
C5 **적응 후 반대 축**: go1_paper 마찰 적응 모델의 모터 0.4: q_{0.1} 넘어짐 ≤ prior만 3.23(Ĵ 4.14); 모터 적응 모델의 마찰 0.15: ≤ 1.16(Ĵ 5.41).
  예측: 성립 40 %(헤드 데이터가 얇고 §2 가정이 약함).
- 방법 논문 성립 조건: C1(a)(b) ∧ C2 ∧ (C3 또는 C4). C1(a)(b) 실패 → **정지**(평가 돌리지 않음; 보정은 오프라인에서조차 안 된다 → 입력을 바꿔 한 번만 재시도: 상상 잠재 전체 추가). C1 성립·C2 실패 → 분포 이동이 원인인지 확인(새 점수로 고른 후보의 Ĵ−q 분포 vs 학습 분포), 맞으면 2단계(후보를 생성형 prior에서 뽑기, 설계 16)로 간다.
- 평균 성능 질문(사용자 11/7): "q_{0.5} ≥ Ĵ 모든 조건에서(보정만으로 평균이 안 내려간다), q_{0.1} > q_{0.5} 마찰 0.15에서, q_{0.1} ≤ q_{0.5} 모터 0.4에서 조금"을 보상/스텝으로 표에 낸다. 셋을 다 돌리므로 결과를 보고 τ를 고르는 것이 아니다.

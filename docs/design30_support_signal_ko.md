# 설계 30: 지원 범위 신호와 행동 어댑터의 오프라인 확인 (2026-11-17 등록)

## 0. 배경

- 연구문제(`docs/research_problem_ko.md`): 커버리지 밖 조건에 적응하면서 이득·안전·보존을 함께 만족시키기.
- 설계 29 G1: 출발 2초 동안 두 모델의 최저 점수를 쓰는 **시간 기준** 전환은 네 시나리오 모두 불통과였다. 사전학습 모델로 되돌아가는 것은 사전학습이 그 조건을 아는 곳에서만 이득이고, 언제 되돌아갈지는 조건을 가리는 신호로 정해야 한다.
- 관련연구 조사(179편): 같은 사전학습에서 fine-tuning한 모델들은 서로 거의 다르게 예측하지 않는다는 근거가 NLP·비전에 있다. 동역학 모델에서는 측정된 적이 없다. 대안 신호는 데이터까지의 거리(VRF, SUMO), 오차 예측기(MDE), 도메인 분류기(DARC 계열), conformal 문턱(UNISafe)이다.
- 이 설계는 계획기를 바꾸기 전에, 기록 데이터만으로 두 가지를 잰다. 폐루프 실험은 여기서 통과한 것만 다음 설계에서 한다.

## 1. 질문

- **QS (신호).** "지금은 적응한 조건이 아니다"를 알려 주는 신호가 있나? 있으면 그 신호로 적응 모델과 사전학습 모델을 전환할 수 있다.
- **QA (어댑터).** 사전학습 세계모델을 고정하고 행동만 변환하는 어댑터가, 동역학 fine-tuning만큼 적응 데이터를 설명하나?

## 2. S 방법 (`scripts/sim2sim/stage30_signals.py`)

**칸** (4개): 모델 {논문, 넓은 DR} × 적응 조건 {빙판(마찰 0.15), 모터 40 %}.

**데이터** (모두 그 모델의 사전학습 계획기가 수집, 설계 20의 것)

| 역할 | 데이터 | 크기 |
|---|---|---|
| 적응 데이터 | 그 조건의 학습용 기록 | 45,000스텝(15분) |
| 범위 안 계획기 데이터 | 평소 조건 기록. 논문 모델은 기존, 넓은 DR 모델은 같은 방식으로 새로 수집 | 45,000스텝 |
| 자기 조건 held-out | 적응 조건의 held-out 기록 | 15,000스텝(로봇 3대 × 5000스텝) |
| 다른 데이터 held-out | 평소, 다른 범위 밖 조건(빙판 ↔ 모터 40 %), 적재 3 kg | 각 15,000스텝 |

**적응 모델 5개.** SimDist 방식(동역학만, 3000스텝) 그대로 시드만 42~46으로 바꾼다. 42·43은 설계 20의 것이고 44~46을 새로 학습한다. 시드는 배치 순서만 바꾼다. 문헌이 약하다고 예상한 바로 그 경우를 있는 그대로 잰다.

**창마다 계산** (이력 25스텝 + 기록된 미래 행동 25개)
- z = 이력 끝의 잠재, φ = [z, 다음 5개 행동 평균, 명령]
- 사전학습 모델과 적응 모델(시드 42)의 k-step 잠재 오차(25스텝 × 64차원 평균)
- 적응 모델 5개의 예측 분산

**신호** (클수록 "적응 모델을 믿을 이유가 적다")

| 이름 | 정의 | 문헌 |
|---|---|---|
| 오차 (기준선) | 적응 모델 오차 − 사전학습 오차 | 오차 기반 선택 (설계 20에서 16/16 틀림) |
| 불일치 | 적응 모델 5개의 예측 분산 | MOPO, RWM-U |
| 거리 | 표준화한 φ에서 적응 데이터의 최근접 10개까지 평균 거리 | VRF, SUMO |
| 오차 예측기 | φ → log(적응 오차 / 사전학습 오차)를 맞춘 MLP. 학습: 적응 데이터 + 범위 안 계획기 데이터 | MDE |
| 분류기 | φ → "적응 데이터가 아니다"의 확률인 MLP. 음성 예: 범위 안 계획기 데이터 | DARC 계열 |

- 각 신호는 창 하나짜리와, 같은 에피소드의 최근 50창 평균(1초, 실행 중 전환에 쓸 형태) 두 가지로 잰다. **1차 지표는 50창 평균이다.**
- 장면: 출발(에피소드 시작 뒤 25~124스텝), 걷는 중(300스텝 이후).

**판정 규칙 (split conformal)**
- held-out을 연속 500스텝 블록으로 나눠 짝수 블록은 보정, 홀수 블록은 시험에 쓴다.
- 문턱 = 자기 조건 보정 블록에서 신호의 95 % 분위수. 장면마다 따로 정한다.
- 거부율 = 다른 데이터에서 신호가 문턱을 넘는 비율. CI는 블록 부트스트랩(1000회).
- AUC(자기 조건 시험 블록 대 다른 데이터)도 함께 적는다.

**통과 기준**
- **한 칸 통과:** 걷는 중 장면에서, 다른 범위 밖 조건 거부율 ≥ 0.80이고 CI 하한 > 0.60, 그리고 자기 조건 시험 블록 거부율 ≤ 0.15.
- **QS 통과:** 같은 신호 하나가 4칸 중 3칸 이상 통과.
- 다른 범위 밖 조건을 기준으로 삼는 이유: 망각이 생기는 곳이 거기다. 평소 조건은 적응 모델로도 넘어지지 않으므로 보고만 한다.
- 출발 장면은 같은 기준으로 따로 보고한다(예측: 불통과).

**행동 지원 (서술용, 통과 기준 없음).** 자기 조건 걷는 중 창 2000개에서 미래 행동 25개에 관절별 일정한 오프셋 N(0, σ²)을 더한다(σ = 0.05, 0.1, 0.2, 0.4; 계획기가 정책에서 벗어난 크기 0.2~1.5에 맞춘 범위). 불일치·거리·예측기·분류기가 문턱을 넘는 비율을 적는다. 전환을 상태 단위로 할지 후보 단위로 할지 정하는 데 쓴다.

## 3. A 방법 (`scripts/sim2sim/stage30_adapter.py`)

- 사전학습 모델을 고정하고, 미래 행동을 a′ = g(z, a)로 바꿔 넣는다(스케일된 행동 단위, 초기값은 항등).

| 어댑터 | 형태 | 파라미터 |
|---|---|---|
| A1 | 관절별 affine: a′ = a·(1 + w) + b | 24개 |
| A2 | 상태 의존: a′ = a + MLP([z, a]), 은닉 64 × 2, 출력층 0 초기화 | 약 1만 개 |

- 손실은 fine-tuning과 같다(예측 잠재 25개와 실제 미래 잠재의 MSE). 어댑터 파라미터만 학습한다. Adam 1e-3, 3000스텝, 배치 64.
- 비교: 사전학습 그대로, 동역학 fine-tuning(설계 20, 시드 42).
- 지표: held-out k-step 잠재 오차. **회복 몫 = (사전학습 오차 − 어댑터 오차) / (사전학습 오차 − fine-tuning 오차)**, 자기 조건에서 잰다. 블록 부트스트랩.
- 다른 데이터에서는 어댑터를 켠 채의 오차 비(어댑터 / 사전학습)를 적는다. 어댑터를 끄면 사전학습 그대로라 보존은 구조상 성립하고, 이 비는 "항상 켜 두면 어떤가"를 본다.
- 칸은 S와 같은 4개다.

**통과 기준.** 논문 모델의 모터 40 %(가장 멀리 범위 밖이고 어댑터가 표현할 수 있는 유형)에서 A1 또는 A2의 회복 몫 ≥ 0.70, CI 하한 > 0.50.

- 설계 31에는 조사에서 정한 기준선(불일치 벌점만, 가치 앙상블 벌점, 두 모델 최저 점수 항상 켬, replay 비율)을 함께 넣는다.
- 통과한 신호가 둘 이상이면 통과 칸 수, 그다음 다른 범위 밖 조건 거부율 평균이 높은 것을 쓴다.

## 6. 한계 (미리 적음)

- held-out은 조건당 로봇 3대 × 5000스텝이다. 평소 조건은 에피소드가 3개뿐이라 출발 장면 표본이 작다.
- 모든 기록은 사전학습 계획기가 모았다. 전환을 건 계획기가 만드는 상태 분포는 다를 수 있다.
- 잠재 오차는 폐루프 넘어짐을 대신하지 못한다(설계 20). 이 설계의 통과는 폐루프 실험을 할 자격일 뿐이다.
- 적응 모델 5개는 시드만 다르다. 부트스트랩이나 독립 초기화 앙상블은 재지 않는다.

### 8.1 QS: 신호 (걷는 중, 50창 평균)

값 = 다른 범위 밖 조건을 거부한 비율 [95 % CI]. 괄호 = 자기 조건 시험 블록을 잘못 거부한 비율. 굵은 글씨 = 칸 통과.

| 신호 | 논문·빙판 적응 | 논문·모터 적응 | 넓은 DR·빙판 적응 | 넓은 DR·모터 적응 | 통과 칸 |
|---|---|---|---|---|---|
| 오차 (기준선) | 0.35 [0.24, 0.46] (0.06) | **1.00 [1.00, 1.00]** (0.07) | 0.30 [0.20, 0.41] (0.05) | 0.43 [0.24, 0.60] (0.07) | 1/4 |
| 불일치 | 0.42 [0.32, 0.53] (0.05) | 0.00 [0.00, 0.00] (0.04) | 0.31 [0.19, 0.43] (0.05) | 0.00 [0.00, 0.00] (0.02) | 0/4 |
| 거리 | **0.98 [0.95, 1.00]** (0.03) | 0.02 [0.00, 0.04] (0.08) | 0.39 [0.26, 0.52] (0.02) | 0.06 [0.01, 0.12] (0.02) | 1/4 |
| 오차 예측기 | **0.86 [0.80, 0.91]** (0.03) | **0.99 [0.97, 1.00]** (0.06) | 0.57 [0.46, 0.66] (0.05) | 0.12 [0.07, 0.18] (0.03) | 2/4 |
| 분류기 | 0.11 [0.05, 0.16] (0.06) | **0.99 [0.99, 1.00]** (0.01) | 0.75 [0.62, 0.87] (0.05) | 0.59 [0.43, 0.73] (0.05) | 1/4 |

- 3칸 이상 통과한 신호가 없다. 가장 나은 오차 예측기도 2칸이고 둘 다 논문 모델이다.
- 넓은 DR 모델에서는 어떤 신호도 한 칸을 통과하지 못했다(최고: 분류기 0.75, 기준 0.80).
- 출발 장면: 3칸 이상 통과한 신호 없음(오차 예측기 1칸, 분류기 1칸).
- 창 하나짜리 신호는 50창 평균보다 모두 같거나 나쁘다(통과 칸: 오차 1, 거리 1, 나머지 0).

### 8.2 QA: 행동 어댑터

회복 몫 = 어댑터가 줄인 오차 / 동역학 fine-tuning이 줄인 오차 (자기 조건 held-out, [95 % CI]).

| 칸 | A1 관절별 affine | A2 상태 의존 MLP |
|---|---|---|
| 논문·빙판 | 0.17 [0.16, 0.19] | 0.45 [0.43, 0.47] |
| **논문·모터 40 % (판정 칸)** | 0.17 [0.15, 0.19] | **0.42 [0.41, 0.44]** (기준 ≥ 0.70) |
| 넓은 DR·빙판 | 0.18 [0.17, 0.20] | 0.43 [0.40, 0.45] |
| 넓은 DR·모터 40 % | 0.14 [0.12, 0.15] | 0.42 [0.40, 0.44] |

- 불통과. 네 칸의 회복 몫이 조건 종류와 무관하게 0.42~0.45로 같다. 어댑터가 배운 것이 "모터가 약하다"가 아니라는 뜻이다.
- 논문·모터 칸에서 어댑터를 켠 채 다른 데이터에 쓰면 사전학습보다 오차가 커진다(평소 1.31배, 빙판 1.20배).

| PS5 | 출발 장면은 어떤 신호도 3칸 이상 통과 못 함 (0.7) | 성립 |
| PA1 | 논문·모터 A2 회복 몫 ≥ 0.70 (0.4) | 기각 (0.42) |
| PA2 | 같은 칸 A1 회복 몫 < 0.30 (0.7) | 성립 (0.17) |
| PA3 | 빙판 두 칸 A2 회복 몫 < 0.30 (0.6) | 기각 (0.45, 0.43) |

### 8.4 왜 안 됐나

k-step 잠재 오차(사전학습 → 적응 모델, 사전학습 계획기가 모은 held-out):

| 칸 | 자기 조건 | 다른 범위 밖 조건 | 평소 조건 |
|---|---|---|---|
| 논문·빙판 적응 | 0.054 → 0.017 | 0.167 → 0.154 | 0.046 → 0.019 |
| 논문·모터 적응 | 0.167 → 0.048 | 0.054 → 0.048 | 0.046 → 0.050 |
| 넓은 DR·빙판 적응 | 0.033 → 0.007 | 0.042 → 0.022 | 0.025 → 0.009 |
| 넓은 DR·모터 적응 | 0.042 → 0.008 | 0.033 → 0.014 | 0.025 → 0.009 |

1. **시드만 다른 적응 모델들은 서로 거의 같게 예측한다.** 불일치(0.0001~0.003)는 오차의 1~4 %다. 모터 적응 두 칸에서는 다른 조건에서 전혀 커지지 않고(거부율 0.00), 빙판 적응 두 칸에서도 거부율이 0.31~0.42에 그친다. 문헌이 NLP·비전에서 보인 위험이 동역학 모델에서도 그대로 나왔다.
2. **적응 모델은 다른 조건의 기록에서 오차가 나쁘지 않다.** 다른 범위 밖 조건 4칸 모두 사전학습보다 오차가 낮다. 그런데 폐루프에서는 바로 이 네 조합에서 넘어짐이 사전학습의 1.2~4.7배였다(설계 29). 평소·적재까지 합친 12칸에서도 11칸이 사전학습보다 낮다. 기록 데이터 위의 예측 오차로는 망각이 보이지 않는다(설계 20과 같은 불일치).
3. **신호가 한쪽 방향으로만 작동한다.** 빙판 적응 모델이 모터 40 % 데이터를 만나면 잡힌다(논문: 거리 0.98, 오차 예측기 0.86). 반대로 모터 적응 모델이 빙판 데이터를 만나면 거리 신호는 0.02다. 빙판 주행 상태는 모터 40 % 데이터가 덮는 범위 안에 있기 때문이다.
4. **넓은 DR 모델은 조건을 구분할 여지가 작다.** 이 모델에는 모터 40 %가 범위 안이고, 이력만으로는 조건 정보가 거의 없다(설계 24, 설계 29 G0). 조건 사이의 오차 차이도 작다.
5. **fine-tuning이 줄인 오차의 대부분은 조건과 무관하다.** 빙판 데이터로 적응했는데 평소 조건 오차가 59~64 % 줄었다(넓은 DR 모터 적응도 63 %). 조건에만 해당하는 변화는 논문·모터 칸뿐이다(평소 +9 %). 어댑터 회복 몫이 조건과 무관하게 0.43인 것도 같은 이유로 보인다: 어댑터도 fine-tuning도 주로 "계획기가 고르는 행동에서의 예측"을 고친다.
6. **행동 지원(서술용):** 행동에 오프셋 σ = 0.2를 더해도 신호가 문턱을 넘는 비율은 0.03~0.14다(σ = 0.4에서 0.06~0.32). 후보 단위로 "데이터 밖 행동"을 걸러 내는 용도로는 약하다.

**(b) 넘어짐이 언제 나는가** (2026-11-18 정정: 처음에는 전체 스텝으로 나눈 값을 적었다. 출발에서 자주 넘어지는 팔은 걷는 시간이 짧아 걷는 중 넘어짐이 작게 보였다. 아래는 노출 시간으로 나눈 값이다.)

- 출발 = 한 에피소드가 첫 125스텝 안에 넘어질 확률. 걷는 중 = 300스텝 이후의 넘어짐을 걷는 중 1000스텝당으로 센 값.

| 조합 | 출발에서 넘어질 확률 (사전학습 → 적응 모델) | 걷는 중 넘어짐 (사전학습 → 적응 모델) |
|---|---|---|
| 논문, 모터 적응 → 빙판 | 0.83 → 0.92 | 0.15 → 0.29 |
| 넓은 DR, 모터 적응 → 빙판 | 0.21 → 0.71 | 0.34 → 0.31 |
| 논문, 빙판 적응 → 모터 40 % | 0.29 → 0.27 | 4.68 → 7.19 |
| 넓은 DR, 빙판 적응 → 모터 40 % | 0.12 → 0.06 | 0.12 → 0.88 |

자기 조건에서의 적응 이득도 같은 방식으로 나눴다.

| 칸 | 출발에서 넘어질 확률 (사전학습 → 적응 모델) | 걷는 중 넘어짐 (사전학습 → 적응 모델) |
|---|---|---|
| 논문, 빙판 | 0.83 → 0.08 | 0.15 → 0.20 |
| 넓은 DR, 빙판 | 0.21 → 0.00 | 0.34 → 0.17 |
| 논문, 모터 40 % | 0.29 → 0.15 | 4.68 → 2.86 |
| 넓은 DR, 모터 40 % | 0.12 → 0.05 | 0.12 → 0.24 |

- 망각은 두 종류다.
  - **모터 적응 → 빙판: 출발에서 난다.** 걷는 중 차이는 작다. 모델의 예측 오차도 오르지 않는다(0.01~0.02 거부). 이력이 없는 출발에서는 어떤 신호도 쓸 수 없다.
  - **빙판 적응 → 모터 40 %: 걷는 중에 난다(논문 4.68 → 7.19, 넓은 DR 0.12 → 0.88).** 실행 중 오차로 잡힌다(0.80~0.91). 이때 정책에서 벗어난 정도도 커진다(넓은 DR 0.28 → 0.40, 논문 0.59 → 0.77).
- 적응 이득도 갈린다. 빙판 이득은 거의 전부 출발이다. 1초 램프 출발만 써도 논문 사전학습 모델의 빙판 출발 넘어짐은 0.83 → 0.05가 된다. 걷는 중 이득이 분명한 칸은 논문·모터 40 %뿐이다.
- 같은 기록을 이미 본 뒤의 관찰이므로, 이 신호를 쓰려면 새 시드의 폐루프로 등록해서 확인해야 한다.

### 8.6 결정

- §5의 "불통과 / 불통과": 상태 단위 전환과 어댑터의 폐루프 실험은 하지 않는다.
- 접는 것: 시드 앙상블 불일치(M1의 원래 형태), 행동 어댑터(M2), 기록 데이터 위의 거리·분류기 신호.
- 다음 설계에 넘기는 사실:
  1. 망각은 "출발"과 "걷는 중" 두 종류이고 처방이 다르다.
  2. 걷는 중 망각은 실행 중인 모델 자신의 예측 오차로 잡힐 가능성이 있다(등록 안 한 관찰).
  3. 출발 망각은 신호로 못 잡는다. 신호 없이 출발을 안전하게 하는 장치가 필요하다.
  4. fine-tuning 변화의 대부분은 조건과 무관하다. 이 부분은 실제 데이터 없이 시뮬레이션의 계획기 데이터로 미리 배울 수 있는지 확인할 가치가 있다.

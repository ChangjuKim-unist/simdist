# 설계 30: 지원 범위 신호와 행동 어댑터의 오프라인 확인 (2026-11-17 등록)

## 0. 배경

- 연구문제(`docs/research_problem_ko.md`): 커버리지 밖 조건에 적응하면서 이득·안전·보존을 함께 만족시키기.
- 설계 29 G1: 출발 2초 동안 두 모델의 최저 점수를 쓰는 **시간 기준** 전환은 네 시나리오 모두 불통과였다. 사전학습 모델로 되돌아가는 것은 사전학습이 그 조건을 아는 곳에서만 이득이고, 언제 되돌아갈지는 조건을 가리는 신호로 정해야 한다.
- 관련연구 조사(179편): 같은 사전학습에서 fine-tuning한 모델들은 서로 거의 다르게 예측하지 않는다는 근거가 NLP·비전에 있다. 동역학 모델에서는 측정된 적이 없다. 대안 신호는 데이터까지의 거리(VRF, SUMO), 오차 예측기(MDE), 도메인 분류기(DARC 계열), conformal 문턱(UNISafe)이다.
- 이 설계는 계획기를 바꾸기 전에, 기록 데이터만으로 두 가지를 잰다. 폐루프 실험은 여기서 통과한 것만 다음 설계에서 한다.

## 1. 질문

- **QS (신호).** "지금은 적응한 조건이 아니다"를 알려 주는 신호가 있나? 있으면 그 신호로 적응 모델과 사전학습 모델을 전환할 수 있다.
- **QA (어댑터).** 사전학습 세계모델을 고정하고 행동만 변환하는 어댑터가, 동역학 fine-tuning만큼 적응 데이터를 설명하나?

## 2. S 방법 (`scripts/sim2sim/stage30_signals.py`)

**칸** (4개): 모델 {논문, 넓은 DR} × 적응 조건 {빙판(마찰 0.15), 모터 40 %}.

**데이터** (모두 그 모델의 사전학습 계획기가 수집, 설계 20의 것)

| 역할 | 데이터 | 크기 |
|---|---|---|
| 적응 데이터 | 그 조건의 학습용 기록 | 45,000스텝(15분) |
| 범위 안 계획기 데이터 | 평소 조건 기록. 논문 모델은 기존, 넓은 DR 모델은 같은 방식으로 새로 수집 | 45,000스텝 |
| 자기 조건 held-out | 적응 조건의 held-out 기록 | 15,000스텝(로봇 3대 × 5000스텝) |
| 다른 데이터 held-out | 평소, 다른 범위 밖 조건(빙판 ↔ 모터 40 %), 적재 3 kg | 각 15,000스텝 |

**적응 모델 5개.** SimDist 방식(동역학만, 3000스텝) 그대로 시드만 42~46으로 바꾼다. 42·43은 설계 20의 것이고 44~46을 새로 학습한다. 시드는 배치 순서만 바꾼다. 문헌이 약하다고 예상한 바로 그 경우를 있는 그대로 잰다.

**창마다 계산** (이력 25스텝 + 기록된 미래 행동 25개)
- z = 이력 끝의 잠재, φ = [z, 다음 5개 행동 평균, 명령]
- 사전학습 모델과 적응 모델(시드 42)의 k-step 잠재 오차(25스텝 × 64차원 평균)
- 적응 모델 5개의 예측 분산

**신호** (클수록 "적응 모델을 믿을 이유가 적다")

| 이름 | 정의 | 문헌 |
|---|---|---|
| 오차 (기준선) | 적응 모델 오차 − 사전학습 오차 | 오차 기반 선택 (설계 20에서 16/16 틀림) |
| 불일치 | 적응 모델 5개의 예측 분산 | MOPO, RWM-U |
| 거리 | 표준화한 φ에서 적응 데이터의 최근접 10개까지 평균 거리 | VRF, SUMO |
| 오차 예측기 | φ → log(적응 오차 / 사전학습 오차)를 맞춘 MLP. 학습: 적응 데이터 + 범위 안 계획기 데이터 | MDE |
| 분류기 | φ → "적응 데이터가 아니다"의 확률인 MLP. 음성 예: 범위 안 계획기 데이터 | DARC 계열 |

- 각 신호는 창 하나짜리와, 같은 에피소드의 최근 50창 평균(1초, 실행 중 전환에 쓸 형태) 두 가지로 잰다. **1차 지표는 50창 평균이다.**
- 장면: 출발(에피소드 시작 뒤 25~124스텝), 걷는 중(300스텝 이후).

**판정 규칙 (split conformal)**
- held-out을 연속 500스텝 블록으로 나눠 짝수 블록은 보정, 홀수 블록은 시험에 쓴다.
- 문턱 = 자기 조건 보정 블록에서 신호의 95 % 분위수. 장면마다 따로 정한다.
- 거부율 = 다른 데이터에서 신호가 문턱을 넘는 비율. CI는 블록 부트스트랩(1000회).
- AUC(자기 조건 시험 블록 대 다른 데이터)도 함께 적는다.

**통과 기준**
- **한 칸 통과:** 걷는 중 장면에서, 다른 범위 밖 조건 거부율 ≥ 0.80이고 CI 하한 > 0.60, 그리고 자기 조건 시험 블록 거부율 ≤ 0.15.
- **QS 통과:** 같은 신호 하나가 4칸 중 3칸 이상 통과.
- 다른 범위 밖 조건을 기준으로 삼는 이유: 망각이 생기는 곳이 거기다. 평소 조건은 적응 모델로도 넘어지지 않으므로 보고만 한다.
- 출발 장면은 같은 기준으로 따로 보고한다(예측: 불통과).

**행동 지원 (서술용, 통과 기준 없음).** 자기 조건 걷는 중 창 2000개에서 미래 행동 25개에 관절별 일정한 오프셋 N(0, σ²)을 더한다(σ = 0.05, 0.1, 0.2, 0.4; 계획기가 정책에서 벗어난 크기 0.2~1.5에 맞춘 범위). 불일치·거리·예측기·분류기가 문턱을 넘는 비율을 적는다. 전환을 상태 단위로 할지 후보 단위로 할지 정하는 데 쓴다.

## 3. A 방법 (`scripts/sim2sim/stage30_adapter.py`)

- 사전학습 모델을 고정하고, 미래 행동을 a′ = g(z, a)로 바꿔 넣는다(스케일된 행동 단위, 초기값은 항등).

| 어댑터 | 형태 | 파라미터 |
|---|---|---|
| A1 | 관절별 affine: a′ = a·(1 + w) + b | 24개 |
| A2 | 상태 의존: a′ = a + MLP([z, a]), 은닉 64 × 2, 출력층 0 초기화 | 약 1만 개 |

- 손실은 fine-tuning과 같다(예측 잠재 25개와 실제 미래 잠재의 MSE). 어댑터 파라미터만 학습한다. Adam 1e-3, 3000스텝, 배치 64.
- 비교: 사전학습 그대로, 동역학 fine-tuning(설계 20, 시드 42).
- 지표: held-out k-step 잠재 오차. **회복 몫 = (사전학습 오차 − 어댑터 오차) / (사전학습 오차 − fine-tuning 오차)**, 자기 조건에서 잰다. 블록 부트스트랩.
- 다른 데이터에서는 어댑터를 켠 채의 오차 비(어댑터 / 사전학습)를 적는다. 어댑터를 끄면 사전학습 그대로라 보존은 구조상 성립하고, 이 비는 "항상 켜 두면 어떤가"를 본다.
- 칸은 S와 같은 4개다.

**통과 기준.** 논문 모델의 모터 40 %(가장 멀리 범위 밖이고 어댑터가 표현할 수 있는 유형)에서 A1 또는 A2의 회복 몫 ≥ 0.70, CI 하한 > 0.50.

## 4. 예측 (실행 전 고정, 괄호는 확률)

스모크 실행을 본 뒤에 적었다. 스모크는 로컬에서 논문 모델로만 돌렸고, held-out이 없어 학습용 기록을 대신 넣었다(S: 빙판 적응 한 칸·모델 2개·창 4000개, A: 모터 40 % 한 칸·300스텝). 기준은 스모크 수치와 무관하게 정했다.

| # | 예측 | 확률 |
|---|---|---|
| PS1 | 거리 신호가 QS 통과 (3칸 이상) | 0.5 |
| PS2 | 불일치 신호가 QS 통과 | 0.25 |
| PS3 | 오차 기준선이 QS 통과 | 0.2 |
| PS4 | 분류기는 평소 조건 거부율 ≥ 0.9(4칸 모두)이지만 다른 범위 밖 조건 거부율 < 0.5(3칸 이상) | 0.6 |
| PS5 | 출발 장면에서는 어떤 신호도 3칸 이상 통과하지 못함 | 0.7 |
| PA1 | 논문 모델 모터 40 %에서 A2 회복 몫 ≥ 0.70 | 0.4 |
| PA2 | 같은 칸에서 A1 회복 몫 < 0.30 (토크 배율은 행동 배율로 표현되지 않음) | 0.7 |
| PA3 | 빙판 두 칸 모두 A2 회복 몫 < 0.30 | 0.6 |

## 5. 결정 규칙

| QS | QA | 다음 (설계 31, 폐루프) |
|---|---|---|
| 통과 | 통과 | 통과한 신호로 상태 단위 전환(수용이면 적응 모델, 거부면 사전학습 모델) + 램프 출발. 모터형 조건에는 어댑터 팔 추가 |
| 통과 | 불통과 | 전환만 |
| 불통과 | 통과 | 모터형 조건의 어댑터를 폐루프로. 신호는 다른 관측(미끄럼, 접지, 탐침 동작)으로 새로 등록 |
| 불통과 | 불통과 | 멈추고 신호를 다시 설계 |

- 설계 31에는 조사에서 정한 기준선(불일치 벌점만, 가치 앙상블 벌점, 두 모델 최저 점수 항상 켬, replay 비율)을 함께 넣는다.
- 통과한 신호가 둘 이상이면 통과 칸 수, 그다음 다른 범위 밖 조건 거부율 평균이 높은 것을 쓴다.

## 6. 한계 (미리 적음)

- held-out은 조건당 로봇 3대 × 5000스텝이다. 평소 조건은 에피소드가 3개뿐이라 출발 장면 표본이 작다.
- 모든 기록은 사전학습 계획기가 모았다. 전환을 건 계획기가 만드는 상태 분포는 다를 수 있다.
- 잠재 오차는 폐루프 넘어짐을 대신하지 못한다(설계 20). 이 설계의 통과는 폐루프 실험을 할 자격일 뿐이다.
- 적응 모델 5개는 시드만 다르다. 부트스트랩이나 독립 초기화 앙상블은 재지 않는다.

## 7. 규칙

# 설계 문서 11: 방법·문제정의를 강하게 만드는 체계적 실험 (2026-11-01)

사용자 요청: "강한 방법론과 문제정의가 될 수 있도록 필요한 실험들을 체계적으로". 심사 보고서(`paper/review_stage1.md`)와 제 평가에서 남은 약점을 항목별로 메운다. 전부 시뮬-투-시뮬, 18대 × 100초, 짝지은 CI. 드라이버 `scripts/sim2sim/stage7_strengthen.sh` (순서 = 가치/비용 순, 총 ≈ 24 h).

| # | 약점 | 실험 | 예측 (사전 등록) |
|---|---|---|---|
| S1 "계획기가 왜 필요한가" | 식별 주도 헤드에서 계획기 이득 미측정 | targethead 단독(prior_only) 대 + 계획기, 모터 0.4·정상 | 계획기 넘어짐 비 ≤ 0.8 (모터 0.4), 정상 ≤ 1.0; 보상 +10 % 이상 |
| S2 식별 정확도 곡선 | 참값 0.4·1.0 두 점뿐 | 배포 시스템(broadhead 계획기)과 SimDist 계획기로 참값 s ∈ {0.3, 0.5, 0.6, 0.8}에서 3000스텝 로그 → 1축 식별 | 추정 − 참값 ∈ [−0.05, +0.15] 전 점; 두 정책의 추정 차 ≤ 0.1 (정책 독립); 0.8은 평평 가능(상한 안 걸림) |
| S3 4단계 교란 제거 | 식별 시뮬 데이터(0.5, 넘어짐 0) 대 참값 데이터(0.4, 넘어짐 多)가 내용부터 다름 | **targethead**(0.4에서 거의 안 넘어짐)로 0.5·0.4 각 45k 수집 → targethead 동역학 적응 → 0.4 평가 | 두 적응 모두 사전학습(0.43) 대비 ≤ 1.2 (해 없음); 둘의 차 CI가 1 포함 → broadhead의 해악은 넘어짐 多 데이터 때문 |
| S4 헤드 시드 | targethead 시드 1 | 전문가(0.3–0.7) 시드 2 → 데이터 → 헤드 → 모터 0.4·정상 | 시드 2의 모터 0.4 넘어짐 ≤ 0.8, 정상 보상 ≥ 0.034 |
| S5 두 번째 축 (적재) | 모터 1축만 | 조건 +5 kg(기본 DR −1~3 밖): broadhead·SimDist 로그 3000스텝 → 질량 격자 식별 → 적재 전문가(질량 DR 3–7, 모터 DR 없음) → 헤드 `payloadhead` → +5 kg·정상에서 SimDist / broadhead / payloadhead | 식별 질량 ∈ [4, 6]; payloadhead +5 kg 넘어짐 ≤ SimDist의 1/2, 정상 보상 ≥ SimDist −5 % |
| S6 식별기 ablation | 요구 가중·구간 길이의 기여 미기재 | 참값 0.4 로그(3000스텝)에서 {요구 가중 on/off} × {구간 10/20스텝} | 가중 off → MAP ≥ 0.8(평평); 20스텝 > 10스텝 |

관문: S1·S2·S3 성립 → 방법 절 완성(계획기 역할, 식별 곡선 그림, 4단계 해명). S5 성립 → 문제정의가 "액추에이터 축"에서 "시뮬에 매개변수화된 축(액추에이터·적재)"으로 넓어진다. S4로 헤드라인 수치에 시드 범위를 붙인다.

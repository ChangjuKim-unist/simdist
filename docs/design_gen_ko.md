# 설계 16: 후보를 생성형 prior에서 뽑는 계획기 (방법 B)
작성 2026-11-09 (설계 15 후속 A 결과 직후, 사용자 지시 "실험을 진행해줘"). 실험 전 등록.

## 0. 출발점 (설계 15 §7)
- 보정 점수(q50)는 반복 8에서 범위 밖 계획 해악을 없앤다(broadwm 마찰 0.15 0.47 → 0.11–0.17, ctx 0.57 → 0.07). 반복 16에서는 못 막는다(7.62 → 5.5–6.4).
- 원인(분포 이동 검사): 센 탐색이 고른 후보는 헤드가 본 적 없는 행동열이고 헤드는 거기서 낙관적으로 외삽한다(10 % 덮음비 0.80 → 0.38). DAgger 1회로 절반만 회복(3.61), 0.9 m/s는 10.8 잔존.
- 지금 후보는 "직전 계획을 민 평균 + 표준편차 2.0 가우시안 잡음"(428개) + "정책 행동열 ± 0.05"(22개). 반복마다 상위 64개로 평균·편차를 다시 맞춘다. 탐색이 셀수록 정책이 결코 하지 않을 행동열이 후보에 들어온다.

## 1. 가설
H16: 후보를 **전문가 데이터의 행동열 분포**(이력·명령 조건부 생성 모델)에서 뽑으면, 탐색 강도를 올려도 후보가 분포 밖으로 못 나가므로 (가) 보정 헤드의 외삽이 생기지 않고 (나) 모델 오차 악용도 줄어, 반복 16에서도 범위 밖 해악이 사라진다.
대안 가설 H16′: 효과는 "후보가 정책 근처에 모여 있다"는 것만으로 설명된다(작은 가우시안 잡음으로 충분). → 대조군 B0로 가른다.

## 2. 방법
생성기 G(u; c): 조건 c = [고유수용 이력 26×35, 행동 이력 25×12, 미래 명령 26×3] (데이터셋 scaler 통계로 정규화), 잠재 u ∈ R^16, 출력 = 25×12 행동열(정규화 단위). 조건부 VAE: 인코더 MLP(행동열+c → 512 → 256 → μ, log σ), 디코더 MLP(u+c → 512 → 512 → 평균 300 + 차원별 log σ_dec), 손실 = 가우시안 NLL + β·KL(β = 1, 3 에폭 워밍업). 학습 데이터: go1_broadwm·go1_ctx의 사전학습 데이터(2026-11-05_11-39-08, 19.1M 스텝, 모터 0.3–1.1·마찰 0.2–1.2·질량 −1~+3)에서 미래 25스텝이 모두 전문가 행동이고 창이 한 에피소드 안인 창 약 45만 개(5 %는 검증). 모델과 독립이므로 go1_broadwm·go1_ctx에 같은 생성기를 쓴다.
계획기(`control.gen`): 매 스텝 u-공간에서 CEM. 초기 μ_u = 0, σ_u = 1; 반복마다 u ~ N(μ_u, σ_u) 450개 → 디코더 평균(+ `dec_noise`·σ_dec·ε, 기본 0) → 행동열 → 점수(Ĵ 또는 보정 q50) → 상위 64개의 u로 μ_u, σ_u 재추정(온도 0.25 가중, σ_u 하한 0.05). 실행 계획 = G(μ_u 최종). 정책 혼합 샘플(B)은 0. 직전 계획 밀기(warm start)는 쓰지 않는다(조건 c가 현재 상태를 이미 담는다).
대조군 B0(`init_mode=prior, init_std=0.3, mixture 0`): 정책 행동열 주변의 작은 가우시안 잡음 후보 + 같은 CEM. "정책 근처"만 공유하고 "분포 위"는 아니다.

## 3. 사전 등록 기준
G0 (오프라인, 검증 창 2만 개; 실패 시 평가 안 함):
- (a) 사후 u로 복원한 행동열의 R² ≥ 0.6, u = 0 평균 예측의 R² 대비 사후 u가 설명하는 추가 분산 ≥ 0.1 (u가 쓸모 있음).
- (b) 한 조건에서 u ~ N(0, I) 450개 샘플의 차원별 표준편차(원 단위) 평균이 0.1 이상(붕괴 아님). 0.1 미만이면 주 팔에 `dec_noise = 1`을 쓰고 기록한다.
- (c) 참 행동열까지의 최근접 거리: 생성 450개 < N(G(0; c), 0.3) 450개 < N(G(0; c), 2.0) 450개(생성 후보가 전문가 행동열을 더 잘 덮는다).
B1 **핵심(C2 재시험)**: go1_broadwm 마찰 0.15, 반복 16, gen + q50(noF 헤드): 넘어짐/1k ≤ 0.47이고 0.9 m/s 넘어짐 < 10.8(A). 짝지은 CI가 Ĵ 반복 16(7.62) 대비 0 제외. 예측 40 %.
B2 반복 8 유지: 마찰 0.15, gen + q50 넘어짐이 C(0.11–0.17)의 CI 안이고 전진 ≥ 45 m. 예측 65 %.
B3 범위 안: 모터 0.4 gen + q50(noM) 보상/스텝 ≥ 0.0282의 CI 안, 넘어짐 ≤ 0.30; nominal·질량 3 gen + q50 넘어짐 ≤ 0.1, 보상 ≥ Ĵ 계획기. 예측 55 %.
B4 설명 분리: 반복 16 마찰 0.15에서 gen + q50 < B0 + q50(CI 0 제외) → H16′ 기각. 예측 50 %. 부가: gen + Ĵ vs gen + q50 → 후보가 분포 위이면 점수 보정이 여전히 필요한지.
정지 규칙: B1·B2 모두 실패 → B 폐기, 방법 = C(반복 8 + q50). B1 실패·B2 성립 → B는 "해롭지 않은 변형"이며 논문 방법은 C 유지, B는 부록. B1 성립 → 방법 = B + q50, C2 성립으로 기록.

## 5. 미리 적는 한계
- 보정 헤드는 Ĵ 계획기 후보로 학습됐다. 생성 후보는 정책 근처라 prior-only 트레이스가 덮지만, 또 다른 분포 이동일 수 있다(B1 실패 시 `calib_shift.py`로 덮음비 확인).
- 생성기는 전문가 분포만 안다. 범위 밖 물리에서 필요한 행동열이 전문가 분포 밖이면 B는 원리적으로 그것을 못 찾는다(그 경우 prior만과 같은 성능이 상한).
- CEM의 u-공간 수축은 또 다른 탐색 강도 손잡이다. 반복 8·16 두 값만 본다.

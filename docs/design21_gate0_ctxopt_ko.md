# 설계 21 관문 0: 맥락 슬롯을 추론하지 않고 최적화하면 적응을 대신하는가 (2026-11-14 등록)

## 0. 질문과 배경
설계 13의 맥락 슬롯 ψ는 이력에서 **추론**했고, 사전학습 DR 범위 안(모터 0.4)에서 평가했다. 거기서는 참값 oracle도 슬롯 없는 대조군과 같아(0.20 = 0.20, 넘어짐/1000스텝) 고칠 여지가 없었다. 범위 밖 마찰 0.15에서는 추론 0.59 / 슬롯 없음 0.47 / oracle 0.34(CI 없음)였다. 즉 "맥락 변수를 실데이터로 **최적화**해 전이 전체 갱신을 대신할 수 있는가"는 시험한 적이 없다(조사 보고서 `reports/적응형 세계모델 구조 아이디어 조사.md` §1.1, 사용자 지적 2026-11-14).

이 관문은 FiLM·hypernetwork 같은 새 구조를 만들기 전에, **이미 있는 덧셈 슬롯**(go1_ctx)으로 최적화형 맥락이 작동하는지 하루에 본다.

## 1. 방법
- 모델: go1_ctx(설계 13, 넓은 DR 데이터로 ψ 슬롯과 함께 이어 학습). 가중치 전부 얼림.
- 적응 데이터: `sim2sim_friction0.15_go1_broadwm_b45000`(마찰 0.15에서 go1_broadwm 계획기가 모은 45k 스텝). go1_ctx로 모은 데이터는 정리 때 지워져, 같은 넓은 DR 데이터로 학습한 슬롯 없는 쌍둥이 모델의 로그를 쓴다. 수집 정책 결합(교훈 5)의 영향은 아래 팔 D가 같은 데이터를 써서 상쇄한다.
- ξ 최적화(`scripts/sim2sim/stage21_ctx_opt.py`): ψ[:3](표준화 [모터, 마찰, 질량])을 자유 3차원 ξ로 대체(`context_override`, 설계 13 oracle 경로), 시작값 0(DR 평균), Adam lr 0.05, 1000스텝, 배치 256, 손실 = 잠재 예측 MSE(설계 20과 같은 손실). 시간순 앞 90 % 창으로 맞추고 뒤 10 %로 held-out MSE 보고. **스텝 수·lr은 여기서 고정하고 넘어짐을 보고 고르지 않는다.**
- 팔(모두 go1_ctx, 계획기 켬):
  - A 추론 ψ(설계 13 그대로, 같은 날 재평가)
  - B oracle ψ[:3] = 각 평가 조건의 참 물리값
  - C 맞춘 ξ*를 모든 조건에 고정(ξ를 바꾸지 않을 때의 "다른 축" 영향 = 설계 20 망각과 같은 뜻)
  - D 같은 데이터로 전이 전체 적응(`dyn`, 3000스텝, 설계 20 V1 레시피), ψ는 추론
- 조건: 마찰 0.15(적응 축), 모터 0.4(다른 축), 정상. 평가 6시드 × 3속도 × 5000스텝, 짝지은 부트스트랩 CI(`paired_stats.py`). 12런, gpu1 4장.

## 2. 예측과 판정 (사전 등록)
- P1(통과 기준): C의 마찰 0.15 넘어짐 ≤ 0.34(설계 13 oracle 수준)이고 A 대비 짝지은 CI가 0을 넘지 않음(개선).
- P2: C의 모터 0.4가 A 대비 CI상 나빠지지 않음, 정상 ≤ 0.1.
- P3(기제): 맞춘 ξ*의 마찰 성분이 DR 평균(0.7)보다 낮은 쪽으로 움직인다(표준화 값 < 0). 모터·질량 성분은 크게 움직이지 않는다(|Δ| < 0.5 표준편차).
- 참고 비교: C의 마찰 이득이 D(전체 적응) 이득의 절반 이상인가.

| 결과 | 판정 |
|---|---|
| P1 성립 | 최적화형 맥락이 작동 → 곱셈형·사전학습 ξ(설계 21 본안, 보고서 §4.1)로 키운다 |
| C 마찰이 0.34~0.47 | 부분: 덧셈 슬롯의 지렛대가 작다. 곱셈형 시험은 1회만 허용, 실패 시 맥락 방향 접음 |
| C 마찰 ≥ 0.47(슬롯 없음 수준) 또는 A와 CI 구분 안 됨 | 맥락 방향 접음. 남는 후보: 적응된 예측 잠재 위 가치 머리 재적합, 얼린 특징 위 계수 ridge(보고서 §2) |

held-out 잠재 MSE는 기록만 하고 판정에 쓰지 않는다(설계 20: 예측 오차는 넘어짐을 못 본다).

## 3. 규칙
gpu1 4장(11/14 저녁 비어 있음 확인), 런당 ≤ 11 GB. 삭제 없음. 끝나면 §4에 결과, 연구 기록 행 21 추가, 커밋·푸시.

## 4. 결과 (2026-11-15, gpu1, 12런 × 18로봇 = 216행)
원시 CSV `results/stage21/eval_gpu{0..3}.csv`(합본 `eval_all.csv`), ξ 맞춤 `results/stage21/xi_friction0.15.json`, 로그 `results/stage21_server.log`. 통계는 `python3 scripts/sim2sim/paired_stats.py results/stage21/eval_all.csv --pair xifit:go1_ctx:go1_ctx_xifit --pair oracle:go1_ctx:go1_ctx_oracle --pair fullft:go1_ctx:go1_ctx_fullft`.

### 4.1 맞춘 ξ
| 성분 | 시작(DR 평균) | 맞춘 값(원래 단위) | 표준화 | 데이터의 참값(표준화) |
|---|---|---|---|---|
| 모터 | 0.7 | 1.23 | +2.29 | +1.30 |
| 마찰 | 0.7 | 1.22 | +1.78 | −1.90 |
| 질량 | 1.0 | 1.16 | +0.14 | −0.87 |

held-out 잠재 예측 MSE(낮을수록 좋음): 추론 0.0560, oracle 0.0565, 맞춘 ξ 0.0547. 참값을 넣은 oracle이 추론보다 예측을 못 맞추고, 맞춘 ξ의 개선은 2.4 %다. 맞춤 손실은 500스텝에 이미 평탄(0.0216 → 1000스텝 0.0234, 배치 잡음 수준).

### 4.2 넘어짐 (1000스텝당, 낮을수록 좋음; 6시드 × 3속도, 기준 = 추론 ψ와 짝지은 차이와 95 % 부트스트랩 CI)
| 팔 | 마찰 0.15 | 모터 0.4 | 정상 |
|---|---|---|---|
| A 추론 ψ(기준) | 0.64 | 0.31 | 0.12 |
| B oracle | 0.47 (−0.18 [−0.60, +0.17]) | 0.24 (−0.07 [−0.23, +0.09]) | 0.00 (−0.12 [−0.22, −0.03]) |
| C 맞춘 ξ 고정 | **1.90 (+1.26 [+0.56, +2.06])** | **1.70 (+1.39 [+0.88, +1.91])** | 0.00 (−0.12 [−0.22, −0.03]) |
| D 전이 전체 적응 | **0.31 (−0.33 [−0.63, −0.10])** | 1.17 (+0.86 [+0.40, +1.30]) | 0.00 (−0.12 [−0.22, −0.03]) |

보조 지표: C는 세 조건 모두 스텝당 보상이 CI상 나빠짐(정상에서도 0.0357 → 0.0287, 넘어짐 0인데도). 마찰 0.15 전진 거리 30.8 → 17.4 m. 정상 칸의 −0.12는 기준 A의 넘어짐 1회(18런 중)가 사라진 것뿐이라 네 팔 모두 같은 값이다.

### 4.3 판정
- **P1 기각**: C 마찰 0.15 = 1.90(≥ 0.47), 기준보다 CI상 나쁨. 결정표 셋째 줄 → **맥락 방향 접음**.
- **P2 기각**: C 모터 0.4가 0.31 → 1.70으로 CI상 나빠짐.
- **P3 기각**: 마찰 성분이 낮은 쪽이 아니라 +1.78로(1.22, 원래 단위) 올라갔고 모터도 +2.29로 크게 움직임(|Δ| < 0.5 예측과 반대).
- 참고 비교: D(전체 적응)는 마찰 0.15에서 이득(−0.33, CI 0 미만)을 재현하고 모터 0.4 망각(+0.86)도 재현(설계 20 V1과 같은 모양). C는 D 이득의 절반은커녕 부호가 반대.

### 4.4 해석 (판정 밖, 다음 설계의 근거)
1. go1_ctx의 슬롯은 전이 예측에 거의 쓰이지 않는다: 참 물리를 넣은 oracle이 추론보다 잠재 예측 MSE가 높고, 넘어짐 차이도 CI 안이다(설계 13과 같음). 그래서 예측 오차의 기울기가 가리키는 ξ는 물리 의미가 없는 방향이며, DR 범위 밖(표준화 +1.8~+2.3)으로 외삽된다.
2. 슬롯은 가치 쪽(ctx_value_proj)에도 들어간다. 범위 밖 ξ는 예측은 2 % 바꾸지만 계획기의 점수를 망가뜨려, 넘어짐이 없는 정상 조건에서도 보상이 20 % 준다. 즉 "예측 오차로 맞춘 변수"가 "점수"를 오염시킨다. 설계 20의 지표 불일치(예측 오차는 넘어짐을 못 봄)와 같은 현상의 다른 면이다.
3. 보고서의 가설 H1(사전학습 때 적응 변수로 훈련되지 않은 슬롯은 사후 최적화 대상이 될 수 없다)과 모순되지 않는다. 다만 이 관문은 H1을 직접 시험하지 않았고, 결정표대로 곱셈형·사전학습 ξ는 만들지 않는다.
4. 남는 후보(결정표): 적응된 예측 잠재 위에서 가치 머리 재적합, 얼린 특징 위 계수 ridge. 해석 2는 "적응 뒤 점수 머리가 어긋난다"는 첫 후보의 동기와 맞닿는다.

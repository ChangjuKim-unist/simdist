# 설계 40: expert 없는 MPC를 world model 데이터 원천으로 — 장난감 환경 E0 (등록 2026-11-22)

## 1. 질문과 이유

고정 문제는 적응 품질이다. sim에서 사전학습한 world model + MPPI가 실제 조건을 만났을 때, 적은 데이터로 이득을 내고 다른 조건 성능을 지켜야 한다. 사용자의 가설: **world model이 expert 하나에 묶여 있어서 적응이 잘 안 된다**(2026-11-22).

SimDist가 expert에 묶이는 경로는 넷이다. 데이터(PPO expert 궤적), value(expert critic 복사), prior(expert BC), 그리고 이번에 코드에서 찾은 **reward의 gait 시계**다. 시계 항은 `simdist/rl/go2.py`의 `gait_reward`(가중치 0.05)와 `feet_height_gait`(0.2)이고, trot 위상 [0, .5, .5, 0], 주기 0.5 s, 들림 0.09 m로 고정돼 있다.

사용자가 준 두 논문이 이 경로를 끊을 재료를 준다.
- **DIAL-MPC** (ICRA 2025): 진짜 시뮬레이터로 MPPI를 돌리고, 노이즈를 반복과 지평 두 방향으로 줄여 간다(annealing).
- **Reference-free MPPI** (arXiv 2511.19204): 관절 위치·속도 Hermite spline 위에서 MPPI를 돌린다. gait 기준 없이 몸 높이, 자세, 발 미끄러짐, 접촉력, 목표 변위만으로 trot, gallop, 점프가 나온다.

두 논문 모두 진짜 모델을 쓴다. 우리 world model에는 그대로 옮겨도 이득이 없다는 근거가 이미 있다.
- annealing: 설계 7 X2
- 최선 표본 실행: 설계 36 C3, 점수 1위가 정책 head보다 실제 수익 −14 %
- warm start: 설계 36 C1

그래서 두 논문은 **planner로 쓰지 않고, expert 없는 데이터 생성기와 완벽한 모델 기준선으로 쓴다.**

## 2. 문헌 확인 (2026-11-22, research_notes/MPC 데이터 월드모델 novelty/notes.md)

| 물음 | 결과 | 이 설계에서 |
|---|---|---|
| 진짜 모델 MPPI가 다리 고장을 다루나 | 이미 했다. LLA-MPPI (2610.10465): Go2, 한 다리의 세 모터 끔, 모델 은행. 진짜 모델 MPPI 성공률 98.5 %, nominal MPPI 25.5 % (네 과제 합산) | 가설에서 뺀다. 구현 확인으로만 본다 |
| blind RL이 무릎 0 토크에서 실패하나 | 이미 있다 (2403.00398) | 기준선 숫자로만 쓴다 |
| planner 목적함수의 gait 시계가 손상 대응을 막나 | 통제 비교 없음. 가장 가까운 것은 RL 쪽 정성 비교 2608.07328. 반대 근거: SG-CPG (2609.25687)는 고정 trot으로 관절 힘 95 % 손실까지 걷는다 | **E0의 가설** |
| sampling MPC 데이터로 world model을 학습하나 (후보 rollout 포함) | 없다. 기존 증류는 정책, proposal, value만 학습하고 후보 rollout은 버린다. 가까운 것은 CureWM, AFFECT(조작), FlashNeRD(무작위 데이터) | E1의 질문 (다음 등록) |

리뷰어가 E1에 요구할 비교군(같은 데이터 양): PPO expert, PPO + 넓은 노이즈(SimDist 방식), 무작위 행동, MPC 실행 궤적만, MPC + 후보 rollout. E2의 비교군에는 모델 은행(LLA 방식)과 OpTTA (2610.35636)가 들어간다.

## 3. 장난감 환경

- MuJoCo Playground `Go1JoystickFlatTerrain`, MJX(JAX), gpu1. 제어 50 Hz, 물리 250 Hz. 관절 PD는 kp 35, 감쇠 0.5. 토크 상한은 엉덩이·허벅지 23.7, 무릎 35.55 N·m.
- 명령: 전진 0.6 m/s(설계 34–38과 같음). 처음 1 s 동안 0 → 0.6으로 올린다(조심스러운 출발).
- 에피소드 500스텝(10 s). 시작 상태는 Playground 리셋 분포를 따르고, 시드 0–15로 16개를 돌린다.
- 넘어짐: 몸통 위 방향 z < 0.5(60°, SimDist와 같음) 또는 몸통 높이 < 0.12 m. 넘어진 뒤의 스텝은 점수 0이다.

**조건:** 모두 토크 상한만 바꾼다. legR50은 설계 34와 같은 방식이다.

| 이름 | 내용 |
|---|---|
| nominal | 그대로 |
| legR50 | 뒤왼쪽 다리 세 관절, 토크 상한 50 % (확정 셋팅) |
| mot50 | 모든 관절 50 % (확정 셋팅) |
| kneeRR0 | 뒤오른쪽 무릎 0 토크 (다친 다리) |
| kneeFR0 | 앞오른쪽 무릎 0 토크 (다친 다리) |

지연, 경사, 끄는 짐은 E0에서 뺀다. 이 셋은 토크 조건이 아니고, E0의 질문(gait를 바꿔야 하는가)과 관계가 약하다. E1·E2에서 다시 넣는다.

## 4. 비교 대상

1. **PPO**: Playground 기본 설정 그대로(DR 켬, 관측 노이즈, 200M 스텝, 시드 0). 관측 48차원, 특권 정보 없음. 평가에서도 관측 노이즈를 켠다. expert 역할이다.
2. **M-free**: 진짜 모델(그 조건의 MJX 모델) MPPI, 논문 비용(표 II walking 가중치).
   - 몸 높이 |z − 0.27|×100, 자세 각²×10, 접촉 발 속도 L1×0.5, 접촉력 |f − mg/4|×0.05
   - 끝 변위 |p − p_target|₁×2500, p_target = 현재 위치 + 명령 속도 × 지평
3. **M-clock**: M-free 비용에 SimDist trot 시계를 더한다.
   - w_g × (원하는 접촉과 어긋난 발 수 + 원하는 들림 구간 발의 높이 오차 항(1 − Gauss(h; 0.09, 0.0225)))
   - 위상 [0, .5, .5, 0], 주기 0.5 s, 접촉 비율 0.5. SimDist와 같다.

**MPPI 공통 설정 (개발 실행으로 고정, 아래 §4.1):**
- 지평 0.9 s (45스텝), spline 노드 10개 (0.1 s 간격), 관절 위치·속도 노드
- 표본 1024개, 반복 6번, annealing β1 = β2 = 1 (논문 식 8), min-max 정규화 가중, 온도 λ 0.1
- 노이즈 σ_q 0.2 rad, σ_v 2.0 rad/s
- 제자리 비용 ×5. 물리 스텝(4 ms)마다 더한 것과 같다. 자세 항 w_q 0.3 (논문의 다른 과제 값)
- 최선 표본의 첫 행동을 실행하고, warm start는 최선 궤적을 한 스텝 민 것이다
- 관절 목표는 제어 스텝(20 ms)마다 바꾼다
- 속도 목표는 위치 목표에 (kd/kp)·q̇*를 더해 넣는다(PD에서 같은 식)
- 지연 없음. 진짜 상태를 쓴다(특권 상한)

**M-clock 가중치 조정 (조건을 보기 전, nominal에서만, 시드 100–107, 8개):**
- 같은 시드로 M-free도 한 번 돌려 기준 J를 얻는다.
- w_g ∈ {1, 3, 10, 30} 중에서 아래 셋을 모두 만족하는 가장 작은 값을 고른다.
  - 접촉 일치율 ≥ 0.80
  - 넘어짐 0
  - J ≥ 0.9 × J(M-free)
  - 만족하는 값이 없으면, 넘어짐 0인 것 가운데 일치율이 가장 높은 값을 쓰고 기록한다.

## 5. 지표

- **J (주 지표)**: 2 s 이후 스텝마다 exp(−((v_x − 0.6)² + v_y²)/0.25)를 매기고 에피소드 평균을 낸다. 0–1이고 1이 완벽한 속도 추종이다. 넘어진 뒤는 0이다.
- **넘어짐**: 16개 중 몇 개인가.
- **동작 품질(판정에 쓰지 않음)**: 평균 전진 속도, 방향 틀어짐(°), 몸 roll/pitch 흔들림 SD, 토크², 관절 목표 jerk, 접촉 발 미끄러짐 속도, 다리별 접지 비율(duty), 시계와의 접촉 일치율.
- **짝비교**: 같은 시드끼리 짝을 짓고, 95 % 구간은 에피소드 16개 bootstrap 5000번이다.

## 6. 판정 (실행 전 고정)

**구현 확인 (가설 아님, 문헌상 예상됨):**
- K1: PPO nominal J ≥ 0.7, 넘어짐 0/16
- K2: M-free nominal 넘어짐 0/16, 평균 전진 속도 ≥ 0.4 m/s. 초안의 J ≥ 0.7은 개발 실행(§4.1)을 본 뒤 사용자 결정으로 바꿨다. 실패하면 장난감 MPC 경로를 멈추고 보고한다.
- 참고(판정 아님): 무릎 0 토크에서 M-free가 PPO보다 덜 넘어지는가(LLA-MPPI, 2403.00398로 예상됨). legR50, mot50에서 PPO 대비 M-free의 J 차이.

**가설 (새 질문): 시계가 손상 대응을 막는가.**

Δ_clock(c) = J(M-free, c) − J(M-clock, c)를 같은 시드끼리 짝지어 계산한다.

| 판정 | 조건 |
|---|---|
| 막는다 | kneeRR0 또는 kneeFR0에서 Δ_clock ≥ 0.10이고 95 % 구간 하한 > 0, 그리고 nominal에서 \|Δ_clock\| ≤ 0.05 |
| 무해 | 두 무릎 조건 모두 Δ_clock < 0.05이거나 구간이 0을 포함 |
| 중간 | 그 밖 |

legR50·mot50의 Δ_clock은 보고만 한다(예측 ≤ 0.05, SG-CPG 근거).

**예측:**
- P1: K1, K2 통과 (80 %)
- P2: "막는다" (50 %). M-free는 다친 다리의 접지 비율을 줄이고, M-clock은 시계를 지키다 J를 잃는다.
- P3: legR50·mot50에서 Δ_clock ≤ 0.05

**결과에 따른 다음 단계:**
- K2 통과 → E1 등록(같은 양의 데이터 다섯 가지, §2). 생성기는 M-free.
- "막는다" → 본 실험 쪽에서 SimDist planner reward의 gait 항을 빼는 설계를 별도로 등록한다(데이터·value 쪽과 분리해서 본다).
- "무해" → 시계는 적응을 막는 경로가 아니다. E1은 그대로 진행한다.

## 8. 결과

### 8.0 조정 단계 (2026-11-23, results/stage40/tune.json, nominal 시드 100–107, 8개 × 500스텝)

| 대상 | J | 넘어짐 /8 | 시계 접촉 일치율 |
|---|---|---|---|
| M-free (기준) | 0.43 | 4 | – |
| M-clock w_g 1 | 0.35 | 6 | 0.55 |
| M-clock w_g 3 | 0.40 | 4 | 0.60 |
| M-clock w_g 10 | 0.28 | 7 | 0.71 |
| M-clock w_g 30 | 0.15 | 8 | 0.81 |

- **M-free부터 nominal에서 8개 중 4개가 넘어진다.** 개발 실행(§4.1, 넘어짐 0)은 5초짜리였고, 이번 넘어짐은 3.6–8.3초에 일어났다.
  - 넘어지기 전 동작은 곡예에 가깝다. 허벅지가 3.85 rad까지 돌아가고(기본 0.9), 네 발이 모두 뜨고, 뒤로 달린다.
  - 넘어짐은 대부분 몸통 높이 기준(z < 0.12 m)이다.
- 시계를 따르게 할수록(일치율 0.81) 넘어짐과 J가 나빠진다. w_g 3은 시계를 거의 따르지 않고(일치율 0.60), M-free와 비슷하다.
- 등록 규칙은 "넘어짐 0인 가중치가 하나도 없는 경우"를 정하지 않았다. 실행 스크립트는 여기서 멈췄고, **M-clock 본 실행은 돌리지 않았다.**
  - 시계 질문(Δ_clock)은 등록한 방식으로는 답할 수 없다.
  - M-free 본 실행 다섯 칸은 시계와 무관하게 등록돼 있어 따로 돌렸다(`stage40_e0_free.sh`).
- M-free 본 실행의 nominal 결과가 K2(넘어짐 0/16, 전진 ≥ 0.4)를 판정한다. 조정 단계의 4/8로 보아 실패 가능성이 크다. 실패하면 등록대로 장난감 MPC 경로를 멈추고 보고한다. E1·E2도 같은 조건에 걸려 있다.

## 9. E1 준비: 장난감 조건 수준 다시 정하기 (등록 2026-11-22, 실행 전 고정)

**이유:** E0의 PPO는 legR50과 mot50에서 nominal과 J가 소수 셋째 자리까지 같다(0.982). 토크 상한이 거의 묶이지 않기 때문이다. nominal 보행에서 상위 1 % 토크는 무릎 12–13 N·m로, 50 % 상한 17.8보다 낮다. 허벅지는 13.8 N·m로 50 % 상한 11.9를 순간만 넘는다. 확정 셋팅의 '중간 난이도(걷지만 나빠짐)'를 장난감에서 만들려면 수준을 다시 정해야 한다.

**후보:**

| 계열 | 수준 |
|---|---|
| 모터 전체 | mot40, mot30, mot25 |
| 뒤왼쪽 다리 | legR30, legR20, legR10 |
| 명령 지연 (제어 스텝) | delay1, delay2, delay3 |
| 끄는 짐 (N) | tow20, tow30, tow40 |

- 지연과 끄는 짐은 설계 34와 같은 방식이다. 끄는 짐은 몸통에 진행 반대 방향 수평 힘을 주고, 전진 0.1 m/s에서 포화한다.
- 비교 대상: E0의 PPO, E0와 같은 평가(시드 0–15, 500스텝, 명령 0.6, 출발 1 s).
- 경사는 장난감 지형 코드가 필요해 이번에는 뺀다.

**고르는 규칙 (계열마다 하나):**
1. 넘어짐 ≤ 2/16이고 J 하락(nominal 대비) ≥ 0.05인 수준 가운데 가장 센 것을 고른다.
2. 그런 수준이 없으면, 넘어짐 ≤ 2/16 가운데 하락이 가장 큰 것을 고른다.
3. 모두 넘어짐 > 2/16이면, 가장 약한 수준을 고르고 기록한다.

고른 수준이 E1·E2의 "확정 셋팅" 조건이 된다. 무릎 0 토크 둘은 "다친 다리" 조건으로 그대로 둔다. 스크립트는 `scripts/toy/stage40_screen.sh`, 결과는 `results/stage40/screen.md`에 둔다.

## 10. E1·E2 등록 (2026-11-23, E1·E2 결과 전; 데이터 생성은 먼저 시작, 판정과 해석은 E0의 K2 통과를 조건으로)

**질문 (사용자 가설의 직접 시험):** world model을 expert 하나의 데이터로 사전학습하면, 새 조건에 적응할 때 이득이 작은가. 같은 양의 expert 없는 MPC 데이터로 사전학습한 world model과 비교한다.

**장난감 world model:** 상태 기반 MLP(3층 × 512)다. 입력은 상태 x(34)와 관절 목표 u(12)다. 출력은 다음 상태 차이와 비용용 물리 특징이다: 접촉, 발 수직력, 발 속도, 이동량, 방향 변화, 발 높이. value, reward head, prior는 없고, 비용은 E0 식을 예측 특징에서 그대로 계산한다. 그래서 이 world model이 expert에 묶이는 경로는 **데이터 하나뿐**이고, E1·E2는 데이터 경로만 따로 본다. 학습은 8스텝 연속 예측 손실, 30k 스텝, batch 256, AdamW 3e-4, 시드 0이다.

**데이터 원천 다섯 (각 5만 transition, Playground DR 켬, 명령 U(0.2, 0.9) m/s):**

| 이름 | 내용 |
|---|---|
| P | PPO (expert), 100개 × 500스텝 |
| PN | PPO + 에피소드마다 행동 노이즈 SD ~ U(0, 0.6) (SimDist식 섭동), 100 × 500 |
| R | 무작위 관절 목표(OU, 기본 자세 주변), 500 × 100 |
| ME | 진짜 모델 MPPI(표본 256 × 반복 6, E0보다 싼 설정)의 실행 궤적, 100 × 500 |
| MC | 같은 MPPI 런의 후보 rollout(스텝마다 마지막 반복 후보 4개를 다시 굴려 기록)에서 뽑은 5만 |

**E1 (적응 전):**
- 후보 순위: 시험용 진짜 모델 MPPI 런(시드 900번대, 후보 16개 기록)의 앵커에서 world model 예측 비용과 진짜 비용의 Spearman, 그리고 예측 1위의 regret을 잰다. 조건은 nominal(DR 없음), kneeRR0, tow40.
- 폐루프: world model MPPI(256 × 6)의 nominal J와 넘어짐, 16개.

**E2 (주 질문):**
- 조건: kneeRR0, kneeFR0, tow40.
  - delay2는 뺀다. 이 상태 모델에는 행동 이력이 없어 지연을 표현할 수 없다.
  - mot30, legR20은 뺀다. PPO가 나빠지지 않는다(§9.1).
- 원천 s의 world model마다, 조건 c에서 자기 world model MPPI로 16개 × 500스텝(8000 transition, 로봇 시간 160 s)을 모은다.
- 그 데이터 + 자기 사전학습 데이터 replay 50 %로 5000스텝 미세조정한다(설계 32에서 replay가 보존을 지켰다).
- 적응 후 c와 nominal에서 16개씩 평가한다.
- 이득 G(s, c) = J(적응 후, c) − J(적응 전, c). 보존 손실 L(s) = J(적응 전, nominal) − J(적응 후, nominal), 조건 셋의 평균이다.

**판정:**

| 판정 | 조건 |
|---|---|
| 가설 지지 | max(G(ME), G(MC)) − G(P) ≥ 0.10이 세 조건 중 둘 이상이고, 그 MPC 원천의 L이 P의 L보다 0.05 넘게 크지 않음 |
| 가설 반대 | G(P)가 두 MPC 원천보다 0.10 이상 큰 조건이 둘 이상 |
| 중간 | 그 밖 |

- 같은 쌍을 PN에 대해서도 보고한다. "다양성만으로(노이즈) 같은 효과가 나는가"를 보기 위해서다.
- 95 % 구간은 에피소드 bootstrap이다. 판정은 평균으로 한다(16개, 미세조정 시드 하나라는 한계를 결과에 적는다).

**예측:**
- Q1: E1 후보 순위 Spearman은 MC > ME > PN > P. R은 폐루프에서 가장 나쁘다.
- Q2: 가설 지지 (40 %)
- Q3: PN의 이득은 P와 MC 사이

**한계 (미리 적음):** 장난감 world model planner는 진짜 모델 MPPI(J 약 0.6)보다 높을 수 없다. 원천끼리의 상대 비교만 한다.

**스크립트:** `scripts/toy/stage40_e1.sh`(데이터 → 학습 → E1 → E2), 분석 `scripts/toy/stage40_e12_report.py`. 결과 전에 커밋한다.

**한계와 읽기 (등록 안 함):**
- **바닥 효과.** 다섯 중 넷(P, PN, R, ME)의 world model MPPI는 적응 전부터 nominal에서 16/16 넘어진다. 그래서 세 조건의 G가 모두 0 근처이고, E2는 "어느 데이터가 더 잘 적응하는가"에 답하지 못한다. 판정 "중간"은 차이가 없다는 뜻이 아니라 잴 수 없다는 뜻에 가깝다.
- **걷는 것은 MC뿐이다.** planner가 실제로 물어볼 후보 궤적을 데이터로 덮은 world model만 MPPI가 쓸 수 있다(J 0.58, 진짜 모델 MPPI 0.68). 같은 MPPI 런의 실행 궤적(ME)은 열린 루프 오차가 MC보다 작은데도(0.42 대 0.49) 16/16 넘어진다. 예측 오차가 아니라 후보 분포를 덮는지가 갈랐다.

- **R의 tow40 이득(+0.148, 넘어짐 15 → 5)은 제자리에 서는 법을 배운 것이다.** 적응 후 전진 −0.01 m/s다.

# 설계 22: 적응된 동역학의 예측 잠재 위에서 점수 머리 재적합 (2026-11-15 초안; §11 빠른 확인만 등록)

## 0. 질문
SimDist는 실데이터로 latent dynamics만 적응하고 보상·가치 머리는 얼린다. 계획기 점수는 J = Σγ^k r̂(ẑ_k) + γ^T V̂(ẑ_T)이고, 머리의 입력은 **적응된 동역학이 예측한 ẑ**다. 머리를 적응된 모델 자신의 예측 잠재 위에서, 넘어짐을 아는 실제 수익으로 다시 맞추면 적응 축의 넘어짐이 SimDist보다 줄어드는가?

## 1. 설계 1과 무엇이 다른가 (코드로 확인)
- 설계 1(`world_model_value_adapt`)은 가치를 **참 미래 관측의 인코더 잠재 E(o)** 위에서 학습했다(손실 docstring: "Values are evaluated on the encoded true future latents"). 계획기는 ẑ에서 가치를 읽는다. 사전학습(`WorldModelLoss`)은 머리를 ẑ 위에서 학습한다. 즉 설계 1은 학습 입력과 사용 입력이 달랐다.
- 설계 1의 판정은 "순위는 고쳐졌는데(Spearman 0.20 → 0.46~0.50) 넘어짐은 −13 %, CI 0 포함. 병목은 경계 근처 동역학 오차"였다.
- 가설 H22: ẑ 위에서 맞춘 머리는 경계 근처 동역학의 **체계적 편향을 흡수**한다(예측이 "덜 넘어진" 상태를 내놓아도 그 예측 잠재에 낮은 가치를 붙인다). E(o) 위에서 맞춘 머리는 이것을 못 한다. 설계 1이 지목한 병목을 머리 쪽에서 우회하는 것이다.
- 보상 머리는 지금까지 어떤 설계에서도 적응한 적이 없다.

## 2. 시험대 선정 (설계 20 중간 결과, go1_paper = SimDist 재현 모델, 넘어짐/1000스텝)
| 적응 데이터 | 적응 축: 적응 전 → SimDist 적응 | 다른 축: 적응 전 → SimDist 적응 | 정책 헤드만 |
|---|---|---|---|
| 모터 0.4 (주 시험) | 3.36 → 2.57 | 마찰 0.15: 2.64 → 4.59 | 모터 0.4: 3.32 |
| 마찰 0.15 (보조) | 2.64 → 0.17 | 모터 0.4: 3.36 → 4.36 | 마찰 0.15: 1.17 |
- 모터 방향은 적응 뒤에도 2.57이 남아 개선 여지가 크고, 계획기가 정책 헤드보다 낫다(SimDist가 의미 있는 영역). 마찰 방향은 바닥(0.17) 근처라 "해치지 않는가"만 본다.
- go1_broadwm은 쓰지 않는다: 계획기가 정책 헤드보다 거의 항상 나빠(마찰 0.15에서 0.59 대 0.02) 점수 머리를 고쳐도 계획기를 쓸 이유가 없다.

## 3. 팔 (모두 go1_paper, 계획기 켬, 동역학은 설계 20 V1 체크포인트 그대로)
| 팔 | 동역학 | 보상·가치 머리 | 머리 학습 입력 |
|---|---|---|---|
| B SimDist 적응 | 적응(V1) | 얼림 | 없음 |
| C 예측 잠재 재적합 | 적응(V1), 얼림 | 재적합 | 적응된 동역학의 ẑ (사전학습과 같은 경로) |
| D 참 잠재 재적합 | 적응(V1), 얼림 | 재적합 | E(o) (설계 1 방식) |
C와 D는 입력만 다르고 라벨·데이터·스텝·학습률·replay가 같다. 참고값(재실행 안 함, 판정에 안 씀): 설계 20의 적응 전 계획기, 정책 헤드만.

## 4. 재적합 방법
- 데이터: 각 방향의 적응 데이터 15분(`sim2sim_very_weak_motor_go1_paper_b45000`, `sim2sim_friction0.15_go1_paper_b45000`). 새 수집 없음.
- 가치 라벨: 기록된 보상의 할인 reward-to-go(γ 0.99, 넘어짐 뒤 0; `terminal.hdf5`의 rtg). 시뮬 앵커를 쓰지 않아 설계 1 §9.4의 타깃 불연속이 없다. 실행 끝(총 스텝 도달)으로 잘린 에피소드의 마지막 300스텝은 rtg가 잘려 있으므로 가린다.
- 보상 라벨: 기록된 시뮬 보상. 실로봇에서는 이 라벨을 그대로 얻기 어렵다. 이 설계는 **상한**을 재는 것이다: 상한에서도 안 되면 실로봇 판도 안 된다. 되면 다음 설계에서 라벨 없는 판(보상 머리를 E(o)에 대어 라벨 생성)을 시험한다.
- 갱신: `reward_emb, reward, reward_dec, value_emb, value, value_dec`만(동역학·인코더·정책 얼림). 이 브랜치의 heads 필터는 경로 원소 일치라 다른 모듈을 고르지 않음; 구현 때 파라미터 수로 확인.
- 망각 방지: 사전학습 시뮬 데이터 replay 50 %(배치 32+32), 시뮬 창에는 사전학습 라벨, 입력 종류는 팔과 같게(C는 ẑ, D는 E(o)). 설계 1 P4에서 replay 없이는 가치 망각이 컸다(RMSE 1.20 대 0.14).
- 3000스텝, 학습률은 finetune 기본(2e-4, warmup 2000 → 1e-4), 시드 42. 넘어짐을 보고 고르지 않는다.
- 라벨 점검(2026-11-15 확인): 넘어짐 플래그 수 = 에피소드 수 − 실행 수 9와 맞음(마찰 57 = 66 − 9, 모터 112 대 111). 구현 때 실행 경계로 한 번 더 확인.

## 5. 관문 0: 기제가 있는가 (오프라인, held-out 기록)
- 기록: 설계 20 held-out(`*_go1_paper_ho_b15000`, 적응 전 계획기, 학습에 안 씀). 모터 0.4(에피소드 56), 마찰 0.15(12), 정상(3).
- 지표: 창 끝 뒤 50스텝 안 넘어짐을 V̂(ẑ_T)로 맞히는 AUC(B, C, D 각각; D는 E(o)에서의 AUC도 기록). 머리 입력 간극 RMS[V̂(ẑ_T) − V̂(E(o_T))] 대 의미 오차 RMS[V̂(E(o_T)) − rtg], 넘어짐 창과 보통 창 따로.
- **중단 규칙**(모터 방향): C의 AUC가 D보다 0.02 이상 높지 않거나 에피소드 부트스트랩 CI가 0을 포함하면, C는 설계 1과 같은 것이므로 폐루프를 돌리지 않는다. 오프라인 지표는 "기제가 없다"는 판단에만 쓰고, 성공 판단에는 쓰지 않는다(설계 20·21 교훈).
- 한계: 실행한 행동열만 있어 같은 상태의 후보 간 순위는 못 잰다. 그것은 폐루프가 판정한다.

## 6. 관문 1: 폐루프
- 조건: 모터 0.4, 마찰 0.15, 정상. 6시드 × 3속도 × 5000스텝, 짝지은 부트스트랩 CI(`paired_stats.py`).
- 런: 방향마다 B·C·D × 3조건 = 9, 적응 시드 43(설계 20 체크포인트)으로 B·C × 적응 축 = 2. 두 방향 22런.

## 8. 위험
- 계획기 착취: 머리는 실행된 행동열의 ẑ만 보고 맞춰진다. MPPI 후보는 그 밖으로 나가므로 재적합 머리가 외삽에서 낙관할 수 있다(설계 15). replay와 고정 스텝으로 줄이고, P3으로 잡는다.
- 정상 조건 held-out의 넘어짐이 0이라 그 칸의 AUC는 정의되지 않음(기록만).

## 9. 구현과 비용
- `losses.py`에 `head_refit` 손실(옵션 `value_input: pred|true`, rtg 라벨과 가림, 보상 라벨, replay), `config/heads/reward_value.yaml`, `run_pipeline.sh` 변형 `hr_pred`·`hr_true`, 오프라인 스크립트 `scripts/sim2sim/stage22_heads_offline.py`, 구동 `scripts/sim2sim/stage22.sh`. 반나절.
- gpu1(사용 전 nvidia-smi 확인, 런당 ≤ 11 GB): 재적합 6건 ≈ 15분씩 병렬 → 관문 0 ≈ 1.5 h → 폐루프 22런 ≈ 5.5 h. 합계 하루 + 하룻밤.

## 11. 빠른 확인 (2026-11-15 등록, 사용자 요청 "빠르게 가능성 체크")
본안(§3~§7)을 돌리기 전에, 모터 방향 한 칸만 작게 돌려 가능성을 본다. 본안의 판정을 대신하지 않는다.
- 재적합: 시작 체크포인트 `go1_paper_very_weak_motor_dyn_b45000_s42`(SimDist 적응), 데이터 `sim2sim_very_weak_motor_go1_paper_b45000`, `loss=head_refit heads=reward_value`, `value_input` = pred(C) / enc(D), 2000스텝, warmup 200, 학습률 기본, 시드 42, **replay 없음**(본안과 다른 점). 체크포인트 `go1_paper_very_weak_motor_hrpred_q`, `go1_paper_very_weak_motor_hrtrue_q`.
- 오프라인(`scripts/sim2sim/stage22_offline.py`): held-out `sim2sim_very_weak_motor_go1_paper_ho_b15000`에서 B·C·D의 V̂(ẑ_T) 넘어짐 50스텝 예측 AUC, 블록 부트스트랩 CI. 기록만 한다.
- 폐루프: 모터 0.4에서 B·C·D, 정상에서 C. 6시드 × 3속도 × **2000스텝**(본안 5000), gpu1 4장 병렬, `results/stage22q/`.
- 판정(모터 0.4, C 대 B, 짝지은 CI):
  - C ≤ 0.8 × B이고 CI가 0 제외 → **가능성 있음**: 본안(§3~§7) 등록·실행.
  - C가 B보다 10 % 이상 낮지만 CI가 0 포함 → **불확정**: 짧은 런의 검출력 한계. 본안으로 판정.
  - C ≥ 0.9 × B → **가능성 낮음**: 머리 방향 접음(설계 1과 일관). 단 C의 AUC가 D보다 CI상 높으면 그 사실을 함께 기록.
  - C 정상 넘어짐 > 0.2 → 해악으로 따로 기록.

### 11.1 결과 (2026-11-15 14:17, gpu1)

**판정 (§11 규칙)**: C 5.19 ≥ 0.9 × 2.11 → **가능성 낮음, 머리 방향 접음.** 규칙대로 함께 기록: C의 AUC는 D보다 CI상 높다(하한 +0.0001, 경계). 즉 오프라인 지표는 C가 가장 좋다고 말했고, 폐루프에서 C가 가장 나빴다.

**진단 (판정 밖)**: 실행된 행동열에 잡음(행동 표준편차 × 0.25)을 더한 후보를 점수가 더 높게 보는 비율은 SimDist 적응 1.6 %, C 16.9 %, D 14.5 %. 두 재적합 모두 실행 행동 주변 점수를 평평하게 만들고, C만의 특이점은 아니다. C가 무너진 원인은 미확인이다. 후보 설명: (1) C의 머리가 예측 잠재에만 있는 특징에 기댄다(예측 대 실제 잠재 가치 차 1.06, D 0.39) → MPPI가 450 후보 × 8반복의 극단에서 그 특징을 착취(설계 15); (2) 보상 머리 쪽 효과. 둘 다 시험하지 않았다.

## 13. 보수적 재적합 (2026-11-15 등록)
§12 결론을 직접 고치는 판. 재적합은 기록 데이터에서는 점수를 자유롭게 바꾸되, **데이터 밖 후보의 점수를 기록 행동 대비 얼린 머리보다 더 올리지 못한다.**
- 손실: §11의 보상·가치 손실 + λ · cons. 창마다 기록 행동열에 원 단위 잡음(표준편차 0.1·0.3·1.0·2.0을 돌려 씀, MPPI 첫 반복의 2.0에서 줄어드는 탐색 폭을 덮음)을 더한 후보 16개를 만들고, 계획기 점수 J로
  cons = 평균( relu( [J_new(후보) − J_new(기록)] − [J_old(후보) − J_old(기록)] )² ) / 가치 표준편차²,

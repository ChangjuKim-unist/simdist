# 설계 31: 조건 토큰 세계모델의 관문 (2026-11-18 등록)

## 0. 배경

- 연구문제(`docs/research_problem_ko.md`): 커버리지 밖 조건에 적응하면서 이득·안전·보존을 함께 만족시키기.
- 설계 30: 기록 데이터 위의 지원 범위 신호와 행동 어댑터가 모두 불통과였다. 이어서 예전 결과를 다시 읽어 세 가지를 확인했다.
  1. **replay는 망각을 고치지만 이득을 지운다** (설계 20, 시드 1개). 넓은 DR 모델 빙판 적응: 모터 40 % 넘어짐 0.73 → 0.24, 빙판 넘어짐 0.29 → 0.63. 논문 모델 모터 적응: 빙판 4.59 → 2.09, 모터 2.57 → 3.39. 해석: 모델 하나는 구분할 수 없는 입력에 평균을 낸다. 모델에 "지금 어느 조건인가"라는 변수가 없다.
  2. **범위 밖에서는 정책만 쓰는 편이 사전학습 계획기보다 낫다** (설계 20 평가). 논문 빙판 1.17 대 2.64, 넓은 DR 빙판 0.02 대 0.59.
  3. **오차로 모델을 고르면 사전학습만 불리하다.** fine-tuning이 줄인 오차의 대부분은 조건과 무관하다(빙판 적응 뒤 평소 조건 오차 −59~64 %). 적응 모델끼리는 평균 오차가 맞는 조건을 고른다(4칸 모두).
- 제안한 방법(사용자 승인 2026-11-18): ① 조건 토큰을 단 모델 하나를 실제 데이터 + 시뮬 replay로 학습, ② 출발은 정책, ③ 걷는 중에는 실제 관측과 더 잘 맞는 토큰에만 계획기를 맡김.
- 이 설계는 ①이 성립하는지만 확인하는 관문이다. ②·③의 폐루프는 통과한 뒤 설계 32에서 한다.

## 1. 토큰 모델

- 구조: 설계 24의 FiLM 경로를 그대로 쓴다. 토큰 ξ(4차원)가 잠재 동역학 각 층의 정규화 뒤 출력을 배율·이동시킨다. 투영은 0으로 초기화해서 시작은 사전학습 모델과 같다.
- 토큰: 실제 적응 데이터 창에는 ξ = [1, 0, 0, 0](적응 토큰), replay 창에는 ξ = 0(시뮬 토큰).
- 학습(변형 `tok`): SimDist 방식과 같은 예산(3000스텝, 동역학만 + FiLM 투영, 시드 42). 손실 = 0.5·실제 + 0.5·replay.
- replay 두 가지(배치 32 + 32, 실제 32):
  - 사전학습 데이터 창: 논문 모델은 `paper_sub8192`(사전학습 데이터의 8192 에피소드), 넓은 DR 모델은 사전학습 데이터 전체.
  - 시뮬 계획기 데이터 창: 사전학습 계획기가 평소 조건에서 모은 45,000스텝(`sim2sim_nominal_{모델}_b45000`). 조건과 무관한 "계획기 행동에서의 예측" 부분을 두 토큰이 함께 배우게 하려는 것이다.
- 칸 4개: 모델 {논문, 넓은 DR} × 적응 조건 {빙판(마찰 0.15), 모터 40 %}.

## 2. 질문

- **G1 (이득).** 가중치를 replay와 나눠 써도, 적응 토큰으로 계획하면 자기 조건의 적응 이득이 남나?
- **G2 (보존).** 같은 모델에 시뮬 토큰을 주면, 다른 범위 밖 조건에서 사전학습 수준으로 걷나?
- **G3 (신호).** 두 토큰의 오차 차이가 "지금은 적응한 조건이 아니다"를 알려 주나? (설계 30의 QS를 토큰으로 다시 묻는 것)

## 3. 측정과 기준

### 3.1 G1 (폐루프)

- 설계 29와 같은 방식: 로봇 18대(속도 0.3/0.6/0.9 × 시드 11~16) × 5000스텝, 1000스텝당 넘어짐.
- 비교 대상은 설계 29의 같은 방식 기록을 그대로 쓴다: 사전학습 계획기, 동역학 fine-tuning 계획기(시드 42).
- 유지된 이득 = (사전학습 − 토큰 모델) / (사전학습 − 동역학 fine-tuning). 자기 조건에서, 적응 토큰으로. 로봇 단위 짝 부트스트랩.
- **한 칸 통과:** 유지된 이득 ≥ 0.70, CI 하한 > 0.40.
- 적응 이득이 있는 칸만 센다: 논문·빙판(2.60 → 0.23), 논문·모터(3.61 → 2.43), 넓은 DR·빙판(0.66 → 0.20). 넓은 DR·모터는 이득이 없어 보고만 한다.
- **G1 통과:** 3칸 중 2칸 이상.

### 3.2 G2 (폐루프)

- 같은 모델에 시뮬 토큰을 주고 다른 범위 밖 조건(빙판 적응 모델 → 모터 40 %, 모터 적응 모델 → 빙판)에서 잰다.
- **한 칸 통과:** 토큰 모델 넘어짐 − 사전학습 넘어짐 ≤ max(0.3 × 사전학습, 0.15). 0.15는 반복 실행 잡음(SD 0.09~0.23) 수준의 바닥이다.
- **G2 통과:** 4칸 중 3칸 이상.

### 3.3 G3 (오프라인, `scripts/sim2sim/stage31_signals.py`)

- 신호 = (적응 토큰의 k-step 잠재 오차) − (시뮬 토큰의 오차). 클수록 적응 토큰을 믿을 이유가 적다.
- 데이터, 장면, 판정 규칙은 설계 30과 같다: held-out 15,000스텝, 50창 평균, 걷는 중 장면, 자기 조건 보정 블록의 95 % 분위수 문턱.
- **한 칸 통과:** 다른 범위 밖 조건 거부율 ≥ 0.80이고 CI 하한 > 0.60, 자기 조건 시험 블록 거부율 ≤ 0.15.
- **G3 통과:** 4칸 중 3칸 이상.
- 같은 창에서 설계 30의 오차 기준선(동역학 fine-tuning 오차 − 사전학습 오차)을 다시 계산해 나란히 적는다.

### 3.4 함께 적는 것 (기준 없음)

- 시뮬 토큰으로 자기 조건을 걸으면 사전학습처럼 걷나(이득이 공유 가중치로 새는지).
- 적응 토큰으로 다른 범위 밖 조건을 걸으면 얼마나 나쁜가(토큰을 잘못 골랐을 때의 비용).
- 시뮬 토큰의 평소 조건 주행.
- 모든 팔의 스텝당 보상, 출발에서 넘어질 확률, 걷는 중 넘어짐(노출 시간 기준), 걷는 중 정책 이탈.
- 실행 순서는 G1 → G2 → 위 세 가지다. 뒤쪽이 시간 때문에 빠지면 빠졌다고 적는다.

## 5. 결정 규칙

| G1 | G2 | G3 | 다음 |
|---|---|---|---|
| 통과 | 통과 | 통과 | 설계 32: 전체 방법의 폐루프(정책 출발 + 토큰 오차 차이로 전환) + 조사에서 정한 기준선 |

| 통과 | 불통과 | — | replay가 시뮬 토큰을 사전학습 수준에 묶지 못한다. replay 구성을 새로 등록(결과를 보고 이번 실행의 비율을 바꾸지 않음) |

## 6. 한계 (미리 적음)

- 칸마다 시드 1개다.
- 시뮬 계획기 데이터는 평소 조건만이다. DR 범위 전체의 계획기 데이터는 통과한 뒤에 모은다.
- 학습 스텝은 SimDist 예산(3000) 그대로다. 실제 창 수는 같지만 모델이 배울 것은 늘었다.
- 비교 대상(사전학습, 동역학 fine-tuning)은 설계 29의 기록을 다시 쓴다. 같은 방식·같은 시드지만 같은 날 실행은 아니다.
- G3은 사전학습 계획기가 모은 기록 위의 판정이다. 설계 30에서 본 대로 기록 위의 오차와 폐루프는 다를 수 있다.
- 로컬 스모크는 논문 모델로만 했다(30스텝 학습, 150스텝 폐루프, 학습용 기록을 대신 넣은 신호 스크립트). 동작 확인용이고 결과로 쓰지 않는다.

## 7. 규칙

- 이 문서를 커밋·푸시한 뒤 실행한다. gpu1에서 `scripts/sim2sim/stage31.sh`, 결과는 `/mnt/newssd/cjkim/simdist/results/stage31`. 런당 11 GB 이하.
- 예상 시간: 학습 약 30분, G3 약 10분, 폐루프 20런 약 4시간(런당 약 50분, GPU 4대). G1·G2 판정에 필요한 8런은 앞의 약 2시간에 끝난다.
- 아무것도 지우지 않는다. 결과를 보고 기준, 토큰, replay 비율을 바꾸지 않는다. 추가 확인은 새로 등록하거나 "등록 안 함"으로 표시한다.

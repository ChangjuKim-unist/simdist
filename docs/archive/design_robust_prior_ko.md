# 설계 문서 6: 강건한 prior, 계획기의 회복, prior-first 적응 — 시뮬 사전학습 월드모델 계획기의 적응 순서

작성 2026-10-21. 선행: 설계 문서 4(커버리지 ≫ 적응, B0 > B), 설계 문서 5 §7(관문 0 불성립: 커버리지는 식별이 아니라 **강건화**에서 온다). 사용자 결정: 분석 논문 아님, A안으로 실험.
컨셉: SimDist의 **적응 단계의 순서**를 바꾼다. (1) prior는 목표 범위를 강건한 DR로 덮는다(시뮬만, 공짜). (2) 계획기의 역할은 강건화의 정상 조건 대가를 월드모델로 **회복**하는 것이다. (3) 실데이터는 그 강건한 prior로 모아 적응한다(prior-first). 월드모델 구조·계획기·적응 손실은 SimDist 그대로.

## 1. 측정된 사실 (출발점)

| 사실 | 수치 (모터 0.4 / 정상, 넘어짐/1000 · 보상/스텝) |
|---|---|
| F1 좁은 prior + 적응 동역학 (SimDist) | 3.19 · 0.0154 / 0.39 · 0.0397 |
| F2 넓은 학생 단독 D | 1.20 · 0.0275 / 0.63 · 0.0265 |
| F3 넓은 학생 + 계획기 + **사전학습** 동역학 B0 | **0.91 · 0.0334** / 0.67 · **0.0331** |
| F4 넓은 학생 + 계획기 + 좁은-prior 데이터로 적응한 동역학 B | 1.98 · 0.0321 / 1.63 · – |
| F5 넓은 전문가의 행동은 히스토리 이상으로 모터 세기에 의존하지 않음 ($S\approx0$), 모터는 히스토리에서 안 보임 ($V\approx0$) | 설계 문서 5 §7 |

읽기: 넓은 prior는 모터 세기를 **식별하지 않고** 하나의 보행으로 덮었고(F5), 그 대가가 정상 보상 −33 %(F2 대 F1)다. 계획기를 사전학습 동역학과 함께 얹으면 정상 보상의 대가 절반 이상을 **넘어짐을 늘리지 않고** 되찾고(F3: 0.0265→0.0331, 넘어짐 0.63→0.67), 모터 0.4에서는 두 지표 모두 좋아진다. 반면 좁은 prior로 모은 데이터로 적응한 동역학은 넓은 prior를 **해친다**(F4). 설계 문서 4 §8의 "계획기는 안전을 깎는다"는 B(적응 동역학) 기준의 판단이었고, B0 기준으로는 성립하지 않는다 — 계획기의 해악은 **결합이 깨진 적응 동역학**에서 왔다.

## 2. 수학적 틀

기호: $\xi$ 물리 조건, $\nu_w$ 폭 $w$의 DR 분포, $h$ 히스토리, $a^*(h,\xi)$ 특권 전문가, $\pi_w$ = $\nu_w$ 전문가를 복제한 학생, $J_\xi(\pi)$ 조건 $\xi$에서의 성능, $\xi^0$ 정상, $\xi^\star$ 목표.

**(a) 강건화와 그 대가.** 학생은 $\xi$를 못 보므로 $\pi_w(h)\approx\mathbb{E}_{\xi\sim\nu_w|h}[a^*(h,\xi)]$. 전문가 자체가 $\nu_w$ 위에서 강건하면($S\approx0$) 이 평균은 손실 없이 하나의 행동 법칙이 된다. 대가 $c(w)=J_{\xi^0}(\pi_0)-J_{\xi^0}(\pi_w)$는 $\nu_w$가 커질수록 제약이 늘므로 **$w$에 단조 비감소**, 목표 성능 $J_{\xi^\star}(\pi_w)$는 $\nu_w\ni\xi^\star$가 되는 순간 **꺾여 포화**한다. (S가 0이 아닌 축에서는 평균이 어떤 조건에도 맞지 않는 행동이 되어 대가가 급증한다 — 이 실험에서는 관찰되지 않은 경우.)

**(b) 계획기의 회복.** MPPI는 $\pi_w$ 주변의 국소 탐색이다(설계 문서 3 명제 5). 모델 $\hat f$가 방문 영역에서 정확하면 계획은 $\pi_w$의 보수성을 그 조건에 맞게 되돌린다: $J_\xi(\text{MPPI}[\pi_w,\hat f])\ge J_\xi(\pi_w)$, 회복량은 $c(w)$의 일부. 정상 조건은 사전학습 분포 안이므로 $\hat f$가 정확하고 회복이 크다. 모터 0.4는 사전학습 밖이지만 F3가 보이듯 회복이 있다(강건한 prior 주변에서는 모델 오차도 작다 — 1절의 "하중 대비 토크 부족"은 PD 추종 지연으로 보여 $\hat f$가 부분적으로 외삽한다).

**(c) prior-first 적응.** 적응 데이터 $D_c$는 prior $\pi_c$가 모은 것이고, 적응된 $\hat f_c$의 오차는 집중성 $\sup \rho_{\pi_e}/p_{D_c}$에 비례한다(설계 문서 5 §2). $\pi_c$ 좁고 $\pi_e$ 넓으면 집중성이 터진다(F4). $\pi_c=\pi_e=\pi_w$이면 집중성이 최소이고, 적응은 사전학습 모델이 틀린 곳(목표 조건)에서만 이득을 준다. 예측: $B'\le B0<B$.

## 3. 실험

재료: 전문가 5개(모터 DR 없음 = 정상 전문가 `2026-10-01_10-38-36`; 0.9–1.1; 0.7–1.1; 0.5–1.1; 0.3–1.1 = `2026-10-20_07-40-06`), 각 데이터 1.9M 스텝(물리 라벨 포함), 학생 5개(BC, 20k 스텝), 사전학습 월드모델 `go1_paper`. 평가는 배치 18대 × 100초, 넘어짐/1000스텝과 보상/스텝, 짝지은 부트스트랩 CI.

**E1 폭 sweep (P1·P2).** 폭 5개 × {D 학생 단독, B0 학생+계획기+사전학습 동역학} × 조건 {정상, 모터 0.6, 모터 0.4} = 30회(약 2.5시간). 각 데이터에 $S_{\text{모터}}$ probe(행동열 이득)도 잰다.

**E2 prior-first 적응 (P3).** 조건 {모터 0.4, 정상}에서 B0로 45k 스텝 수집 → SimDist 동역학 적응(`dyn_b45000_term` 레시피) → B′ = 넓은 학생 + 계획기 + 그 동역학. 비교: B0, B(기존, 좁은 prior 데이터), B′. 구현: 배치 시뮬레이터에 실로봇 형식 로깅(또는 단일 시뮬레이터에 학생 prior) 추가.

**E3 하드웨어 (2단계, 계획서와 동일 틀, 모델 교체).** 조건 평지 정상 / 토크 60 % / 토크 40 % / 적재 3 kg. 모델: SimDist(`go1_finetuned_r3`), 넓은 학생 단독, 넓은 학생 + 계획기(사전학습 동역학), 넓은 학생 + 계획기 + prior-first 10분 적응. 세션 전 예측 기록.

## 4. 예측 (실험 전 기록)

- **P1 (강건화 대가)**: D의 정상 보상은 폭이 넓을수록 단조 감소(5점 Spearman = −1). D의 모터 0.4 넘어짐은 0.5–1.1까지 높고(0.4 미포함) 0.3–1.1에서 꺾여 내려간다(포화점 = 목표를 덮는 폭). $S_{\text{모터}}$는 모든 폭에서 ≈ 0 (강건화, 식별 없음).
- **P2 (계획기 회복)**: 폭 ≥ 0.5–1.1에서 정상 조건 B0의 보상은 D 대비 격차 $(D_0-D_w)$의 **50 % 이상** 회복하고, 넘어짐 비 B0/D의 95 % CI는 1을 포함하거나 아래에 있다. 모터 0.4에서 B0 ≤ D (넘어짐·보상 모두).
- **P3 (prior-first)**: 모터 0.4에서 B′ 넘어짐 ≤ B0 (CI), B′ < B (CI가 1 제외). 정상에서 B′ ≈ B0 (적응이 해치지 않음).
- **P4 (하드웨어, 2단계 전 재기록)**: 토크 40 %에서 넓은 학생(+계획기)이 SimDist보다 덜 넘어지고, 정상에서 학생+계획기가 학생 단독보다 빠르다.

## 5. 관문

- P1·P2 성립 → 논문 주장 확정: "시뮬 사전학습 월드모델 계획기에서 실세계 적응은 **prior-first**다: 목표 범위는 강건한 DR prior로 덮고(대가는 계획기가 회복), 실데이터는 그 prior로 모아 적응한다." E2·E3로 간다.
- P2 불성립 (계획기가 대가를 못 되찾거나 넘어짐을 늘림) → 계획기 없는 "강건 prior + 적응" 논문으로 축소. 주장은 C1·C4.
- P1 불성립 (대가가 단조가 아님 / 포화가 없음) → 강건화 틀 자체가 흔들림. 정지하고 재검토.
- P3 불성립 (B′ > B0) → 적응 없이 B0로 하드웨어. C4는 "적응은 prior에 묶여 있고 이득이 없다"로 보고.

## 6. 위험

- 폭 sweep 전문가의 PPO 분산: 시드 1개씩이라 단조성이 시드 노이즈에 묻힐 수 있음 → 정상 보상의 차이가 CI 밖인지로 판정하고, 애매하면 폭 2개만 시드 추가.
- 첫 전문가 실행이 CUDA 오류로 죽음(2026-10-21 19:48): 기본 4096 환경이 3060 12 GB에서 OOM(Xid 31). 넓은 전문가와 같은 1024 환경으로 재실행.
- 계획기 회복이 정상 조건에서만 나오고 목표 조건에서는 없을 수 있음 → P2의 모터 0.4 부분은 "≤ D"로 약하게 둠.
- 집중성 주장(c)은 직접 재지 않고 B/B0/B′ 순서로만 지지 → Limitations에 명시.
- 자원: 전문가 3개 18시간(3060, 진행 중), 데이터·학생 5시간, 평가 3시간, 적응 2회 4시간. 11/1 전 완료 가능.

### 7.1 예측 대조

- **P1 커버리지 쪽: 성립.** 모터 0.4 넘어짐은 DR 하한이 0.7까지는 전혀 안 변하고(9.6–11.4), 0.5에서 절반 이하(4.3), 0.3(목표 포함)에서 2.3. 계획기를 얹어도 같은 곡선(10.3–12.9 → 3.6 → 2.2). 목표를 덮는 폭에서 꺾인다는 예측대로이고, 강건한 보행은 범위 밖으로 조금(0.5→0.4) 외삽된다.
- **P1 정상 대가 쪽: 판정 불가 → 사실상 불성립.** 학생 단독의 정상 보상은 폭에 단조가 아니다(0.0253 / 0.0253 / 0.0159 / 0.0255 / **0.0293**: 가장 넓은 폭이 가장 좋다). 학생 단독 수치는 폭이 아니라 학생·전문가 편차가 지배한다: 같은 "DR 없음"인데 1.9M 스텝 데이터의 새 학생은 2.34, 사전학습 데이터 전체로 학습한 옛 학생은 0.60. **설계 문서 4의 "넓은 prior의 정상 대가 −17 %"는 학생 학습 데이터 양의 차이였다. 철회한다.** 계획기 위에서는 넓은 폭의 정상 보상이 조금 낮다(B0: 0.0312 대 0.0359–0.0370, −13 %)—대가는 있으나 폭에 단조는 아니다(0.5–1.1은 0.0341).
- **P2 계획기 회복: 성립, 예측보다 강함.** 정상·모터 0.6에서 계획기는 모든 폭의 학생 넘어짐을 15–62 %로 줄이고 보상을 올린다(CI가 1을 제외). 다만 **넓은 폭(0.3–1.1)에서는 작다**(정상 0.85 [0.70, 1.05], +0.002). 모터 0.4에서는 **prior가 덮지 못한 폭에서 계획기가 넘어짐을 전혀 못 줄이고**(1.02–1.14, 오히려 늘림) 보상만 조금 올린다; 덮는 폭에서는 D ≈ B0.

### 7.2 읽기

1. **커버리지는 prior가 정하고, 계획기는 그것을 바꾸지 못한다.** 사전학습 동역학 위의 계획기는 prior 범위 밖(모터 0.4, 좁은 폭)에서 넘어짐 10/1000을 그대로 둔다. 설계 문서 4 명제 7("계획의 가치는 커버리지가 끝나는 곳에서 시작한다")의 **반대**다: 계획의 가치는 커버리지 **안**에서만 있다.
2. **계획기가 되찾는 것은 "DR의 대가"가 아니라 "학생의 불완전함"이다.** 좁은 학생일수록 계획기의 이득이 크고(넘어짐 0.22–0.38배), 넓고 좋은 학생에서는 이득이 거의 없다. 즉 계획기는 BC prior의 복합 오차(compounding error)를 월드모델로 고치는 장치다 — 이것이 "왜 계획인가"의 측정된 답이다.
3. DR 폭의 정상 대가는 작고 비단조이며, 학생 데이터 양의 효과에 묻힌다. 폭 설계 규칙(설계 문서 5 C3)은 "목표를 덮을 만큼 넓게"로 충분하고, 그 이상의 수식은 이 데이터가 지지하지 않는다.

### 7.3 관문 적용

P1(커버리지)·P2 성립 → E2(prior-first 적응)·E3(하드웨어)로 간다. 논문 주장은 다음으로 다듬는다: "실세계 적응 전에 prior가 목표를 덮어야 한다(계획기도 적응 동역학도 그것을 대신 못 한다); 계획기는 prior의 복합 오차를 되찾는다; 적응 데이터는 그 prior로 모은다." 정상 대가 수식(C3)은 뺀다.

| 정상 | 0.68 · 0.0330 | – | **0.50 · 0.0348** | 0.74 [0.55, 0.98], 보상 +0.0018 [+0.0004, +0.0031] | – |

- **P3 성립**: $B' \le B0 < B$. 모터 0.4에서 B′ = B0(적응이 해치지 않음), B는 B0의 2.15배 [1.64, 2.78] — 좁은 prior로 모은 데이터로 적응한 동역학이 넓은 prior를 해친다는 결합(설계 문서 4 B0 > B)이 18쌍에서 확인됐다. 정상에서는 prior-first 적응이 **유의하게 좋아진다**(넘어짐 −26 %, 보상 +5 %): 배포할 prior의 분포에서 동역학을 다듬는 효과.
- 모터 0.4에서 적응 이득이 0인 이유: 강건한 prior 주변에서는 사전학습 동역학이 이미 충분히 맞는다(E1: B0 ≈ D). 적응이 값을 하는 곳은 "prior가 덮지만 모델이 틀린" 조건인데, 모터 0.4는 그 조건이 아니었다. 정상 조건의 이득은 그 조건이 (사전학습 분포 안이어도) 존재함을 보인다.

**관문**: P1(커버리지)·P2·P3 성립 → E3 하드웨어. 논문 주장(최종 형태):
1. 실세계 적응 전에 prior가 목표를 덮어야 한다 — 계획기도 적응 동역학도 커버리지를 대신 못 한다 (E1 모터 0.4, 좁은 폭에서 10/1000 그대로).
2. 계획기는 prior의 복합 오차를 월드모델로 되찾는다 (E1 정상·모터 0.6, 모든 폭).
3. 적응 데이터는 배포할 prior로 모아야 한다 — 다른 prior의 데이터는 해치고(B, 2.15배), 같은 prior의 데이터는 돕거나 적어도 해치지 않는다 (E2).

## 9. E3 하드웨어 계획 (2026-10-25 확정, 사용자 위임)

**결정 1 — 토크 상한 구현**: 브리지(`go1_bridge.cpp`)에서 호스트 측 PD를 계산해 $|\tau|\le s\cdot 23.7$ N·m(시뮬 effort limit과 같음)로 자른 뒤 토크 전용 명령으로 보낸다(500 Hz, `go1.torque_scale` 파라미터, 0.3–1.0으로 제한). Kp·Kd 축소가 아니라 포화이므로 시뮬 조건과 같은 현상이다. 60 %에서 끈을 걸고 먼저 확인한 뒤 40 %로 간다. 브리지는 넘어짐 잠금 시 `/fallen`을 발행하고, 컨트롤러 노드는 에피소드 로그에 `terminated`를 기록한다. 컨트롤러 설정에 `prior.student`(학생 prior)와 `mppi.prior_only`(학생 단독)를 추가했다. 두 패키지 컨테이너에서 빌드 확인.

**결정 2 — 일정**: 11월 둘째 주부터 세션 4회(각 2시간). 12/4 초록까지 3주 여유.

**조건과 모델**
| 조건 | 평지 정상 | 토크 60 % | 토크 40 % | 적재 3 kg |
|---|---|---|---|---|
모델: (M1) SimDist `go1_finetuned_r3` (좁은 prior, 29.5분 실데이터 적응) / (M2) 넓은 학생 단독 (`student_broad`, prior_only) / (M3) 넓은 학생 + 계획기 + 사전학습 `go1_paper` / (M4) M3 + prior-first 적응: M3로 10분 수집 → 동역학 적응. 비교 참고 (M5) 넓은 학생 + 계획기 + **r3 데이터로 적응한 동역학**(좁은 prior로 모은 실데이터 = 결합 B의 하드웨어판; 추가 수집 없음).

**세션 전 예측 (지금 기록)**
- H1 (커버리지): 토크 40 %에서 M1은 넘어지거나 서 있고(시뮬 모터 0.4의 좁은 폭처럼), M2·M3는 걷는다. 토크 60 %에서는 차이가 작다.
- H2 (계획기의 회복): 정상·토크 60 %에서 M3는 M2보다 넘어짐이 적고 속도 추종이 좋다. **실로봇에서는 시뮬보다 격차가 크다** — 실로봇 학생은 sim-to-real 간극만큼 더 불완전하므로 계획기가 고칠 복합 오차가 더 많다.
- H3 (prior-first): M4 ≤ M3 (해치지 않음), M5 > M3 (r3 데이터로 적응한 동역학은 넓은 prior를 해친다). 정상 조건에서 M4 < M3이면 시뮬 E2의 정상 이득이 재현된 것.

# 연구 계획: Coverage Before Adaptation — 시뮬 사전학습 월드모델 계획기의 실세계 적응에서 무엇을 랜덤화하고 무엇을 적응할 것인가

작성 2026-10-21. 설계 문서 1~5와 조사 보고서 5편을 하나의 흐름으로 묶는다. 목표 학회 RSS 2027 (초록 12/4, 최종 4/16). 자원: Go1 1대, 3060(로봇·평가), 4090(전문가 학습), A100 12시간 창(선택).

---

## 0. 한 문장

**어떤 동역학 변화를 시뮬 사전학습으로 덮을 수 있는지는 그 변화가 로봇의 히스토리에 얼마나 드러나는지로 정해지고, 그 가시성으로 축별 랜덤화 폭과 실데이터 적응의 자리가 계산되며, 적응 데이터는 덮인 prior로 모아야 한다.**

## 1. 주장의 사슬 (각각 증거가 붙는다)

| # | 주장 | 이미 있는 증거 | 더 필요한 증거 |
|---|---|---|---|
| C1 | 적응 후 성능을 정하는 것은 동역학·값의 정확도가 아니라 prior의 커버리지다 | 문서 1~4: 값 교정 −13 % n.s., 동역학 손실 실패, oracle −60 %, 커버리지 −73 % 대 적응 −17 % | 하드웨어 확인 |
| C2 | 커버리지는 "히스토리에 드러나는" 축에서만 생긴다 (가시성 $V_j$) | 모터(됨)·마찰/적재(안 됨)의 정성 관찰 | $V_j$ 측정과 성능의 상관 (0단계) |
| C3 | 축별 랜덤화 폭에는 계산 가능한 최적이 있다: $J_j(w)=S_j[(1-V_j)\tfrac{w^2}{3}(1+\lambda)+\mathbb{E}(\lvert\xi^*_j-\xi^0_j\rvert-w)_+^2]$ | 넓은 prior의 정상 대가 −17 % | 폭 sweep 곡선 (1단계) |
| C4 | 실데이터 적응은 가시성이 낮은 변화의 자리이며, 덮인 prior로 모은 데이터여야 한다 (결합) | B0 > B | prior-first 적응 B′ > B0 (1단계) |
| C5 | 위 결정은 실로봇에서 라벨 없이 내릴 수 있고, 결과를 사전에 예측한다 | – | 하드웨어 예측·확인 (2단계) |

C1~C4가 시뮬, C5가 하드웨어. 계획기의 잔여 실패(결과 기반 하드 필터)는 **확장 단계**로 미룬다 (RSS 2단계 Extension Charter 또는 다음 논문).

## 2. 수학적 틀 (설계 문서 5 + 축별 폭 공식)

- 기호: $\xi$ 물리 조건, $\nu$ DR 분포, $\tau$ 목표 조건 분포, $h$ 히스토리, $a^*(h,\xi)$ 특권 전문가, $\pi$ BC prior, $q_{\xi^*}$ 질의 분포.
- 분해: 배포 오차 ≲ 모호성 $\mathbb{E}_h\mathrm{Var}_{\xi|h}[a^*]$ + 집중성 $C/n$ + 근사.
- 축별 양: 민감도 $S_j=\mathbb{E}\|\partial a^*/\partial\xi_j\|^2$, 가시성 $V_j=1-\mathbb{E}_h\mathrm{Var}(\xi_j|h)/\mathrm{Var}_\nu(\xi_j)$ (probe $R^2$).
- 폭 공식 $J_j(w)$와 결정 규칙: $V_j\to1$이면 목표 범위까지, $V_j\to0$이면 안쪽에서 멈춤. 우선순위 $S_jV_j$.
- 라벨 없는 가시성(실로봇): 히스토리 조건부 예측기와 무조건 예측기의 오차 차. 시뮬에서 $V_j$와의 일치로 검증.
- 집중성 $C=\sup\rho(a|h)/p_D(a|h)$: 동역학 데이터의 행동 혼합 기준 (확장 단계).

## 3. 단계와 관문

### 0단계 — 측정 (10/22–10/27, GPU 소량)
구현: 데이터 생성기에 $\xi$ 기록(모터 스케일·마찰·질량, 환경별). 재생성: 좁은(정상)·넓은(go1dr) 데이터 각 2M 스텝 (40분씩).
측정:
- $V_j$: 히스토리 → $\xi_j$ probe, 축별 $R^2$ (좁은·넓은 데이터, 보류 분할).
- $S_j$: 전문가를 같은 상태에서 $\xi\pm\delta e_j$로 평가해 행동 차이.
- 라벨 없는 가시성: 조건별 배포 로그에서 히스토리 유무 예측기 오차 차 → $V_j$와 비교.
- 조건별 학생 BC 보류 오차(모호성) ↔ 학생 단독 넘어짐 (문서 4 데이터 + 조건 2개 추가 평가).
**예측 P0**: $V_{\text{모터}}>0.7$, $V_{\text{마찰}}<0.4$, $V_{\text{질량}}<0.5$; 축 순위 = 성능 순위; 모호성–넘어짐 Spearman > 0.8.
**관문 0**: P0 성립 → 1단계. 불성립 → 가시성 정의를 고치거나(히스토리 길이·특징) 틀 폐기. 폐기 시 분석 논문으로 전환.

**관문 0 결과 (2026-10-21, 설계 문서 5 §7)**: **P0 불성립.** $V_{\text{모터}}=0.004$(넓은 데이터), $V_{\text{질량}}=0.71$–$0.87$, $V_{\text{마찰}}\le0.36$; 모든 축에서 $S_j\approx0$(전문가 행동은 히스토리 이상으로 $\xi$에 의존하지 않음). 넓은 전문가는 모터 세기를 식별하지 않고 **강건한 보행 하나**로 덮었다. 축별 학생 저하 순위(combo > 모터 0.4 ≈ 적재 > 저마찰 > 모터 0.6 ≈ 정상)는 가시성 순위와도 DR 범위와도 맞지 않는다. 라벨 없는 가시성 두 정의(예측 이득, probe 적용) 모두 변화를 구분하지 못한다. → C2·C5 폐기, C3는 "정상 대가 대 범위" 절충으로 퇴화. **1단계로 가지 않는다.** 선택지는 설계 문서 5 §7.7 (A 강건화-대-식별 틀, B 분석 논문). 사용자 결정 대기.

### 1단계 — 설계 규칙 검증 (10/28–11/7, 4090 30시간 + 3060 평가)
- 모터 폭 sweep: 전문가 5개(폭 0 / 0.3 / 0.5 / 0.7 / 0.9 반폭 상당, 4090 각 6시간) → 학생 5개 → 모터 0.4·정상·모터 0.6 평가. **예측 P1**: 정상 보상은 $w^2$ 꼴로 감소, 모터 0.4 넘어짐은 $w$가 목표를 덮는 지점에서 꺾여 포화; $J(w)$ 최소가 내부.
- 마찰 축 가시성 올리기: 탐침 행동(속도 변화·급정지) 섞은 데이터로 학생 학습. **예측 P2**: $V_{\text{마찰}}$ 상승, 저마찰 넘어짐 −30 %, 정상 대가 측정.
- prior-first 적응: 넓은 학생으로 15분 수집 → 동역학 적응 → 넓은 학생 + 적응 동역학(B′). **예측 P3**: B′ < B0 < B (넘어짐).
- 계획기 대 학생 표 완성(학생 단독 / 학생+계획기 / 학생+적응 계획기), 보상과 넘어짐 분리 보고.
**관문 1**: P1·P3 성립 → 2단계. P1만 성립 → C4 없이 진행. 둘 다 불성립 → 분석 논문.

### 2단계 — 하드웨어 (11/8–11/24, 세션 4회)
구현: 브리지에 토크 상한 옵션(소프트웨어 모터 약화 100/60/40 %), ROS 컨트롤러 노드에 학생 prior·학생 단독 모드, 종단(넘어짐 잠금·RECOVERY) 로깅.
조건: 평지 정상, 토크 60 %, 토크 40 %, 적재 +3 kg, 폼 매트. 모델: SimDist(`go1_finetuned_r3`), 넓은 학생 단독, 넓은 학생 + 계획기(+prior-first 적응 데이터 10분).
**예측을 세션 전에 기록**: 라벨 없는 가시성이 큰 조건(토크)에서는 학생이 SimDist를 이기고, 작은 조건(적재·폼)에서는 비슷하거나 못하며 적응이 필요하다. 조건당 모델당 10회, 지표: 넘어짐·속도 추종·거리.
**관문 2**: 예측 적중 조건 ≥ 2/3 → 초록 작성. 아니면 하드웨어 절을 "정상 조건 망각 없음"으로 축소하고 시뮬 중심 초록.

### 3단계 — 초록 (11/24–12/3)
5쪽: 서론(C1 동기, 설계 문서 1~3의 음성 결과 요약) / 틀(2절) / 시뮬 결과(0·1단계) / 하드웨어 예측·확인 / Limitations. 선점 재검색(Margolis CoRL 2023 능동 감지, Semantic Scholar 최신 인용).

### 확장 단계 (RSS 2단계 1–4월, 또는 다음 논문)
- 결과 기반 넘어짐 위험 헤드의 하드 후보 필터 (조사 1순위): 계획기가 학생보다 더 넘어지는 문제의 처방.
- 동역학 데이터의 집중성 기준(행동 혼합) — A100 창에서 월드모델 재사전학습 1~2회.
- Go2 시뮬로 두 번째 임바디먼트, 벤치마크·도구 공개.

## 5. 위험과 대비
- 가시성 측정이 성능을 설명 못 함 → 관문 0에서 중단, 분석 논문.
- 폭 sweep이 $J(w)$ 형태를 안 따름 → C3를 "경향"으로 약화, 결정 규칙은 순위($S_jV_j$)만 주장.
- 하드웨어 토크 상한이 시뮬 모터 약화와 다른 현상을 냄 → 60 %에서 먼저 잔차·가시성을 재고 조건을 조정.
- "RMA의 데이터 설계" 반론 → 답: 측정 가능한 기준($V_j$, $J_j$)과 계획기·적응 절차까지 포함하는 틀, 그리고 B0 > B(결합)는 정책 논문에 없는 발견.
- 선점(CLAW 수집 정책, Margolis 능동 감지) → 가시성 **측정**과 적응 **순서**를 헤드라인으로, 수집 최적화는 주장하지 않음.
- 넘어짐 희소성(실로봇) → 토크 상한 조건은 안전하게 넘어짐을 유도하므로 결과 데이터가 생김; 끈 필수.

# 설계 문서 3: 계획기의 prior 갱신 — 실데이터로 지도를 고친 뒤, 습관은 상상으로 다시 들인다

작성 2026-10-19. 선행: 설계 문서 1(값), 2(동역학), 보고서 `reports/다음 연구 아이디어 결정 조사.md`.
컨셉: 사전학습은 건드리지 않는다. 실세계 적응 단계에서 계획기를 막는 모듈을 메커니즘으로 찾아 그것만 고친다.

## 1. 질문

동역학 $f$를 실데이터로 고친 뒤에도 계획기는 약한 모터에서 6초마다 넘어진다. 값(설계 문서 1)과 경계 동역학(설계 문서 2)은 원인이 아니었다. **남은 얼린 모듈인 기본 정책 $\pi$(계획기가 후보를 뽑는 중심 = prior)가 원인인가? 그렇다면 $\pi$를 적응된 $f$로 상상 속에서 다시 최적화하면, 추가 실데이터 없이 넘어짐이 줄어드는가?**

## 2. 분석: MPPI는 국소 탐색이고, 탐색 영역은 prior와 warm start가 정한다

`simdist/control/mppi.py` (우리 설정 200×3):
- 후보 222개 = 중심 $\mu$ 주변 노이즈 200개 + $\pi$ 출력 주변 노이즈 22개(5 %).
- 중심 $\mu$의 초기값 = **이전 스텝의 계획을 한 칸 민 것**(warm start). 노이즈 폭은 초기 2.0에서 엘리트 64개의 표준편차로 즉시 줄어든다(하한 0.05).
- 행동 공간은 25스텝 × 12관절 = 300차원. 200개 샘플은 이 공간에서 $\mu$ 근처의 국소 탐색일 뿐이다.

**명제 5.** 반복 수와 샘플 수를 늘려도 MPPI는 $\{\mu, \pi(x)\}$ 가 가리키는 영역의 바깥을 보지 못한다. 좋은 행동이 그 영역 밖에 있으면 샘플 수는 무력하다. (우리 측정: 450×8 ≈ 200×3.)

**명제 6.** 느린 붕괴(2~4초)를 피하려면 붕괴 **전에** 다른 걸음을 골라야 하고, 그 시점의 후보 간 수익 차는 0.4(감도 4 미만)이므로 선택은 값이 아니라 탐색 영역의 위치가 결정한다. (우리 측정: 넘어짐 4초 전 수익 하락 29 %.)

**따름 2.** 동역학 변화로 좋은 영역이 옮겨졌는데 $\pi$와 warm start는 시뮬 영역에 남아 있다면, (i) 영역을 억지로 넓혀도(노이즈 ↑) 300차원에서 200개로는 못 찾고, (ii) 영역을 **옮기면**(좋은 $\pi$) 바로 찾는다. 특권 전문가가 같은 조건에서 걷는다는 사실이 "좋은 영역이 존재한다"의 증거다.

## 3. 측정 (학습 없이, 설정과 oracle로 전제를 확인)

모두 `dyn_b45000_term`(동역학만 적응, 시뮬 $\pi$) 체크포인트, 모터 40 %, 배치 평가 18대(속도 3 × 시드 6) × 5000스텝, 정상 조건 동시.

| 번호 | 조작 | 묻는 것 |
|---|---|---|
| M1 | warm start 제거 (매 스텝 $\mu$=0 또는 $\mu=\pi(x)$) | 관성이 영역을 가두는가 |
| M2 | 노이즈 폭 ×2, ×4; 엘리트 16 | 영역을 넓히면 찾아지는가 (명제 5의 예측: 아니다) |
| M3 | $\pi$ 샘플 비율 0 % / 5 % / 50 % | 시뮬 $\pi$가 돕는가, 해치는가 |
| **M4 (oracle)** | 매 스텝 $\mu$를 **특권 전문가의 현재 행동**을 지평 길이만큼 반복한 것으로 초기화 | 영역을 옳은 곳으로 옮기면 계획기가 걷는가 — **전제의 결정적 검증** |
| M5 | 전문가 단독 (이미 있음: 0.40 넘어짐/1000) | 상한 |

M4는 전문가의 특권 관측이 시뮬에서만 가능하므로 oracle이다. 실로봇에서는 쓸 수 없고, 그 자리를 4절의 방법이 대신한다.

## 4. 방법: $\pi$를 적응된 $f$로 상상 속에서 재최적화

실데이터 윈도우의 입력 $x$(히스토리, 현재 잠재, 명령)에서
$$\max_\theta\; \mathbb{E}_x\Big[\sum_{k} \gamma^k R(\hat z_k, a_k) + \gamma^{T+1} V_{\mathrm{sim}}(\hat z_T)\Big] - \beta\, \big\|\pi_\theta(x) - \pi_{\mathrm{sim}}(x)\big\|^2,\quad a = \pi_\theta(x),\ \hat z = f_{\mathrm{adapted}}(z_t, a, h)$$
- 기울기는 미분 가능한 $f$를 통해 $\pi_\theta$(policy, policy_dec)로만 흐른다. $f, R, V, E, C$ 고정.
- 닻: $\pi_{\mathrm{sim}}$의 얼린 사본과의 거리(β). 시뮬 보행에서 너무 멀어지는 것(모델 착취)을 막는다.
- 종단은 $V_{\mathrm{sim}}$ 고정(값 재최적화는 하지 않는다. 설계 문서 1이 값 교정의 행동 이득이 작음을 보였고, 여기서는 변수를 하나만 바꾼다).
- 구현: 기존 trainer에 손실 `policy_refresh`와 heads `policy`를 추가하면 된다(heads 필터가 `policy`, `policy_dec`를 잡음). 앵커는 `add_policy_anchor()`(값 앵커와 같은 방식). 학습 데이터는 같은 15분 윈도우, 1000~3000스텝, $\beta \in \{0.1, 1\}$.
- 배포: 갱신된 $\pi$를 가진 체크포인트를 MPPI가 그대로 쓴다. 추가로 M3의 결과에 따라 $\pi$ 샘플 비율을 올린 설정도 평가한다.

왜 상상인가: 실데이터로 $\pi$를 학습하면(BC) 실데이터의 행동 = 시뮬 $\pi$로 계획된 행동이라 새 영역을 못 배운다. 적응된 $f$ 안에서 수익을 최대화해야 새 영역이 나온다. 위험(모델 착취)은 7절.

## 5. 예측 (실험 전 기록)

- P1 (전제, M4): 전문가 행동으로 중심을 옮기면 동역학만 모델의 넘어짐이 **50 % 이상** 준다 (3.0 → 1.5 이하, CI 0 제외).
- P2 (명제 5, M2): 노이즈 폭·엘리트 변경은 넘어짐을 30 % 이상 줄이지 못한다.
- P3 (방법): 상상 속 재최적화 $\pi$는 M4 이득의 **50 % 이상**을 회복한다 (넘어짐 25 % 이상 감소, CI 0 제외), 정상 조건의 넘어짐·보상은 유지.
- P4 (연산): 갱신된 $\pi$의 200×3이 시뮬 $\pi$의 450×8보다 넘어짐이 적다.
- P5 (음성 대조): combo_hard에서는 M4도 방법도 차이가 없다 (새 실패 모드 없음).

## 6. 실험과 판정

**관문 1 (3절, 학습 없음, 약 1일 GPU)**: M1~M4.
- P1 성립 → 전제 확인, 4절 구현으로 진행.
- P1 불성립(oracle로 옮겨도 안 걸음) → 계획기 영역 가설 기각. 남는 설명은 지평·동역학 표현이며, 이 연구선은 분석 논문으로 종료.

**관문 2 (4절, 구현 2일 + 학습·평가 1일)**: $\beta$ 2개 × $\pi$ 샘플 비율 2개.
- P3 성립 → 논문 주장 확정. 실로봇(폼 매트 고속: 적응 전 / 동역학만 / 동역학+갱신 $\pi$, 조건당 10회, 끈)으로 진행.
- P3 불성립이되 M4는 성립 → 상상 속 최적화가 모델을 착취한다는 뜻. 대안 하나만: 상상 대신 **무거운 MPPI(1000×16)의 계획을 $\pi$로 증류**(계획기가 찾은 행동을 모방; 착취 위험 작음). 그것도 안 되면 "oracle은 되지만 실용 방법은 못 찾음"으로 분석 논문.

**지표**: 1000스텝당 넘어짐(주), 스텝당 보상, 정상 조건 동일 지표, $\pi$의 시뮬 $\pi$ 대비 거리(망각), 18쌍 부트스트랩 CI.

## 7. 위험

- **모델 착취**: 상상 속에서 $\pi$가 $f$의 오류를 파고들어 실제로는 넘어지는 행동을 "좋다"고 배울 수 있다 (RWM, DiWA의 보고). 대책: β 닻, 짧은 지평(T=25 그대로), 종단 $V_{\mathrm{sim}}$ 고정, 그리고 **MPPI가 여전히 후보를 $f$로 평가해 고르므로** $\pi$는 중심만 옮긴다. 착취가 심하면 관문 2의 증류 대안.
- **닻이 너무 강하면** 시뮬 보행에 묶여 새 영역을 못 간다. β를 두 값으로.
- **oracle의 한계**: M4는 전문가 행동을 25스텝 반복하는 조악한 초기화라, 성립해도 "최적 영역"의 상한이 아니라 하한 추정이다. 불성립하면 더 강한 oracle(전문가 행동을 매 스텝 중심으로 + 노이즈 폭 축소) 하나만 추가.
- **실로봇에서의 조건**: 모터 약화를 하드웨어에서 못 만든다. 폼 매트 고속(SimDist 데이터에서 적응 전 0/5)을 새 실패 모드 조건으로 쓴다. 폼 데이터 10분 수집이 추가로 필요하다.

## 8. 이 문서가 바꾸는 것

논문의 주장이 **"실세계 적응에서 실데이터로 고칠 것은 동역학이고, 계획기의 prior는 고쳐진 동역학으로 다시 최적화해야 한다"**로 정해진다. 설계 문서 1·2의 결과(값·동역학 정확도는 병목이 아님)가 "왜 prior인가"의 소거 논증이 되고, 3절의 oracle이 "prior가 맞다"의 직접 증거, 4절이 처방이다.

학습 중 상상 속 수익은 개선됐다 (β=0.1: −0.41 → −0.78, β=1.0: −0.37 → −0.60; 시뮬 π와의 거리 0.07 / 0.15). 실제 배포는 전 조건에서 붕괴했다. **상상 속에서 좋아지고 실제에서 나빠지는 것 = 모델 착취**(7절의 첫 번째 위험 그대로; RWM·DiWA의 보고와 일치). 앵커 β=1.0으로도 막지 못했고, 정상 조건까지 망가졌다 (정책이 적응된 동역학의 오차를 파고들어 실제로는 성립하지 않는 행동열을 배움).

**예측 대조**: P3(상상 재최적화가 M4 이득의 50 % 회복) **불성립, 반대 방향으로 대실패.** P4·P5 무의미.

**판정**: 6절 두 번째 갈래 — "M4는 성립, 방법은 불성립 = 상상 속 최적화가 모델을 착취." 사전 등록된 마지막 대안은 "무거운 MPPI(1000×16)의 계획을 π로 증류"다. 그러나 관문 1의 결과가 이 대안의 실패를 예측한다: 시뮬 π 주변의 계획기는 샘플을 늘려도(450×8 ≈ 200×3, 노이즈 ×4도 −14 %) 좋은 영역을 못 찾으므로, 그 계획을 증류한 π는 같은 영역에 남는다. 증류가 의미 있으려면 **전문가로 초기화한 계획기(M4)의 계획**을 증류해야 하는데, 그 전문가는 시뮬에만 있다.

**이 판정이 뜻하는 것**
1. 확정된 사실: 계획기의 탐색 영역(prior)이 병목이다 (M4: −60 %, 18/18). 모델(값·동역학·데이터)은 아니다. 이것은 긍정적 발견이며 재현 가능하다.
2. 실패한 처방: 적응된 모델로 prior를 상상 속에서 재최적화하는 것. 15분 데이터로 적응한 모델은 300차원 행동 공간에서의 기울기 최적화를 버티지 못한다. 앵커로는 부족하고, RWM-U처럼 불확실성 패널티(앙상블)가 있어야 할 가능성이 크지만 3060에서는 비용이 크다.
3. 남는 길 둘: (a) prior를 **사전학습 단계에서** 옮겨진 조건까지 덮도록 만든다 — 전문가가 약한 모터에서도 걷는다는 것은 전문가 데이터를 넓은 랜덤화 아래 생성하면 π도 그 영역을 배울 수 있다는 뜻 (주제 1, 사전학습 데이터·커버리지). (b) 실로봇에서 prior를 model-free로 적응한다 (SLowRL 계열; 다른 연구선).
4. 논문으로서는: "실데이터 적응 뒤 남는 실패의 원인은 prior이며(oracle 증명), 모델 교정으로는 안 되고(세 번의 음성 결과), 상상 속 재최적화도 착취로 실패한다" — 분석 논문으로서 완결성은 있다. RSS급 긍정 처방은 없다.

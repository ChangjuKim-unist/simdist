# 설계 문서 4: 계획기 prior의 커버리지 — 계획이 prior를 이기는 조건과, 그때 성능을 정하는 것

작성 2026-10-20. 선행: 설계 문서 3(관문 1 통과: prior가 병목; 관문 2 실패: 상상 재최적화는 착취), `reports/계획기 prior 관련연구 조사.md`.
컨셉: 사전학습 단계 중 **prior(π)의 학습 데이터만** 넓힌다. 월드모델(E, C, f, R, V)과 계획기(MPPI)는 그대로. 동역학 적응은 SimDist 방식 그대로.

---

## 1. 질문

1. 실세계 적응 뒤의 성능은 비싼 실데이터(동역학 적응)와 공짜 사전학습(prior 커버리지) 중 어느 쪽에 더 좌우되는가?
2. 넓은 prior를 가진 계획기는 **그 prior 정책 단독**보다 나은가? 나은 조건은 무엇인가?
3. 넓은 prior의 대가(정상 조건 정밀도, 보상)는 계획기 안에서 얼마인가?

## 2. 분석

- 설계 문서 3 관문 1: 같은 적응된 동역학 위에서 중심만 전문가 행동으로 옮기면 넘어짐 −60 %; π 샘플 0 %면 못 걸음. MPPI는 π 주변의 국소 탐색이다 (명제 5).
- SimDist의 사족 DR에는 모터 세기 항이 없다 (질량, 마찰, 강성만). 약한 모터는 π도 f도 본 적 없는 영역이다. 특권 전문가가 거기서 걷는 이유는 반응형 closed-loop + 특권 관측이고, 복제된 π(open-loop, 정상 조건 데이터)는 그 능력을 물려받지 못했다. RMA의 "적응 모듈 없는 학생은 8 kg 이상에서 실패"와 같은 구조.
- 문헌: 히스토리 조건 학생(RMA/HIM/ADAPT)은 모터 DR로 실제 액추에이터 변화를 견딘다. prior를 계획기 안에서 넓힌 연구는 없고, "계획기 + 넓은 prior 대 prior 단독"의 비교도 없다.

**명제 7.** prior가 조건을 덮으면(DR 안) 계획기는 prior의 국소 개선만 하므로 prior 단독과 비슷하거나 (지평 0.5초의 한계로) 약간 못하다. prior가 조건을 덮지 못하면(DR 밖) 계획기는 적응된 동역학으로 prior의 제안을 교정하므로 prior 단독보다 낫다. **계획의 가치는 prior의 커버리지가 끝나는 곳에서 시작한다.**

## 3. 방법 (재료 준비 + 한 가지 변경)

1. **넓은 전문가**: Go1 PPO를 모터 세기 U(0.3, 1.1) 랜덤화(에피소드마다)로 재학습 (`Go1DR` 과제; 나머지 DR은 SimDist와 동일). 약 10시간.
2. **학생 prior**: 넓은 전문가로 데이터를 생성(`go1dr`, 전문가 행동만, 수백만 스텝)하고, **과거 관측 25스텝 + 명령**만 입력받아 **25스텝 행동열**을 내는 작은 MLP를 BC로 학습. 특권 정보 없음. 조건은 히스토리에서 읽어야 한다. 같은 구조를 정상 조건 데이터(기존 사전학습 데이터)로도 학습해 "좁은 학생"을 만든다 (DR 폭 ablation).
3. **계획기 결합**: MPPI의 π 샘플(22개)을 학생의 출력으로 대체. 월드모델·동역학·값·계획기 설정은 그대로. 동역학 적응은 기존 `dyn_b45000_term` 그대로 사용.
4. **학생 단독**: 학생의 행동열 첫 스텝을 매 스텝 실행 (receding horizon). 계획기 없음.

## 4. 측정·실험 (배치 평가 18대 × 100초, 조건당)

| 군 | prior | 동역학 | 계획기 |
|---|---|---|---|
| A 기준 | 시뮬 π (좁음) | 적응 | 있음 |
| B | 넓은 학생 | 적응 | 있음 |
| B0 | 넓은 학생 | **적응 전** (go1_paper) | 있음 |
| C | 좁은 학생 | 적응 | 있음 |
| D | 넓은 학생 단독 | – | 없음 |
| E (상한) | 전문가 초기화 (관문 1 M4) | 적응 | 있음 |
| F | 전문가 단독 | – | 없음 |

조건: 모터 0.4 (DR 안), **모터 0.2 (DR 밖)**, 정상, combo_hard.

## 5. 예측 (실험 전 기록)

- P1 (prior 커버리지가 주 변수): B는 A 대비 넘어짐 **40 % 이상** 감소, E(−60 %)에 근접. C(좁은 학생)는 A와 같다.
- P2 (동역학 적응 대 커버리지): B0(적응 없는 동역학 + 넓은 prior)의 이득이 A(적응 + 좁은 prior)의 이득보다 크다 — "실데이터보다 커버리지".
- P3 (명제 7, DR 안): 모터 0.4에서 D(학생 단독) ≈ B 또는 D가 낫다.
- P4 (명제 7, DR 밖): 모터 0.2에서 B > D (계획기가 적응된 동역학으로 prior를 교정). 이것이 "왜 계획인가"의 답이다. 성립하지 않으면 보행에서 계획의 가치는 증명되지 않는다.
- P5 (대가): 정상 조건에서 B의 보상/스텝은 A 대비 10 % 이내 손실.

## 6. 판정

- P1·P4 성립 → 논문 주장 확정: "적응 후 성능은 prior 커버리지가 정하고, 계획은 커버리지 밖에서 값을 한다." 실로봇(폼 매트 고속 = 커버리지 밖 조건, 학생 단독 대 계획기 + 학생).
- P1 성립·P4 불성립 → "넓은 prior면 충분하고 계획기는 불필요"라는 패러다임 수준의 음성 결과. 그대로 보고(분석 논문).
- P1 불성립 → 학생이 전문가의 적응 능력을 BC로 물려받지 못한 것. 학생 입력(히스토리 길이)·구조 한 번만 바꿔 재시험, 안 되면 중단.

## 7. 위험

- 넓은 전문가가 정상 조건에서 보수적이 됨(Xie, DrEureka의 보고). P5로 측정.
- open-loop 25스텝 제안으로는 반응형 적응의 일부만 남을 수 있음. 관문 1 M4(행동 반복)가 −60 %였으므로 출발점은 있음.
- 모터 0.2는 물리적으로 보행이 불가능할 수 있음(전문가 단독 F로 확인; F가 못 걸으면 0.25로 조정).
- 전문가 재학습 10시간 + 데이터 생성 2시간 + 학생 학습 1시간 + 평가 약 20시간.

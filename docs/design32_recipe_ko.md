# 설계 32: 한 모델 적응 레시피의 재현과 성분 (A부) (2026-11-18 등록)

## 0. 배경

- 설계 31: 조건 토큰 모델(실제 데이터 + 사전학습 창 replay + 시뮬 계획기 창 replay)이 G1(이득)·G2(보존)를 통과했고 G3(토큰 오차 차이 신호)은 불통과였다.
- 그런데 토큰은 거의 쓰이지 않았다. 시뮬 토큰만 줘도 자기 조건 이득의 78~99 %가 나오고, 적응 토큰을 그대로 둬도 다른 범위 밖 조건에서 동역학 fine-tuning보다 4칸 모두 낮다. 이득과 보존은 공유 가중치에서 나왔다.
- 그래서 지금 모르는 것이 두 가지다.
  1. 설계 31의 통과는 칸마다 학습 시드 1개의 결과다. 다른 시드에서도 나오나?
  2. 무엇이 이득과 보존을 같이 만들었나? 설계 20의 replay(사전학습 창만)는 이득을 지웠다. 이번에 달라진 것은 시뮬 계획기 창과 토큰(FiLM 경로)이다.
- 설계 31 §5의 결정은 "토큰 모델 유지, 전환 신호를 실행 중 1스텝 오차로 바꿔 설계 32에 등록"이다. **순서를 나눈다.** 전환(B부)은 어떤 모델 위에 얹을지(토큰이 있는지 없는지)가 정해져야 설계할 수 있고, 설계 31의 통과가 재현돼야 의미가 있다. 그래서 A부(재현 + 성분)를 먼저 등록해 돌리고, B부(정책 출발 + 실행 중 오차로 전환, 새 평가 시드)는 A부 결과가 나온 뒤 이 문서에 추가 등록한다.

## 1. 질문

- **R (재현).** 학습 시드를 바꿔도 설계 31의 G1·G2가 통과하나? 전환 없이 적응 토큰을 그대로 둬도 다른 범위 밖 조건에서 사전학습 수준인가?
- **A (성분).** 토큰을 빼거나 시뮬 계획기 창을 빼면 이득과 보존 중 무엇이 사라지나?

## 2. 팔

칸은 설계 31과 같다: 모델 {논문, 넓은 DR} × 적응 조건 {빙판(마찰 0.15), 모터 40 %}. 학습 예산, 데이터, replay 데이터, 손실 가중은 설계 31과 같다(3000스텝, 실제 32 + replay 창, 손실 = 0.5·실제 + 0.5·replay 평균).

| 팔 | 토큰 | 사전학습 창 | 시뮬 계획기 창 | 학습 시드 | 비고 |
|---|---|---|---|---|---|
| 토큰 모델 | 있음 | 있음 | 있음 | 43, 44 (42는 설계 31) | 재현 |
| 토큰 없음 + replay 둘 다 | 없음 | 있음 | 있음 | 42 | 토큰이 필요한가 |
| 토큰 + 사전학습 창만 | 있음 | 있음 | 없음 | 42 | 시뮬 계획기 창이 필요한가 |
| 토큰 없음 + 사전학습 창만 | 없음 | 있음 | 없음 | 42 | 설계 20의 레시피를 같은 replay 데이터, 같은 평가로 다시 |

- 토큰이 없는 팔은 동역학 fine-tuning에 replay 손실만 더한 것이다(변형 `dyn_replay2`, `dyn_replay`). 토큰 + 사전학습 창만은 변형 `tok_noplan`.
- 성분 팔은 모델 하나를 그대로 쓴다(토큰 있는 팔은 적응 토큰 고정). 전환이 없을 때의 이득과 보존을 본다.

## 3. 측정과 기준

- 폐루프 방식, 비교 대상, 칸 기준은 설계 31 그대로다: 로봇 18대(속도 0.3/0.6/0.9 × 시드 11~16) × 5000스텝, 1000스텝당 넘어짐, 사전학습·동역학 fine-tuning은 설계 29의 기록, 로봇 단위 짝 부트스트랩.
  - **이득 칸 통과:** 자기 조건에서 유지된 이득 = (사전학습 − 팔) / (사전학습 − 동역학 fine-tuning) ≥ 0.70, CI 하한 > 0.40. 이득이 있는 3칸(논문·빙판, 논문·모터, 넓은 DR·빙판)만 센다.
  - **보존 칸 통과:** 다른 범위 밖 조건에서 팔 − 사전학습 ≤ max(0.3 × 사전학습, 0.15). 4칸.

### 3.1 재현 (토큰 모델 시드 43, 44)

- **R1:** 적응 토큰, 자기 조건. 시드마다 이득 3칸 중 2칸 이상.
- **R2:** 시뮬 토큰, 다른 범위 밖 조건. 시드마다 보존 4칸 중 3칸 이상.
- **R3 (새로 등록):** 적응 토큰 그대로, 다른 범위 밖 조건. 시드마다 보존 4칸 중 3칸 이상. 시드 42에서는 등록 없이 본 값이 3칸이었다(설계 31 §8.5 b).
- 각 항목은 **새 시드 두 개가 모두 넘어야 "재현"**이다.

### 3.2 성분 (학습 시드 42)

- **레시피 통과:** 이득 3칸 중 2칸 이상이고 보존 4칸 중 3칸 이상(모델 하나를 그대로 쓸 때).
- 같은 기준에서 설계 31의 토큰 모델(시드 42, 적응 토큰 고정)은 이득 3/3, 보존 3/4로 통과다.
- 성분 팔은 시드가 1개다. 그래서 토큰 모델 세 시드의 칸별 넘어짐 폭을 나란히 적고, 그 폭 안의 차이는 차이로 읽지 않는다(서술 규칙, 판정은 위 기준).

### 3.3 함께 적는 것 (기준 없음)

- 모든 팔의 스텝당 보상, 출발에서 넘어질 확률, 걷는 중 넘어짐(노출 시간 기준), 걷는 중 정책 이탈.
- 토큰 없음 + replay 둘 다의 평소 조건 주행.
- 실행 순서: 토큰 없음 + replay 둘 다 → 재현(R1, R2) → 토큰 없음 + 사전학습 창만 → 토큰 + 사전학습 창만 → R3 → 평소 조건. 뒤쪽이 빠지면 빠졌다고 적는다.

## 5. 결정 규칙

| 재현 (R1, R2) | 성분 | 다음 |
|---|---|---|
| 하나라도 재현 안 됨 | — | 설계 31의 통과는 시드에 달린 결과다. 이 레시피 위에 쌓지 않는다. 재현 안 된 쪽에 해당하는 설계 31 §5의 줄(R1 → 가중치를 나누지 않는 두 벌, R2 → replay 구성)을 처음부터 3시드로 등록 |
| 둘 다 재현 | 토큰 없음 + replay 둘 다 통과, 토큰 없음 + 사전학습 창만 불통과 | 필요한 성분은 시뮬 계획기 창이다. 토큰을 뺀다. B부를 토큰 없는 모델로 등록하고, 시뮬 계획기 창을 DR 범위 전체에서 모으는 판을 함께 등록 |
| 둘 다 재현 | 토큰 없는 두 팔 모두 통과 | 사전학습 창 replay로 충분하다(설계 20의 "replay가 이득을 지운다"는 이 평가에서 재현 안 됨). 가장 단순한 레시피로 B부 등록 |
| 둘 다 재현 | 토큰 없음 + replay 둘 다 불통과, 토큰 + 사전학습 창만 통과 | 필요한 성분은 토큰 경로다. 시뮬 계획기 창을 빼고 B부 등록 |
| 둘 다 재현 | 위 둘 다 불통과 | 두 성분이 함께 필요하다. 토큰 모델 그대로 B부 등록 |

- R3이 재현되면 B부의 전환은 "정책으로 물러나기"만 다룬다. 재현되지 않으면 토큰 전환(적응 → 시뮬)도 B부의 팔로 남긴다.
- B부(초안, 아직 등록 아님): 출발은 정책, 걷는 중에는 실행 중 1스텝 오차의 50스텝 평균이 자기 조건 주행에서 정한 문턱을 넘으면 정책으로 물러남. 새 평가 시드에서 이득·보존·출발 넘어짐을 잰다.

## 6. 한계 (미리 적음)

- 성분 팔은 학습 시드 1개다. 재현 팔도 시드 2개 추가(합 3개)뿐이다.
- 평가 로봇(속도 × 시드)은 설계 29·31과 같다. 짝 비교를 위해서이고, 그래서 평가 시드에서 오는 잡음은 모든 팔이 공유한다.
- 비교 대상(사전학습, 동역학 fine-tuning)은 설계 29의 기록(학습 시드 42)이다. 유지된 이득의 분모에 동역학 fine-tuning의 시드 변동은 들어 있지 않다.
- 시뮬 계획기 창은 평소 조건만이다. 논문 모델의 사전학습 창은 8192 에피소드 부분집합이다.
- 조건은 여전히 빙판과 모터 40 % 둘뿐이다. 빙판의 이득은 대부분 출발에서 온다(설계 30).
- 로컬 스모크: 변형 네 개의 30스텝 학습과 150스텝 폐루프 2런(논문 모델), 분석 스크립트는 설계 31 결과를 이름만 바꿔 넣어 확인. 동작 확인용이고 결과로 쓰지 않는다.

## 7. 규칙

- 이 문서를 커밋·푸시한 뒤 실행한다. gpu1에서 `scripts/sim2sim/stage32.sh`, 결과는 `/mnt/newssd/cjkim/simdist/results/stage32`. 런당 11 GB 이하.
- 분석은 `scripts/sim2sim/stage32_gate.py`(실행 전 작성).
- 예상 시간: 학습 20개 약 40분, 폐루프 52런 약 11시간(런당 약 50분, GPU 4대). 재현(R1, R2)과 토큰 없음 + replay 둘 다는 앞의 약 5시간에 끝난다.

### 8.8 읽기

1. **보존은 replay에서 나오고 튼튼하다.** 토큰 유무, 시뮬 계획기 창 유무, 학습 시드와 무관하게 모델 하나를 그대로 써도 다른 범위 밖 조건에서 사전학습 수준이다. 설계 29에서 본 망각(1.2~4.7배)은 사전학습 창 replay만으로 없어진다.
2. **이득은 replay 아래에서 일부만 남고 시드에 따라 달라진다.** 논문·빙판은 항상 남는다. 논문·모터와 넓은 DR·빙판은 0.0~0.9 사이로 흩어진다. 설계 31의 통과는 가장 좋은 시드였다.
3. **토큰은 필요한 성분이라는 증거가 없다.** 설계 31에서 토큰이 거의 쓰이지 않았고(§0), 이번에 토큰 있는 팔과 없는 팔이 같은 칸에서 같은 식으로 불통과다. 시뮬 토큰으로 바꾸는 것은 한 칸(논문·모터 적응, 빙판)에서 세 시드 모두 오히려 나쁘다.
4. **한계.** 유지된 이득의 분모인 동역학 fine-tuning은 시드 1개다(§6). 0.52~0.71이라는 값이 replay의 손실인지 동역학 fine-tuning 시드 42가 좋은 시드였던 것인지 이 실행으로는 가릴 수 없다. 다음 설계는 비교 대상도 3시드로 돌려야 한다.

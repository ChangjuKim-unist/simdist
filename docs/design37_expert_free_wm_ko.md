## 3. 방법 후보: 경로 둘, G0 결과로 고른다

### A. 후보 순위 교정 (counterfactual correction)

설계 38이 "정보로는 설명 안 됨"이거나 "부분"이면 주 경로가 된다. 설계 36 C3에서 순위가 잡음 바닥보다 뚜렷이 틀릴 때 의미가 있다.

1. **sim 사전학습 단계 (DR 범위 안):**
   - planner를 돌리며 상태를 복제한다.
   - planner 자기 후보를 점수 순위 층(상·중·하) + 정책 후보 + 실행 계획에서 골라 실제로 실행한다. 설계 36 group M 도구를 그대로 쓴다.
   - 같은 상태 후보 쌍의 실제 수익 순서를 맞추는 pairwise ranking 손실을 모델 점수(보상 합 + γ^T V)에 건다.
   - 회차마다 데이터를 누적하고, 2회를 기본으로 한다.
2. **실기 적응 단계:** 동역학 fine-tuning 때 sim replay 창과 함께 1의 ranking 손실을 유지한다(순위 보존 적응). 실기에는 상태 복제가 없으므로 ranking 라벨은 sim 쪽만 쓴다.
3. **value 정합:** 상태 복제로 실제 실행한 수익(Monte Carlo)으로 value를 맞춘다. 이러면 value가 "horizon 뒤에 실제로 행동하는 것"(MPPI + 정책)의 value가 된다. 지금은 expert critic V^e를 복사한다.

### B. 추정 보조 (privileged-signal heads) — 내림 (설계 38 "정보로는 설명 안 됨")

설계 38이 "정보가 설명"이거나 "부분"이면 쓴다.

1. **sim 사전학습:** world model latent에서 설계 38이 찾은 주 신호를 예측하는 보조 head를 둔다. 예를 들어 발 접촉력을 예측한다. latent가 expert가 기대는 정보를 담게 하는 것이 목적이다.
2. **실기 적응:** 실기에서 잴 수 있는 신호는 fine-tuning의 자기 지도 목표로 추가한다. Go1의 발 힘 센서, 상태 추정기 속도가 해당한다. 그러면 동역학 예측 손실만 쓸 때보다 적응 신호가 늘어난다.
3. **sim2sim 대리 실험:** 측정 신호에 실기 수준의 잡음과 지연을 넣는다.

### v1에서 남기는 것

- 걸음 조건부 데이터와 보상 가중치 value는 확장(Extension, 2027-02) 후보로만 둔다.
- 데이터 기록기의 항별 보상 기록은 A의 value 정합과 E1 분석에도 필요해서 남긴다.

### 4.1 G1 등록 내용 (2026-11-22, 실행 전 고정)

**공통 자료.** 설계 36 C3의 분기점은 조건 넷(평소 = 논문 모델, tow20·mot50·legR50 = 각 조건 적응 모델 `go1_paper_{c}_dyn_b45000_s42`) × 96개다. 분기점마다 후보 64개가 있다. 표본 후보 62개에는 실제 125스텝 수익 ret, 개루프 25스텝 동안의 수익 ret_chunk, 넘어짐 fell이 있다. "마지막 반복 후보"는 그중 34개(가우시안 24, 정책 2, 점수 상위 8)다.

#### G1-0: 점수 분해 (스크립트 `scripts/sim2sim/stage37_g10.py`)

1. **재구성.** 앵커에 저장된 이력(hist_p, hist_a, fut_cmds)과 후보 행동(m_acts)으로 같은 모델을 다시 실행한다. 높이 스캔은 앵커에 없다. 평지에서는 모든 칸이 같으므로 clip(몸통 높이 − 0.3, −2, 2)로 채운다. 점수를 두 항으로 나눈다.
   - R = Σ γ^k r̂_k: 25스텝 예측 보상의 할인 합.
   - V항 = γ^(T+1) V̂(z_T): 끝 value.
   - 충실도 기준: 분기점 안 Spearman(다시 계산한 점수, 기록된 m_score)이 네 조건 모두 0.99 이상. 못 미치면 G1-0을 멈추고, 앵커에 높이 스캔을 기록하도록 고쳐 다시 돌린다. (평소 조건으로 충실도만 먼저 확인했다: 0.9999. 항별 결과는 등록 전에 보지 않았다.)
2. **마지막 반복 후보 안에서 재는 것** (분기점마다 계산해 평균, 분기점 bootstrap 5000번):
   - ρ_R = Spearman(R, ret_chunk)
   - ρ_V = Spearman(V항, ret − ret_chunk), 즉 이어 가기 수익과의 상관
   - R과 V항 각각의 125스텝 수익 상관과 넘어짐 AUC
   - 점수 분산 중 V항의 몫
3. **판정** (조건 넷 중 셋 이상에서, 위에서부터 먼저 맞는 것):

   | 판정 | 규칙 |
   |---|---|
   | "둘 다" | ρ_R < 0.1이고 ρ_V < 0.1 |
   | "value 쪽" | ρ_V < 0.1이고 ρ_R ≥ 0.3 |
   | "보상 쪽" | ρ_R < 0.1 |
   | 그 밖 | "중간" |

4. **읽는 법.** G1-A는 판정과 상관없이 두 팔을 모두 돌린다. 판정은 어느 팔이 주 결과인지 정한다.
   - "value 쪽": A3가 주 결과다.
   - "보상 쪽": A1이 주 결과다.
   - "둘 다" 또는 "중간": 둘 다 주 결과다.

#### G1-A: 끝 latent 교정 head (오프라인)

1. **입력.** G1-0이 저장한 끝 latent z_T(후보마다)다. 모델 가중치는 건드리지 않는다. 새 점수 = R + γ^(T+1) [V̂(z_T) + Δ(z_T)]이고, Δ만 학습한다.
2. **Δ의 구조.** MLP(입력 표준화, 은닉 64 × 2, ReLU), Adam 1e-3, weight decay 1e-4, 3000스텝, 미니배치 256. 초기화 시드 3개의 평균 결과를 보고한다.
3. **팔.**
   - A3 (value 정합): Δ를 MSE로 학습한다. 목표는 V̂(z_T) + Δ(z_T)가 실제 이어 가기 수익(ret − ret_chunk)을 γ^(T+1)로 나눈 값에 맞는 것이다. 표본 후보 62개와 실행 계획·head 계획 복제본을 모두 쓴다.
   - A1 (순위): 같은 분기점의 표본 후보 쌍(실제 ret 차이가 그 조건 복제 잡음 SD보다 큰 쌍만)에 pairwise logistic 손실을 새 점수에 건다.
4. **라벨 판.**
   - O (같은 조건 라벨, 상한): 각 조건에서 시드 11–13 분기점으로 학습하고 시드 14–16 분기점으로 시험한다.
   - N (평소 라벨만, 배치 가능 판): 평소 조건의 시드 11–13 분기점으로만 학습하고, 각 적응 조건의 시드 14–16에서 시험한다. 적응은 동역학만 바꾸고 encoder·value는 같으므로 z_T 공간을 공유한다.
5. **시험 지표** (시험 분기점 48개, 분기점 bootstrap):
   - (i) 마지막 반복 후보 안 Spearman(새 점수, ret)의 변화
   - (ii) 마지막 반복 후보 안 넘어짐 AUC
   - (iii) 표본 후보 62개 전체 Spearman의 변화
   - (iv) 새 점수 1위 후보의 실제 ret − 원래 점수 1위 후보의 실제 ret (head 절댓값 평균 대비 %)
6. **판정** (적응 조건 셋 tow20·mot50·legR50과 평소 조건을 따로 본다):

   | 판정 | 규칙 |
   |---|---|
   | 팔 X "교정 성공(O)" | 적응 조건 셋 중 둘 이상에서 (i)가 +0.2 이상이거나 (ii)가 0.65 이상이고, (iii)이 −0.05보다 덜 떨어짐. 평소 조건은 같은 기준을 따로 기록 |
   | 팔 X "배치 가능" | O가 성공이고, N의 (i) 개선이 그 조건 O 개선의 절반 이상인 적응 조건이 둘 이상 |
   | 둘 다 실패 | 후보 순위 교정으로 G2에 가지 않는다. G1-0의 분해와 함께 결과를 사용자에게 보고하고 다음 안을 제안한다 |

7. **G2로 가는 조건.** 어느 팔이든 "배치 가능"이면 그 팔로 G2(폐루프)를 따로 등록한다. "교정 성공(O)"만이면 실기에서 라벨을 얻는 방법이 없으므로 G2 전에 사용자와 정한다.

#### 예측 (실행 전)

- Q1. 충실도는 네 조건 모두 0.99를 넘는다(평소 0.9999 확인됨, 적응 모델도 같은 입력이므로).
- Q2. G1-0 판정은 "value 쪽"이다(50 %). 근거: C3에서 25스텝 수익과의 상관(후보 구름 전체 0.77–0.86)이 125스텝(0.62–0.70)보다 높고, 넘어짐은 덩어리 뒤에 생긴다.
- Q3. A3는 O 판에서 (ii) 넘어짐 AUC를 0.65 이상으로 올리는 조건이 둘 이상이다(45 %). (i) +0.2는 어렵다(마지막 후보 사이 실제 차이가 잡음의 2–4배뿐).
- Q4. N 판은 O 개선의 절반에 못 미친다(55 %). 조건마다 넘어지는 방식이 다르기 때문이다.

## 5. 기준선 (리뷰어가 요구할 것)

- SimDist 원본(적응 전·후 planner), 정책 head 단독, 특권 expert(상한).
- A에 대해: ranking 손실 없이 같은 분기 데이터로 MSE만 다시 맞춘 팔(데이터 양 효과 분리), 실행 계획 대신 정책 후보 중 상위만 고르는 planner(IQL-TD-MPC식 후퇴안).
- B에 대해: 보조 head 없이 같은 센서 신호를 입력으로만 추가한 팔(입력 효과와 학습 목표 효과 분리).

## 6. 선행연구 위치 (요약)

- **A:** pico-WAM(2611.01039), FIRM-WM(2609.22816), World4Scorer(2609.36438)는 상태 복제 반사실 라벨로 순위를 교정했다. 모두 조작·주행이고 planner 자기 후보를 표적으로 하지 않는다. FDM(2504.19322)과 SNS-MPC(2601.12169)는 실행 궤적만 쓴다. 다리 로봇에서 사전학습 latent WM의 후보 순위 교정과 적응 뒤 순위 보존을 보인 연구는 찾지 못했다.
- **B:** 특권 정보 예측 보조 목표는 teacher-student·RMA 계열에 흔하다. 그래서 B의 새로움은 "world model 적응 신호로서의 실측 신호"에 한정된다. 확인 조사가 필요하다.

## 7. 위험

- C3에서 후보 간 실제 차이가 잡음 바닥이면 A의 순위 지표가 무의미하다 → G1-A로 가지 않는다.
- ranking 손실이 다른 상태의 예측을 망칠 수 있다(설계 7·22에서 점수 쪽을 다시 맞추면 나빠진 전례) → 평소 회귀 검사를 모든 단계에 넣는다.
- B는 설계 21·24·31(맥락 추정)의 실패와 겹칠 수 있다. 차이는 물리값이 아니라 expert가 실제로 쓰는 신호를 겨냥한다는 점이고, 설계 38이 그 신호를 정한다.
- 평소 조건 격차(0.80)는 적응 문제가 아니라 사전학습 문제일 수 있다. 그 몫은 A 사전학습 단계(G3)에서만 다룬다.

### 8.2 A 경로를 어떻게 좁히나

- 넘어짐은 25스텝 덩어리가 끝난 뒤 12–50스텝 사이에 생긴다(설계 36 §8.3 (d)). 점수에서 그 구간을 맡는 것은 끝 value다.
- 지금 value는 expert critic V^e를 복사한 것이다. V^e는 "그 상태에서 expert가 이어 가면 받을 수익"이다. 설계 38에서 expert는 조건과 정보 없이도 거의 넘어지지 않았다. 그러므로 V^e는 배치 controller가 회복하지 못하는 상태에도 높은 값을 줄 수 있다. 이 가설은 아직 확인하지 않았다.
- 그래서 A 경로의 첫 단계는 A3(value를 배치 쪽 이어 가기 수익에 맞추기)로 둔다. A1(pairwise ranking 손실)은 G1-0에서 보상 항이 문제로 나오면 앞으로 당긴다.
- 위험: 설계 22에서 value head를 MSE로 다시 맞추면 폐루프가 나빠졌다(2.50 → 2.69–5.19). 그때 데이터는 기록 궤적이었다. 이번 라벨은 planner 자신의 후보(착취가 일어나는 자리)라는 점이 다르다. 그래도 G2 폐루프 전에는 이득을 주장하지 않는다.
- 한계: C3의 이어 가기는 정책 head다. 실제 planner는 매 스텝 다시 계획한다. G1의 라벨은 "덩어리 + head"의 가치이고, 폐루프와 맞는지는 G2가 판정한다.

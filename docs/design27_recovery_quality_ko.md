# 설계 27: 넓은 DR 계획기는 왜 미끄러진 뒤 회복을 못 하나 + 움직임의 질 지표 (2026-11-16 등록)

## 0. 배경

설계 26(마찰 0.15, 속도 0.9, 1초 램프 출발, 시드 18)의 결론은 이렇다.
- 넓은 DR 모델의 계획기는 미끄러지는 횟수가 정책과 비슷하다(1000스텝당 5.1 대 4.1).
- 그런데 미끄러진 뒤 100스텝 안에 넘어지는 비율이 3배다(0.42 대 0.14).
- 명령 상한 0.9 m/s는 이 비율을 둘 다 절반으로 줄였지만 격차는 그대로였다(0.23 대 0.07).
- 논문 모델은 계획기와 정책의 이 비율이 같다(0.11 대 0.09).

설계 전에 설계 26 기록에서 잰 보정값이 있다. 결과를 미리 본 셈이므로 여기서는 예측으로 쓰지 않고, 후보를 만드는 데만 쓴다.
- 넓은 DR 계획기가 정책 행동에서 벗어나는 정도(|a − a_pol|)
  - 미끄러진 뒤 100스텝에서 평균 0.44다. 평소 걷는 중에는 0.32다.
  - 분포의 꼬리가 길다. 중앙값 0.31, 95 백분위 0.89다.
  - 관절별로는 종아리 관절에 몰려 있다. 표준편차가 FL 종아리 0.45, FR 종아리 0.31, RR 종아리 0.27, RR 허벅지 0.28이고, 나머지는 0.12~0.20이다.
  - 한 스텝 전과의 상관이 0.70~0.84로, 한 방향으로 오래 유지된다.
- 논문 모델 계획기는 미끄러진 뒤 0.36으로 평소 0.35와 같다. 관절별 크기는 모두 0.09~0.14로 고르다.

사용자 요청(2026-11-16)은 두 가지다. 회복 실패의 원인을 확인할 것. 그리고 넘어짐에만 기대지 말고 움직임이 얼마나 자연스러운지를 여러 지표로 따져 문제를 파고들 것.

## 1. 질문

- **QR. 회복 실패의 원인.** 미끄러진 뒤 넘어지는 비율의 차이(0.42 대 0.14)는 어디서 오나.
  - 계획기가 더 위험한 미끄러짐 상태로 들어가서인가(상태 탓)?
  - 같은 상태에서 계획기의 회복 행동이 나빠서인가(행동 탓)?
  - 행동 탓이라면, 정책에서 벗어나는 **크기** 탓인가, 지금 상태에 맞춰 고른 **방향** 탓인가?
- **QM. 움직임의 질.** 넘어짐 말고 다음 지표에서 무엇이 다른가.
  - 지표: 행동 매끄러움, 힘·에너지, 몸통 흔들림, 걸음 규칙성, 발 미끄럼, 속도 추종
  - 비교 1: 계획기 대 정책
  - 비교 2: 논문 모델 대 넓은 DR 모델
  - 비교 3: 빙판 대 보통 바닥

## 2. 가설

- **HR-행동.** 같은 미끄러짐 상태에서 시작해도 계획기로 회복하면 정책보다 더 자주 넘어진다.
- **HR-상태.** 계획기로 걷다 생긴 미끄러짐 상태 자체가 더 위험하다. 같은 정책으로 회복해도 더 자주 넘어진다.
- **HR-크기.** 계획기와 같은 크기·같은 지속성의 이탈이면 무작위여도 똑같이 해롭다. 즉 정책의 회복이 작은 교란에 약하다.
- **HR-방향.** 무작위 이탈은 해롭지 않고, 계획기가 지금 상태를 보고 고른 방향만 해롭다. 즉 미끄러진 상태에서 모델이 틀린 방향을 고른다.
- **HM.** 계획기 행동은 매 스텝 표본을 새로 뽑는 탐색 때문에 정책보다 덜 매끄럽고(떨림), 힘을 더 쓰고, 걸음이 덜 규칙적이다.

## 3. 측정 도구 (코드 변경, 기본값은 꺼짐)

- `scripts/simulate_batch.py`의 `output.diag_npz`에 매 스텝 관절 속도, 실제 토크, 발 접촉력을 추가했다. 로봇 질량도 저장한다.
- `scripts/sim2sim/branch_eval.py`(설계 18의 분기 도구)
  - `branch.drive=planner`: 계획기가 직접 걷는 앵커 런. 분기점의 계획기 시작 계획은 자기 계획이다.
  - `branch.trigger=slip`: 미끄러짐 사건이 감지되는 순간 전체 상태를 저장한다.
    - 감지 기준은 설계 26 §5와 같다. 접지 발 미끄럼의 10스텝 이동평균 > θ가 5스텝 연속이고, 시작이 리셋 후 300스텝 이상.
    - 평상시 대조점도 저장한다. 100스텝마다, 직전 50스텝 미끄럼 ≤ θ인 로봇.
  - 새 후보
    - `Nrep`: 정책 헤드 행동에 계획기가 **다른** 미끄러짐 순간에 실제로 냈던 이탈 수열(a − a_pol)을 그대로 더한다.
      - 이탈 은행은 설계 26 D6·D5 기록에서 만들었다(`results/stage27/dev_bank.npz`).
      - 크기, 꼬리, 지속성, 관절 사이 상관이 같고, 지금 상태와의 관계만 없다.
    - `Pcalfpol`, `Ponlycalf`: 2단계 K용(§7).
  - `branch.steps_dir`: 분기마다 매 스텝 기록을 남긴다. 기울기, 미끄럼, 접지, 속도, 행동, 정책 행동, 명령, 모델 1스텝 예측 오차, 토크², 일률.
  - `branch.max_events`·`max_ctrl`: 시드를 고정한 무작위 부분집합. `only_events`도 추가했다.
- 분석 스크립트(결과 전 커밋)
  - `scripts/sim2sim/stage27_metrics.py`(§5.1)
  - `scripts/sim2sim/stage27_branch.py`(§5.2)
- 이탈 은행 대신 AR(1) 잡음(`Ncl`)도 만들었지만 쓰지 않는다. 넓은 DR 계획기의 이탈은 꼬리가 길다. 표준편차를 맞춘 정규 잡음은 평균 크기가 0.77로 계획기(0.44)의 1.75배가 되어, 크기 비교가 공정하지 않다.

로컬 스모크 테스트(RTX 3060, go1_paper)는 모두 정상이었다.
- 정책 앵커 800스텝 × 4대에서 사건 23개를 감지했다. 같은 런 기록에서 설계 26 방식으로 오프라인 감지한 23개와 23/23 일치했다.
- 계획기 앵커에서 저장된 시작 계획의 첫 행동과 실제 실행 행동의 차가 0.001(float16 반올림)이었다.
- 분기에서 후보별 정책과의 차가 정책 0, 계획기 0.37, 이탈 재생 0.35였다. 종아리 나누기 후보는 해당 관절의 차가 정확히 0이었다.
- 두 분석 스크립트를 스모크 자료에서 끝까지 돌렸다(설계 26·27 실제 결과는 보지 않음).

## 5. 지표 정의 (고정)

### 5.1 움직임의 질 (QM, `stage27_metrics.py`)

걷는 중(리셋 후 300스텝 이후, 정지 구간 제외)에서 로봇마다 계산하고 18대 평균을 낸다. 비는 같은 시드끼리 묶은 부트스트랩으로 95 % CI를 낸다.

| 묶음 | 지표 | 정의 | 좋은 쪽 |
|---|---|---|---|
| 안전 | 넘어짐/1000스텝 | 전체 스텝 | 낮을수록 |
| 발 | 미끄럼 | 접지한 발들의 수평 속도 평균 | 낮을수록 |
| 과제 | 전진 속도 오차 | \|vx − 0.9\| 평균 | 낮을수록 |
| 과제 | 옆 속도, 회전 속도 | \|vy\|, \|ωz\| 평균 | 낮을수록 |
| 매끄러움 | 행동 변화 | ‖a_t − a_{t−1}‖ 평균(12차원 관절 목표) | 낮을수록 |
| 매끄러움 | 행동 2차 차분 | ‖a_t − 2a_{t−1} + a_{t−2}‖ 평균 | 낮을수록 |
| 매끄러움 | 고주파 비율 | 행동 신호 전력 중 10~25 Hz 몫(128스텝 Hann 창, 평균 제거, 관절·창 평균). 걸음 주기는 2 Hz다 | 낮을수록 |
| 매끄러움 | 관절 가속도² | 보상 항 dof_acc_l2(비만), 새 런은 Σq̈² 직접 | 낮을수록 |
| 힘 | 토크² | 보상 항 dof_torques_l2(비만), 새 런은 Στ² 직접 | 낮을수록 |
| 힘 | 기계적 일률, 이동 비용 | Σ\|τ·q̇\| [W], 일률 / (질량 × 9.81 × 평균 vx). 새 런만 | 낮을수록 |
| 몸통 | 롤·피치 속도, 상하 속도 | RMS | 낮을수록 |
| 몸통 | 기울기, 높이 SD | ‖g_xy‖ 평균, 높이 표준편차 | 낮을수록 |
| 걸음 | 보폭 주기, 변동계수 | 같은 발의 착지 간격. 착지는 3스텝 이상 이어진 접지의 시작이다 | 0.5 s에 가까울수록 / 낮을수록 |
| 걸음 | 접지 비율 | 발이 땅에 닿은 시간 비율 | 0.5에 가까울수록 |
| 걸음 | 대각 발 동기율 | FL=RR이고 FR=RL인 스텝 비율 | 높을수록 |
| 걸음 | 짧은 접지 | 2스텝(40 ms) 이하 접지의 초당 횟수(발 구름·헛디딤) | 낮을수록 |
| 걸음 | 걸음 보상항 | 보상 항 gait(비만) | 높을수록 |
| 발 | 착지 충격 | 착지 후 3스텝 안 최대 접촉력. 새 런만 | 낮을수록 |

비교표(하나에 비교 하나)는 다음과 같다.
- M1: 논문 모델 빙판, 정책 D8 → 계획기 D5
- M2: 넓은 DR 빙판, 정책 D7 → 계획기 D6
- M3: 새 앵커로 같은 비교 재현(AP, AB). 일률·이동 비용 포함.
- M4: 보통 바닥 → 빙판(제어기·모델 4가지), 그리고 보통 바닥에서 정책 → 계획기
- M5: 논문 모델 → 넓은 DR(계획기끼리, 정책끼리)
- M6: 출발 구간(s = 25~99), 기존 출발. 논문 정책 D4 → 논문 계획기 D1, 논문 계획기 D1 → 마찰 적응 계획기 D3

### 5.2 미끄러진 순간에서 갈라 실행 (QR, `stage27_branch.py`)

- **넘어짐**: 갈라진 뒤 100스텝 안의 넘어짐(설계 26의 "사건 뒤 100스텝"과 같은 창).
- 분기점마다 복제본 3개를 평균한다.
- 비율과 짝 차이(같은 분기점, 뒤 − 앞)는 로봇 단위(출발 상태 런, 시드) 군집 부트스트랩으로 95 % CI를 낸다.
- 같은 모델의 두 출발 상태 런(계획기가 만든 미끄러짐, 정책이 만든 미끄러짐)은 합쳐서 본다. HR-상태만 따로 비교한다.
- 회복 과정 지표: 갈라진 뒤 0~24스텝과 0~99스텝에서 살아 있는 스텝만 쓴다.
  - 정책 행동과의 차, 종아리·나머지 관절 이탈
  - 최대 기울기, 미끄럼, 전진 속도, 행동 2차 차분
  - 토크², 일률, 모델 1스텝 예측 오차, 접지 발 수, 롤·피치 속도
  - 미끄럼 회복 시간: 분기 안 10스텝 이동평균 미끄럼 ≤ θ가 25스텝 연속인 첫 시각
- 설명용(판정에 쓰지 않음): 계획기 분기의 넘어짐/안 넘어짐 AUC, 관절별 부호 있는 이탈, 시간 경과.
- 복원 충실도(참고): 정책 앵커에서 섭동 없는 정책 복제본이 앵커 자신의 연속과 같은 결과를 내는지 본다.

- **상태 탓도 있음**: PR2의 차이가 +0.10 이상이고 CI > 0.

- **크기 탓**: 이탈 재생 − 정책 ≥ +0.10(CI > 0)이고, |계획기 − 이탈 재생| ≤ 0.05.

### 9.7 종합

1. **QR.** 넓은 DR 계획기의 "미끄러진 뒤 넘어짐"은 대부분(약 2/3) 미끄러지기 전에 만들어진다. 계획기로 걷다 생긴 미끄러짐이 더 크고, 더 기울고, 더 떨리는 상태에서 일어나기 때문이다. 나머지(약 1/3)는 미끄러진 뒤 계획기의 회복 행동 탓이다. 이 몫은 등록 기준(+0.10)에는 조금 못 미치지만 0보다 확실히 크다.
2. 계획기의 정책 이탈은 무작위가 아니다. 크기와 지속성이 같은 상태 무관 이탈은 평상시에도 넘어짐을 30 % 안팎으로 만들지만, 계획기는 0.035다. 회복 중에 해로운 것은 상태에 맞춘 이탈이 미끄러진 뒤에는 덜 맞는 것이다. 그 순간 모델의 1스텝 예측 오차가 크다(AUC 0.84).
3. **QM.** 계획기의 떨림(행동 2차 차분, 고주파)은 두 모델과 두 바닥 모두에서 1.15~1.4배다. 넓은 DR 계획기만의 특징은 빠르고 불규칙한 걸음 리듬과 짧은 접지(헛디딤)다. 이것은 보통 바닥에서도 보인다.
4. 1과 3을 함께 보면 이렇게 정리된다. 넓은 DR 계획기는 걷는 방식 자체(떨리고 불규칙한 걸음)로 더 나쁜 미끄러짐을 만든다. 그리고 미끄러진 뒤 모델이 틀리는 구간에서 회복을 조금 더 못 한다.

남은 질문과 다음 방법 후보(등록 전)
- 계획 비용에 걸음 규칙성·행동 매끄러움 항을 넣거나 탐색 잡음을 매끄럽게 하면, 미끄러짐 상태 자체가 덜 나빠지나(상태 몫 2/3 겨냥).
- 미끄러짐과 모델 예측 오차 상승을 신호로 계획기를 정책 헤드로 넘기면 회복 몫(1/3)이 사라지나.
- 넓은 DR 계획기는 왜 보통 바닥에서도 보폭이 짧고 헛디디나. 모델의 접촉 예측 문제인지, MPPI 탐색 문제인지는 아직 모른다.

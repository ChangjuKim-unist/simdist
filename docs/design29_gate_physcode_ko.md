## 2. G0 방법 (`scripts/sim2sim/stage29_g0.py`, 학습 없음, 로컬 GPU)

**데이터와 모델**
- 데이터: 넓은 DR 데이터 `2026-11-05_11-39-08`(go1dr, 32,105 에피소드, 걸음마다 물리 라벨 [모터 세기, 마찰, 추가 질량]).
- 모델: `go1_broadwm`. 이 데이터로 이어 학습한 모델이고, 잠재 64차원, 이력 25, 예측 25입니다.

**에피소드와 장면**
- 에피소드 경계: "끝까지 남은 스텝" 값이 다시 커지는 곳을 에피소드 시작으로 봅니다. 기록 첫 구간처럼 시작이 보이지 않는 구간은 뺍니다.
- 길이 400스텝 이상인 에피소드에서 4000개를 뽑습니다(시드 29). 에피소드 단위로 반으로 나눠 맞춤용 A 2000개, 평가용 B 2000개로 씁니다.
- 장면: 창의 현재 시점 τ(에피소드 시작부터 스텝 수)로 정합니다.
  - 출발: 25 ≤ τ < 125. 에피소드당 8개를 균등하게 뽑습니다.
  - 평상시: τ ≥ 300. 에피소드당 8개를 뽑습니다.

**물리 묶음**
- 모터 세기와 마찰은 데이터의 3분위로 나눕니다. 걸음 표본 기준 경계는 모터 0.592 / 0.848, 마찰 0.497 / 0.858입니다.
- 질량은 중앙값(0.883 kg)으로 둘로 나눕니다.
- 그래서 묶음은 18개입니다. 라벨은 묶음에만 쓰고 모델 입력으로는 넣지 않습니다.

**잔차와 보정**
- 잔차: 데이터 행동을 그대로 넣은 25스텝 잠재 예측에서, 학습 손실과 같은 공간으로 r = 예측 − 미래 관측 인코딩을 구합니다. 크기는 25 × 64입니다.
- 장면마다 따로 A에서 맞추고 B에서 평균 제곱오차를 잽니다.
  - C1 전체 상수: 스텝 k별 A 전체 평균 잔차
  - C2 묶음 상수: 묶음 g, 스텝 k별 A 평균 잔차
  - C3 전체 선형: r ≈ W φ. φ = [z_t(64), 처음 5스텝 미래 행동 평균(12), 명령(3), 1]. 리지 λ는 A 안 5겹 교차검증으로 {0.1, 1, 10, 100} 중 고르고 C4에도 같은 λ를 씁니다.
  - C4 묶음 선형: 묶음별 W_g

**지표 (B에서, 에피소드 단위 부트스트랩 95 % CI)**
- 물리 몫(상수) = 1 − MSE(C2)/MSE(C1)
- 물리 몫(선형) = 1 − MSE(C4)/MSE(C3)
- 참고값: 보정 전 MSE, 스텝 k = 1과 k = 25의 몫, 낮은 마찰 묶음과 낮은 모터 묶음의 몫

**G0 통과 기준**
- 출발 장면에서 max(물리 몫 상수, 물리 몫 선형) ≥ 10 %이고, 그 CI 하한 > 5 %.
- 묶음 상수나 묶음 선형은 물리 코드가 할 수 있는 일의 하한입니다. 코드는 비선형이고 동역학 안에서 작동하기 때문입니다.

## 3. G1 방법 (계획기 수정 + 시뮬 평가, gpu1)

**계획기 수정** (`simdist/control/mppi_batch.py`, `scripts/simulate_batch.py`, 설정 `control.robust`, 기본 꺼짐)
- `control.robust = {enabled, models: [체크포인트 이름 목록], hold, decay}`.
- 켜지면 현재 모델 외에 목록의 모델을 불러옵니다. 로봇별 γ_t는 이렇게 정합니다.
  - 리셋 뒤 경과 s < reset_steps + hold이면 1
  - 이후 decay 스텝 동안 선형으로 0까지
  - 그다음은 0
- 매 MPPI 반복에서 같은 후보 집합을 모든 모델로 굴립니다. 점수 = (1 − γ)·현재 모델 점수 + γ·모든 모델 점수의 최저값입니다. elite 선택과 평균은 이 점수로 합니다.
- γ가 모두 0인 스텝에서는 추가 모델을 계산하지 않습니다(lax.cond). 정책 헤드 후보는 현재 모델 것을 그대로 씁니다. 적응은 동역학만 바꾸므로 헤드는 모두 같습니다.
- 고정값: hold = 50(풀린 뒤 1초), decay = 50(다음 1초). 결과를 보고 바꾸지 않습니다.
- 구현 점검(실행 전, `results/stage29/test_robust.py`): γ = 0인 로봇은 수정 전과 행동이 같고(차 0), 로봇별 γ가 따로 적용됩니다. 다른 모델을 섞으면 행동이 바뀝니다. 같은 모델을 두 번 넣으면 행동이 최대 0.07 다른데, 상위 64개 후보의 점수 간격(최소 3 × 10⁻⁵)이 분기 안 계산의 미세한 수치 차이로 뒤집힌 것으로 봅니다. 따로 컴파일한 두 사본의 출력은 같았습니다.
- 실행 스크립트 `scripts/sim2sim/stage29.sh`: 셀 38개, gpu1 4장 대기열, 셀마다 eval·falls CSV와 diag npz를 남깁니다(움직임 품질 지표용).

**팔** (모델 m ∈ {논문, 넓은 DR})

| 팔 | 계획에 쓰는 모델 | robust |
|---|---|---|
| PRE | 사전학습 | 꺼짐 |
| ICE | 빙판 적응 `m_friction0.15_dyn_b45000_s42` | 꺼짐 |
| MOT | 모터 적응 `m_very_weak_motor_dyn_b45000_s42` | 꺼짐 |
| ICE+R | 빙판 적응 | {사전학습} 추가 |
| MOT+R | 모터 적응 | {사전학습} 추가 |

**조건과 규약**
- 조건: 평소(마찰 0.8), 빙판(마찰 0.15), 모터 40 %
- 규약은 설계 20과 같습니다. 시드 11~16 × 속도 0.3/0.6/0.9 = 18대, 5000스텝, 에피소드 100 s, 평지, 출발 램프 없음, `output.falls_csv`(출발·걷는 중 구분).
- 셀 30개 = 5팔 × 3조건 × 2모델

**보조 Q1r (1초 램프, `sim.cmd_ramp_steps=50`)**
- PRE와 MOT를 빙판에서, PRE와 ICE를 모터 40 %에서 돌립니다. 두 모델이라 셀 8개입니다.

**지표 (18대 로봇 단위 짝 부트스트랩)**
- 넘어짐/1000스텝(전체, 출발 중 s < 300, 걷는 중)
- 실제 보상/스텝, 전진 거리
- 이득 보존율 = (PRE − X+R) / (PRE − X). 적응 조건에서 잽니다.
- 망각비 = (X+R) / X. 다른 조건에서 잽니다.

**G1 통과 기준 (모델·시나리오별)**
- **F 망각:** 다른 조건에서 (X+R)/X ≤ 0.7이고 CI 상한 < 1, 그리고 X+R ≤ PRE × 1.15.
- **G 이득:** 적응 조건에서 이득 보존율 ≥ 0.7.
- **N 평소 비용:** 평소 조건 보상 (X+R)/X ≥ 0.95이고, 넘어짐 증가 ≤ 0.05.
- 시나리오는 넷입니다: 논문 MOT(빙판 망각), 논문 ICE(모터 망각), 넓은 DR MOT, 넓은 DR ICE.
- **G1 통과 = 네 시나리오 중 하나 이상이 F·G·N을 모두 만족.** 어느 망각 유형(출발형/걷는 중형)을 덮는지 함께 기록합니다.

## 7. 실행 기록

### 7.1 G0 (2026-11-17 13:15~13:30, 로컬 RTX 3060)

- 에피소드 4000개(길이 400 이상 20,055개 중), 창 62,029개(출발 30,372, 평상시 31,657), 교차검증 λ = 10.
- 구현 중 확인: "끝까지 남은 스텝"은 0이 아니라 1까지 내려간다. 그래서 에피소드 길이 = 시작 시점 값이고, 인덱스 0도 에피소드 시작이다. 물리 라벨은 이 구간 안에서 일정하다. 스모크 단계에서 고쳤고, 기준은 바꾸지 않았다.

- 선형 몫이 크게 음수인 것은 묶음당 창 약 800개에 같은 λ를 쓴 과적합이다. 측정 방법의 한계라서 아래 보조 확인으로 갈랐다.

**보조 확인 (등록 안 함, `scripts/sim2sim/stage29_g0_explore.py`, `results/stage29/g0_explore.md`)**

물리 몫의 기준선은 물리 없는 전체 선형 보정이고, λ는 넓은 격자에서 교차검증으로 골랐다.

| 장면 | 실제 물리값 + 상호작용 [CI] | 묶음별 선형 (λ 따로) [CI] | 낮은 마찰만 | 낮은 모터만 |
|---|---|---|---|---|
| 출발 | −0.038 [−0.041, −0.034] | −0.114 [−0.119, −0.108] | −0.036 | −0.039 |
| 평상시 | −0.022 [−0.023, −0.020] | −0.086 [−0.090, −0.083] | −0.024 | −0.023 |

- 실제 물리값(연속)과 그 상호작용을 넣어도 남은 오차는 줄지 않고 늘어난다. 정보가 아니라 분산만 더해진다는 뜻이다.
- 결론: **넓은 DR 범위 안에서는 25스텝 이력이 주어지면 물리값이 잠재 예측 오차에 보태는 정보가 출발 장면에서도 사실상 0이다.** 설계 13·21(참 물리를 넣어도 오차·넘어짐 같음)·24(이력 밖 정보 약 1 %)와 같은 결론이다.
- 한계: 이 데이터에는 DR 범위 밖(빙판 0.15 < 0.2)이 없다. 맥락이 범위 밖에서만 효과를 낸다는 문헌(DALI: 범위 안 0.92~0.97 동률, 범위 밖 +87.9 %)의 경우는 G0로 잴 수 없다.

# 설계 43: world model planner가 자기 상태에서 진짜 결과를 배우면 무릎 고장에서 걷는가 (장난감, 특권)

등록 2026-11-24, 결과 전. 설계 42 §9의 미리 정한 갈래("장난감 경로 닫음, A4도 실패")에 따라 사용자 위임(12시간 자율 진행) 아래 등록한다.

## 1. 질문

설계 42에서 고장 데이터만 5만 개 배운 world model(A4)도 MPPI로 걷지 못했다(J 0.16–0.20, 13–14/16 넘어짐, 상한 0.60/0.45, 0/16). 그 데이터는 **진짜 모델 planner가 걸으며 지나간 상태**에서 나왔다. world model planner는 처음 1–2초에 그 상태를 벗어나고(A4 kneeRR0 전진 0.40 m/s, 상한 0.34), 그 뒤 상태는 데이터에 없다.

> world model planner가 **실제로 지나가는 상태**에서, 그 planner가 고려한 후보 행동을 진짜 모델로 굴린 결과를 반복해서 더해 주면(DAgger식) 걷게 되는가. 같은 양의 데이터를 걷는 planner 상태에서만 더 주는 것과 다른가.

실기에서는 후보 행동의 진짜 결과를 얻을 수 없으므로 특권 실험이다. 실기용 절차의 가능성을 먼저 본다.

## 2. 고정

- 환경, planner(256 × 6, 관절 상자), 평가(명령 0.6 m/s, 16개 × 500스텝, 평가 시드 0–15), 지표 J, 넘어짐 — 설계 41, 42와 같다.
- 조건: kneeRR0, kneeFR0. world model 시드 0, 1, 2. MLP 3 × 512, 30000스텝, 처음부터 학습.
- 기본 데이터 B: 설계 42의 특권 데이터(진짜 모델 MPPI가 고장 조건에서 걸으며 만든 후보, `p_{c}_s1, s2`)에서 5만 transition.

## 3. 팔

| 팔 | 라운드 r = 1–4에서 더하는 데이터 |
|---|---|
| DG (자기 상태) | 직전 라운드 모델의 world model MPPI가 c에서 32개 × 최대 150스텝을 돈다(묶음 시드 20000 + 32(r−1)). 매 스텝 마지막 반복의 표본 4개를 진짜 조건 모델로 45스텝 굴려 기록한다. 첫 넘어짐까지의 상태만 쓴다. 라운드마다 2만5천 transition씩 누적한다 |
| CT (같은 양 대조) | B에서 2만5천 transition씩 더 뽑는다(걷는 planner 상태만) |

- 라운드 0 = B만으로 학습(두 팔 공통).
- 라운드 r 모델 = B 5만 + 추가 2만5천 × r로 처음부터 학습한다.

## 4. 측정

- 라운드마다 c에서 평가(16개 × 500스텝): J, 넘어짐, 전진 속도.
- 상한 U(c)는 설계 41 값(kneeRR0 0.601, kneeFR0 0.453).

## 5. 판정 (실행 전 고정)

**통과(팔, 조건):** 라운드 4에서 시드 평균 J ≥ 0.5 U(c)(kneeRR0 0.300, kneeFR0 0.226), 그리고 시드 평균 넘어짐 ≤ 8/16.

| 판정 | 조건 |
|---|---|
| 자기 상태 덮기가 열쇠 | DG가 통과하고 같은 조건에서 CT는 실패한 조건이 하나 이상 |
| 양으로 충분 | DG가 통과한 조건에서 CT도 모두 통과 |
| 중간 | CT만 통과 |
| 실패 | DG가 두 조건 모두 통과 못 함 |

## 6. 예측

- DG 통과(하나 이상) 35 %, CT 통과 15 %.
- 판정: 열쇠 25 %, 양으로 충분 10 %, 중간 5 %, 실패 60 %.

## 7. 실행

- 코드: `toy_wm.py evalcl --record_cand K`(등록 전 커밋), `scripts/toy/stage43.sh`, `scripts/toy/stage43_report.py`.
- 12개 사슬(DG 6 + CT 6)을 GPU 4개에 2개씩. 결과 `results/stage43/`, 큰 파일 `/mnt/newssd/cjkim/toy/e43`.
- 예상 계산: 약 1.5–2시간.

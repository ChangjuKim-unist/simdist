# 설계 문서 9: 배포 분포 정합(Deployment-Matched) 사전학습·적응 — 방법 논문을 위한 메커니즘

작성 2026-10-28. 선행: 설계 문서 6(E1·E2), 7(§7: 잔차·계획기 옵션·증류 고리 불성립, 결합은 prior 갱신에도 적용), 8(broadhead, 평가 중). 사용자 결정: "강한 방법론"; 방향 합의(2026-10-28).
컨셉: 지금까지의 발견은 하나의 원리로 읽힌다 — **학습 분포가 배포 방문 분포와 다르면, 그 차이(집중성 계수)만큼 갱신이 해가 된다.** 방법은 이 계수를 세 곳에서 데이터 쪽에서 상쇄한다. 월드모델·계획기·제어 루프는 바꾸지 않는다.

| ① 초기 prior (시뮬) | 없음 | DR 분포 | 엔트로피 최대화(DORAEMON 인용) + **계획기가 회복 못 하는 조건 우선** | E1·X4: 계획기는 커버리지를 못 넓힘 |

| ③ 적응 (실데이터) | 라운드 k 로그 + 과거 로그 | 잠재 동역학 | prior 일관성 $w_t=\exp(-\lVert a_t-\pi(h_t)\rVert^2/2\sigma^2)$ | E2·X3: 다른 prior의 데이터가 2.2–2.8배 해악 |

## 1. 수학 (짧게)
ERM으로 학습한 $f$의 배포 손실 $\le$ 학습 분포 손실 × $c$, $c=\sup d_{\pi_e}/\nu$ (Ross & Bagnell 2012; BC에도 같은 형태). 중요도 가중 $\nu' \propto r\cdot\nu$ 로 학습하면 $c\to\sup d_{\pi_e}/\nu'$ 가 줄어든다. ②는 $\nu$ = 시뮬 전문가 분포, $d_{\pi_e}$ = 실로그 분포, $r$ 은 분류기 로짓(균형 배치)으로 추정. ③은 $\nu$ = 과거 수집 정책 분포, 가중치는 "배포 prior가 그 행동을 할 가능성"의 대리이며, $\pi_e$ 자신의 로그에서는 $w\approx1$(측정: prior-first 데이터 평균 0.96, 좁은 prior 데이터 0.45).
①의 계획기 인식 기준: 조건 $\xi$의 prior 단독 넘어짐 $F_D(\xi)$, 계획기 포함 $F_B(\xi)$. 회복비 $\rho(\xi)=F_B/F_D$. DR 가중 $\propto F_D(\xi)\cdot\rho(\xi)$ — 넘어지는데 계획기도 못 고치는 조건에 집중. (측정됨: 모터 ≤ 0.5 $\rho\approx1$, 마찰 0.15 $\rho>1$, 정상·모터 0.8 $\rho\approx0.4$.)

## 2. 실험 (시뮬-투-시뮬, 18대 × 100초, 짝지은 CI; 모두 11/8 이전)

**X9a 프라이어 일관성 적응 (③)** — 드라이버 `stage4_matched.sh`
데이터: 좁은 prior 로그(B의 데이터) 모터 0.4·정상, σ = 0.5(주), 0.3(보조). 평가: 넓은 학생 + 계획기.
- P9a: 모터 0.4에서 B_pw/B0 ≤ 1.2 (B는 2.15). 정상에서 ≤ 1.2 (B 1.15).
- P9a′: prior-first 데이터에 같은 가중을 걸면 결과 불변(B′ ± 10 %).
- P9a″ (재사용): 좁은+prior-first 혼합 데이터(90k) 가중 적응 ≥ prior-first 단독(45k) — 과거 데이터를 버리지 않아도 됨.
관문: P9a 성립 → 방법 ③ 확정, 하드웨어 M5′(r3 데이터 가중 적응 + broadhead/학생) 추가. 불성립 → ③ 제외, "prior-first 수집만" 처방.

**X9b 밀도비 가중 prior (②)**
시뮬 데이터: 넓은 전문가 사전학습형 7.7M(설계 문서 8). "실로그": 배포 시스템(B0)의 모터 0.4·마찰 0.15·정상 로그 각 45k(마찰 0.15는 수집). 학생 두 개, 같은 데이터·같은 1.5M 윈도·20k 스텝: 균등 대 밀도비 가중(세 로그 합집합).
- P9b: 가중 학생 단독 넘어짐 마찰 0.15에서 −30 % 이상(CI 1 제외), 모터 0.4에서 ≤ 균등, 정상에서 +10 % 이내.
- P9b′: 분류기의 "지지 없음" 비율(p(real) > 0.95)이 마찰 0.15 > 모터 0.4 > 정상 (커버리지 진단으로서의 순서).
관문: P9b 성립 → ② 확정, 라운드 2(가중 학생의 로그로 재가중) 1회. 불성립 → ②는 진단(P9b′)만 남김.

**X9c 계획기 인식 DR (①)** — 전문가 2개(각 2.5시간)
균등 확장(모터 0.3–1.1, 마찰 0.05–1.2, 질량 −1~6) 대 계획기 인식 확장(회복비 표에 따라 모터·마찰은 넓히고 질량은 기본 유지, 모터 0.3–0.5 구간 샘플 2배). 같은 레시피 학생 → 모터 0.4·마찰 0.15·적재 5·정상에서 D와 B0.
- P9c: 계획기 인식 전문가의 학생이 모터 0.4·마찰 0.15에서 균등 확장과 같거나 낫고 정상에서 더 낫다(보수성 적음). 시드 편차(±50 %)를 넘는 차이만 인정.
관문: 성립 → ① 포함. 불성립 → ①은 DORAEMON 인용 + 회복비 진단 표로 축소.

## 3. 자원·순서
stage3 eval(broadhead) → X9a(적응 4회 + 평가 6회 ≈ 6 h) → X9b(수집 1회, 가중 계산, 학생 2개, 평가 6회 ≈ 7 h) → X9c(전문가 2개 5 h + 데이터·학생 1 h + 평가 8회 ≈ 10 h). 총 ~1일 반. 하드웨어 11/10 전 완료.

## 4. 위험
- ③의 σ 선택이 결과를 좌우 → 주·보조 두 값 사전 등록, 실로봇에서는 prior-first 데이터의 평균 가중 0.9가 되도록 σ 보정.
- ②는 데이터를 재배분할 뿐 만들지 못함 → 효과는 DR 가장자리·서툰 축에서만; 마찰 0.15를 주 지표로 둔 이유.
- X3의 증류 실패 해석 보정: prior-first 로그의 실행 행동은 학생 출력과 거의 같았으므로(중앙 거리 0.005), X3의 악화는 계획기 라벨이 아니라 소량 데이터로의 계속 학습 자체일 수 있다. ②는 전문가 라벨·대용량 시뮬 데이터를 쓰므로 이 문제가 없다.

### 2.1 구현 메모 (2026-10-28 저녁)
밀도비 분류기를 학생 입력 전체(관측+행동+명령)로 학습하면 실로그(계획기 행동)와 시뮬(전문가 행동)이 **행동**으로 완벽히 갈려(AUC 1.0, 실 윈도 98 %가 "지지 없음") 가중이 퇴화한다 — 설계 문서 5의 라벨 없는 가시성이 실패한 것과 같은 이유. 관측 히스토리만 써도 AUC 0.998·66 % 지지 없음. **관측의 윈도 통계(평균·표준편차·처음–끝 차, 105차원)**로 바꾸면 AUC 0.978, 지지 없음 3.7 %, 시뮬 가중치의 유효 표본 비율 0.70, 상위 10 % 윈도가 질량의 24 % — 행동이 아니라 **상태 영역**을 구분하는 가중이 된다. 밀도비는 α = 0.5로 템퍼링. 기본값으로 채택(`--features stats`).

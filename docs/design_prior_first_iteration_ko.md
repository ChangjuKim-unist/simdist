# 설계 문서 7: Prior-First Iteration — DR prior · 계획기 · 실데이터 적응을 한 고리로

작성 2026-10-26. 선행: 설계 문서 6(E1·E2 통과), `reports/Prior-first 연계 아이디어.md`(문헌 근거). 사용자 승인: "이런 방향으로 진행".
컨셉: SimDist의 라운드 고리(수집 → 오프라인 적응 → 재수집)는 그대로 두고, 라운드 안에서 **(i) 동역학은 동결된 시뮬 동역학 위의 잔차로 적응하고, (ii) prior도 계획기가 실제 실행한 행동으로 갱신하며, (iii) 커버리지 밖 조건은 실데이터 대신 시뮬 DR 재학습으로 돌려보낸다.** 온라인 학습·제어 루프·월드모델 구조·MPPI는 바꾸지 않는다.

## 1. 수학적 근거 (전부 기존 결과; 우리 역할은 측정)

- **결합**: batch system-ID 경계(Ross & Bagnell 2012)의 집중성 항 $c^{\pi_e}_{\nu}=\sup d_{\pi_e}/\nu$ — 배포 정책 $\pi_e$의 방문 분포와 수집 분포 $\nu$의 비. agnostic 경우(잠재 트랜스포머는 참 시스템을 포함하지 않음) 지지 밖 적합은 임의. 우리 E2의 2.2배가 이 항이다. 현재 정책으로 수집하면($\nu=d_{\pi_e}$) 항이 사라진다(DAgger-for-models Thm 4.1).
- **잔차-on-동결**: $f'=f_{\text{sim}}+g$, $g$ 0-초기화. 지지 밖에서는 $g\approx0$으로 되돌아가 시뮬 커버리지를 지킨다(ReDRAW, LIFT 관찰). 전체 적응은 지지 밖에서 임의로 틀어진다.
- **prior 갱신**: Dual Policy Iteration — 계획기(느린 정책)의 실행을 prior(빠른 정책)에 지도학습. 신뢰 영역(혼합 β)이 없으면 다음 라운드 $c$가 다시 커진다. 상상 데이터가 아니라 **실행된** 행동만 쓰므로 설계 문서 3의 착취 붕괴가 없다.
- **커버리지 벽**: 계획기는 prior가 샘플할 수 있는 교정만 되살린다(PA-RL, DREAM-Chunk; 우리 E1). prior가 모르는 조건은 DR로만 덮인다.
- **계획기 노이즈**: 단일 노이즈 MPPI는 과착취/과탐색(DIAL-MPC); 반복·지평 2축 어닐링은 연산 0.
- **실행 일관성**: 직전 계획의 예측 잠재 $\hat z_{t}$와 실제 $z_t$의 거리는 모델 신뢰도의 실측치. 커버리지 밖에서 계획기가 넘어짐을 1.02–1.14배 늘리던 손해를 "거리가 크면 prior 계획 실행"으로 없앤다.

## 3. 실험과 예측 (실험 전 기록; 모두 시뮬-투-시뮬, 18대 × 100초, 짝지은 CI)

**X1 잔차 대 전체 적응 (결합 해악)** — `stage2_residual.sh`
같은 데이터로 (전체 dyn) 대 (잔차 dynres), 넓은 학생 + 계획기로 평가. 데이터: 좁은 prior 데이터(B의 것)와 prior-first 데이터(B′의 것), 조건 모터 0.4·정상.
- P1a: 좁은 데이터에서 잔차의 해악은 전체의 절반 이하 — B_res/B0 ≤ 1.3 (B/B0 = 2.15).
- P1b: prior-first 데이터에서 잔차 ≈ 전체 (B′_res ≈ B′ ≈ B0 모터 0.4; 정상에서 B′_res ≤ B0).
- 관문: P1a 성립 → PFI 2단계는 잔차. 불성립(잔차도 2배 해악) → 결합은 구조로 못 막고 prior-first 수집만이 처방; 전체 적응 유지.

**X2 계획기 ablation** — σ 스케줄, 일관성 게이트, 둘 다. 학생 {좁은 w10, 넓은 w03} × 조건 {정상, 모터 0.4} × 변형 {기본, σ, 게이트, σ+게이트}.
- P2a (σ): 좁은 학생·정상에서 넘어짐 −10 % 이상(CI가 1 제외); 넓은 학생에서는 변화 없음(CI가 1 포함).
- P2b (게이트): 커버리지 밖(좁은 학생·모터 0.4)에서 B0/D 비 1.02–1.14 → ≤ 1.0; 안에서는 손실 없음(보상 −3 % 이내).
- 관문: 둘 중 하나라도 성립 → 하드웨어 M3에 적용. 둘 다 불성립 → 계획기는 현재 설정 유지, 논문의 계획기 절은 "회복 측정"만.

**X3 계획기→prior 증류 + PFI 2라운드** (조건 모터 0.4와 정상 각각)
라운드 1: B0(넓은 학생 + 계획기)로 45k 수집(이미 있음, prior-first 데이터) → $f_1$ 잔차 적응 → $\pi_1$ = 학생을 실행 행동으로 BC(β = 0.3, 시뮬 윈도 혼합, 학생 초기화) → 평가 D1(π₁ 단독), B1(π₁ + 계획기 + $f_1$).
라운드 2: B1로 45k 수집 → $f_2$, $\pi_2$ → D2, B2.
- P3a: D1 < D0 (학생 단독 넘어짐 −30 % 이상, 모터 0.4) — 계획기의 교정이 prior에 흡수됨.
- P3b: B1/D1 비가 B0/D0 비보다 1에 가깝다(계획기 할 일이 줄어듦), B1 ≤ B0.
- P3c: 라운드 2에서 해악 없음: B2 ≤ B1 (CI), D2 ≤ D1. 결합 유지의 증거.
- P3d (대조): 같은 β로 **좁은 prior 데이터**로 증류한 π₁′는 D1보다 나쁘다(결합이 prior 갱신에도 적용).
- 관문: P3a·P3c 성립 → PFI가 논문의 뼈대, 하드웨어 세션 3–4에 1라운드 투입. P3a만 → "증류 1회" 방법으로 축소. 불성립 → prior는 시뮬 고정, 주장 1·3만.

**X4 커버리지 진단 표** — RAPP식 축별 feasibility sweep(학생 w03·w10, 축 {모터, 마찰, 질량, 강성} × 6점). 예측 P4: 학생이 걷는 구간이 전문가 DR 범위와 일치(모터 하한 ≈ 0.4; 마찰 ≈ 0.15; 질량 ≤ 3 kg). 실로봇 토크 40 %·적재 3 kg 예측의 근거.

## 5. 위험
- 잔차가 너무 작아 적응이 안 됨(정상에서도 B′_res ≫ B′) → hidden 256으로 1회 재시험.
- 게이트 임계가 조건마다 달라 자동 보정 필요 → 실행 중 중앙값의 배수(자기 보정)로 정의, 배수 3·5 두 값.
- 증류가 prior를 넓은 전문가 행동에서 멀리 끌고 가면 라운드 2 결합이 깨짐 → β ≤ 0.3, P3c로 감시.
